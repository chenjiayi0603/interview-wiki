# 面试知识库

544 个面试知识点，覆盖 C++、Go、MySQL、Redis、RocksDB、网络协议、性能优化、系统设计、AI 等领域。

## 使用

直接打开 `index.html` 即可搜索和浏览（需要 HTTP 服务器，不支持 `file://` 协议）。

## 部署到 GitHub Pages

```bash
git init
git add .
git commit -m "init"
git remote add origin https://github.com/<your-username>/<repo-name>.git
git push -u origin main
```

然后在 GitHub 仓库 Settings → Pages → 选择 `main` 分支，根目录，保存即可。

## 本地预览

```bash
python3 -m http.server 8000
# 或
npx serve .
```

## 搜索

客户端全文搜索，无需后端服务，无服务器成本。
