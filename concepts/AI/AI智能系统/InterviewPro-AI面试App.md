# InterviewPro AI 面试 App

> 独立开发的 AI 面试练习 App，支持语音对话、实时转写、发音评测。

## 项目信息

| 项目 | 内容 |
|------|------|
| 开发时间 | 2024年 gap 期间 |
| 技术栈 | Go + Gin + WebSocket + Redis + React Native + DeepSeek API + 阿里云语音 |
| 类型 | 个人全栈项目 |

## 核心功能

- **模拟面试**：AI 生成问题，语音回答
- **实时转写**：边说边识别成文字
- **发音评测**：评测英文发音标准度
- **智能反馈**：分析回答内容，给改进建议

## 技术难点与解决方案

### 1. 语音延迟优化（1.5s → 500ms）

**流式上传**：边录边上传，不等录完
**阿里云实时语音 API**：WebSocket 实时识别
**结果缓冲**：200ms buffer 平滑输出抖动

### 2. AI 响应慢优化

流式输出 + 打字机效果，首字延迟从 5s 降到 0.5s

### 3. 技术选型

Go 选型原因：goroutine 适合 WebSocket 高并发，单二进制易部署，性能足够

## 面试问答

**Q: WebSocket 怎么保证可靠性？**
心跳保活（30s一次），超时重连，消息序列号防丢

**Q: AI 评分准不准？**
多维度评测：内容相关性 + 逻辑性 + 发音标准度，结果供参考
