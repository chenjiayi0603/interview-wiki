# C++17 并行算法

> C++17 引入的并行算法执行策略，支持多线程并行和向量化。

## 基本用法

```cpp
#include <algorithm>
#include <execution>

std::sort(std::execution::seq, v.begin(), v.end());       // 串行
std::sort(std::execution::par, v.begin(), v.end());       // 并行
std::sort(std::execution::par_unseq, v.begin(), v.end()); // 并行+向量化
```

## par vs par_unseq

| 维度 | par | par_unseq |
| ---- | --- | --------- |
| 并行方式 | 多线程并行 | 多线程 + SIMD 向量化 |
| 线程内执行 | 顺序执行 | 可向量化、可交错执行 |
| 同步限制 | 元素访问可含 mutex | 元素访问不可含任何同步原语 |
| 性能潜力 | 多核并行 | 多核 + 向量化，吞吐更高 |

- **par**：多线程间并行，线程内顺序；元素访问可安全使用 mutex。
- **par_unseq**：多线程 + 向量化，线程内可能交错、向量执行；元素访问**禁用** mutex/condition_variable 等，否则易死锁或未定义行为。
- **选型**：元素访问无共享可变状态、无同步原语时用 par_unseq 追求性能；否则用 par。
  - **par_unseq 适用**（无共享可变状态、无同步原语）：
    - 逐元素变换：`[](auto& x){ x *= 2; }`、`[](auto& x){ x = std::sqrt(x); }`，每元素仅依赖自身；
    - 纯拷贝/填充：`std::copy`、`std::fill`，目标仅由下标决定；
    - 只读统计：`std::count_if` 只读谓词，不修改共享变量。
  - **par 才适用**（有共享可变或同步）：
    - 共享计数器：`int sum = 0; for_each(par, ..., [&sum](auto x){ sum += x; })` 需 atomic 或 mutex；
    - 元素间依赖：`v[i] += v[i-1]` 等跨元素读写；
    - 访问 mutex/atomic/condition_variable：元素处理内部加锁或原子操作。
