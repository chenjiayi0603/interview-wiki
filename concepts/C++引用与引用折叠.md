# C++引用与引用折叠

See also: [[C++语言特性]], [[C++进阶知识点]], [[C++高频面试问题]]

## 引用基础知识

- **左值引用**：`T&` → 绑定到左值
- **右值引用**：`T&&` → 绑定到右值（临时变量）

| 类型 | 是否有名字 | 是否可取地址 | 生命周期     | 示例      |
| -- | ----- | ------ | -------- | ------- |
| 左值 | ✅ 有   | ✅ 可    | 程序块结束前   | 普通变量    |
| 右值 | ❌ 无   | ❌ 不可   | 表达式结束即销毁 | 临时值、返回值 |

> **左值 vs 右值 快速对比：**
>
> - **左值（lvalue）**：有"身份"的对象，一般**可以取地址、可以多次使用**。典型如：普通变量、数组元素、解引用 `*p`、返回左值引用的函数结果等。  
>   - 示例：  
>     ```cpp
>     int a = 10;
>     a = 20;        // a 是左值
>     int* p = &a;   // 可以对左值取地址
>     ```
> - **右值（rvalue）**：大多是**用完即丢的临时值**，没有稳定的存储"身份"，通常不能取地址。典型如：字面量 `10`、表达式 `a + b` 的结果、按值返回的函数结果。  
>   - 示例：  
>     ```cpp
>     int a = 10, b = 20;
>     int c = a + b;   // a+b 是右值
>     // int* p = &(a + b); // 非法，右值不能取地址
>     ```
> - **右值细分（C++11）**：  
>   - **纯右值（prvalue）**：传统意义上的临时值，例如 `10`、`a + b`、按值返回的对象。  
>   - **将亡值（xvalue）**：即将"被搬走"的对象，典型表达式是 `std::move(obj)`，类型通常是 `T&&`。  
> - **记忆口诀：**  
>   - 左值：**有名字，可取地址，可复用**（"有家可回"）。  
>   - 右值：**多为临时，无稳定地址**（"路过打个招呼就走"）。  
>   - 在参数绑定上：`T&` 只接左值，`T&&` 只接右值（完美转发中的"万能引用"是特殊规则，见后文）。 

## 引用初始化规则

| 引用类型        | 可绑定目标       | 示例                   |
| ----------- | ----------- | -------------------- |
| `T&`（左值引用）  | 左值          | `int a; int &r = a;` |
| `const T&`  | 左值、右值       | `const int &r = 10;` |
| `T&&`（右值引用） | 右值          | `int &&r = 5;`       |

## 引用折叠规则（核心）

| 组合形式     | 折叠结果    | 说明      |
| -------- | ------- | ------- |
| `X& &`   | → `X&`  | 左值优先    |
| `X& &&`  | → `X&`  | 左值优先    |
| `X&& &`  | → `X&`  | 左值优先    |
| `X&& &&` | → `X&&` | 双右值保留右值 |

> **记忆口诀：** 只要有 `&` 出现，结果就是 `&`。

## 引用折叠应用场景

- **模板参数推导**：`template<typename T> void func(T&& val)` 万能引用
- **typedef 类型别名**
- **auto 类型推导**：`auto &&b = a;`
- **decltype 类型推导**

引用折叠是 **C++11 完美转发（std::forward）** 的理论基础。
