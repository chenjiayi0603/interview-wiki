# C++ 指针体系

## 1. 原始指针基础

**指针的本质：**

```cpp
int* p;           // 指向 int 的指针
int** pp;         // 指向指针的指针
const int* cp;    // 指向常量的指针
int* const pc;    // 常量指针（指针本身不能改变）
const int* const cpc; // 指向常量的常量指针
```

**指针的常见操作：**

| 操作 | 说明 | 示例 |
|------|------|------|
| `&` | 取地址 | `int* p = &x;` |
| `*` | 解引用 | `int y = *p;` |
| `->` | 成员访问 | `p->member` |
| `[]` | 数组访问 | `p[i]` |
| `nullptr` | 空指针 | `int* p = nullptr;` |

**指针的常见问题：**

- **悬空指针（Dangling Pointer）**：指向已销毁对象
- **野指针（Wild Pointer）**：未初始化，指向随机地址
- **内存泄漏（Memory Leak）**：忘记 `delete`
- **重复释放（Double Free）**：对同一块内存多次 `delete`

> **野指针 vs 悬空指针：**
>
> - **野指针（Wild Pointer）**：指向**未知/未定义地址**的指针。常见于指针**未初始化就使用**，或经过错误的指针运算/越界访问后指向了不可控区域，例如：  
>   `int* p; *p = 10;  // p 是野指针，内容是随机垃圾值`。  
>   特点：根本不知道“指向哪里”，一用就可能立刻崩溃或破坏内存。
> - **悬空指针（Dangling Pointer）**：指向**曾经合法、现在已经失效**对象的指针。典型是对象已经被 `delete` 或生命周期结束，但指针还保留旧地址，例如：  
>   `int* p = new int(10); delete p; *p = 20;  // 此时 p 为悬空指针`，  
>   或返回局部变量地址、容器扩容后仍使用旧迭代器等。  
>   特点：看起来“好像还指着一块正常内存”，但已经是未定义行为，更隐蔽难查。
>
> **一句话记忆：** 野指针 = 一开始就没家；悬空指针 = 原来有家，现在家没了。

## 2. 函数指针

函数指针指向一个函数的入口地址，用于间接调用函数。

```c
typedef int (*fun_t)(int, int);
int (*p)(int, int);
```

| 写法                                         | 含义                                          |
| ------------------------------------------ | ------------------------------------------- |
| `int (*p)(int, int);`                      | `p` 是一个指针，指向返回值为 `int`、参数为 `(int,int)` 的函数。 |
| `typedef int (*fun_t)(int, int); fun_t p;` | 用 `typedef` 简化函数指针定义。                       |

**使用示例：**

```c
int sum(int a, int b) { return a + b; }

fun_t p = sum;
printf("%d\n", p(3, -4)); // 等价于 sum(3, -4)
```

> 函数名本身会**隐式转换为函数指针**，其值即为函数的入口地址。

**函数指针数组：**

```c
typedef int (*fun_t)(int, int);
int sum(int, int); int max(int, int);
fun_t p[2] = { sum, max };
printf("%d\n", p[0](3,4));
```

**函数名与地址关系：**

| 表达式       | 含义                          |
| :-------- | :-------------------------- |
| `sum`     | 函数名，可隐式转换为函数指针              |
| `&sum`    | 函数地址，类型为 `int (*)(int,int)` |
| `*sum`    | 解引用函数指针，再次转回函数指针（同样地址）      |
| `*(&sum)` | 等价于 `sum`                   |

## 3. 数组指针

**一维数组指针：**

```c
char cTestOne[3] = {1,2,3};
char (*pOneArray)[3] = &cTestOne;  // 指向整个数组
char *pOneElement = cTestOne;      // 指向数组首元素
```

| 表达式           | 含义      | 步距    |
| :------------ | :------ | :---- |
| `&cTestOne`   | 整个数组地址  | +3 字节 |
| `pOneArray`   | 指向数组的指针 | +3 字节 |
| `cTestOne`    | 第一个元素地址 | +1 字节 |
| `pOneElement` | 指向元素的指针 | +1 字节 |

**二维数组指针：**

```c
char cTestTwo[2][3] = {1,2,3,4,5,6};
char (*pTwoArray)[2][3] = &cTestTwo;     // 指向整个二维数组
char (*pTwoArrayOneLine)[3] = cTestTwo;  // 指向一行
char *pTwoElement = *cTestTwo;           // 指向首元素
```

## 4. 复杂声明

**函数返回数组指针：**

```c
int (*func(int num))[4];
```

**函数指针返回数组指针：**

```c
int (*(*p)(int, int))[4];
```

## 5. 总结对比表

| 类型        | 示例声明                      | 指向内容   | 使用说明            |
| --------- | ------------------------- | ------ | --------------- |
| 普通指针      | `int *p`                  | 单个变量   | 取地址或偏移访问        |
| 数组指针      | `int (*p)[N]`             | 一整个数组  | 用于函数参数传递数组      |
| 函数指针      | `int (*p)(int,int)`       | 函数入口   | 间接调用函数          |
| 函数指针数组    | `int (*p[])(int,int)`     | 多个函数指针 | 动态调用不同函数        |
| 返回数组指针的函数 | `int (*func())[4]`        | 函数返回数组 | 用 typedef 简化    |
| 返回数组指针的函数指针 | `int (*(*p)(int,int))[4]` | 复杂嵌套   | 通常通过 typedef 封装 |

**关键理解点：**
- 优先级口诀：括号 `()` > 星号 `*` > 方括号 `[]` > 右结合
- 函数名在表达式中自动转为“指向函数的指针”
- 数组名在表达式中自动转为“指向首元素的指针”，但 `&array` 表示整个数组的地址
