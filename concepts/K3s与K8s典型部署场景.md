## 详细场景分析

### 个人学习与实验

**推荐方案：K3s**

**优势：**
- 安装简单，一行命令完成
- 资源占用低，可在 2GB 内存机器运行
- 启动快速，便于快速迭代
- 完整 K8s API，学习成果可迁移

**配置示例：**
```bash
# 在个人电脑上安装 K3s（最小配置）
# 系统要求：Ubuntu 20.04+, 1CPU, 1GB RAM

# 安装
curl -sfL https://get.k3s.io | sh -

# 验证
kubectl get nodes
kubectl version
```

### 边缘计算与 IoT

**推荐方案：K3s**

**优势：**
- 极低资源占用，适应 ARM 设备
- 支持单节点和集群模式
- 内置 Traefik，简化边缘路由
- 离线安装包可用

### 企业级生产环境

**推荐方案：K8s**

**优势：**
- 经过大规模生产验证
- 丰富的云服务商支持
- 完善的企业级功能
- 更多的生态工具和集成

### CI/CD 流水线

**推荐方案：根据规模选择**

| 规模 | 推荐 | 说明 |
|------|------|------|
| 个人/小团队 | K3s | 快速搭建，低成本 |
| 中等规模 | K8s (单集群) | 稳定的生产级环境 |
| 大型企业 | K8s (多集群) | 隔离不同环境 |

**工具集成建议：**
```yaml
# GitLab CI + K3s 集成示例
apiVersion: v1
kind: Namespace
metadata:
  name: gitlab-runners
---
apiVersion: v1
kind: ServiceAccount
metadata:
  name: gitlab-runner
  namespace: gitlab-runners
---
apiVersion: v1
kind: ConfigMap
metadata:
  name: gitlab-runner-config
  namespace: gitlab-runners
data:
  config.toml: |
    [[runners]]
      name = "k3s-runner"
      url = "https://gitlab.example.com"
      executor = "kubernetes"
      [runners.kubernetes]
        namespace = "gitlab-runners"
        image = "ubuntu:22.04"
```
