# KeyDB与RocksDB

## 一、KeyDB架构
```
┌────────────────────────────────────────┐
│              Redis协议兼容              │
├────────────────────────────────────────┤
│           RocksDB存储引擎              │
│  ┌──────────────────────────────────┐  │
│  │        MemTable (SkipList)       │  │
│  ├──────────────────────────────────┤  │
│  │     Immutable (后台flush)        │  │
│  ├──────────────────────────────────┤  │
│  │      L0/L1/L2... (SSTable)       │  │
│  └──────────────────────────────────┘  │
└────────────────────────────────────────┘
```

## 二、KeyDB vs Redis
| 特性 | Redis | KeyDB |
|------|-------|-------|
| 持久化 | RDB/AOF | RocksDB |
| 数据结构 | 丰富 | 字符串为主 |
| 内存需求 | 全量内存 | 可配置 |
| 容量 | 受内存限制 | 磁盘容量 |
| 性能 | 极低延迟 | 稍高延迟 |
| 备份恢复 | 简单 | 需处理SSTable |

## 三、KeyDB云存储特点
- **存算分离**：计算节点与存储节点分离
- **扩展性**：存储层独立扩缩容
- **一致性**：WAL + 分布式存储保证
- **多租户**：资源隔离

## 四、项目实践（华为云存储）

### 1. 存算分离架构
```
┌─────────────┐     gRPC      ┌─────────────┐
│  计算节点   │  <────────>   │  存储节点   │
│  (KeyDB)    │              │  (RocksDB)  │
└─────────────┘              └─────────────┘
       │                            │
       │  数据路径                   │  数据路径
       └────────────────────────────┘
              OBS对象存储
```

### 2. 扩容方案
- **数据迁移**：一致性哈希
- **在线扩容**：无需停服
- **流量切换**：灰度切流

### 3. 故障恢复
- **WAL重放**：恢复未持久化数据
- **副本同步**：Paxos/Raft
- **增量同步**：断点续传
