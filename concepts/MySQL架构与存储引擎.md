# MySQL 架构与存储引擎

## 一、整体架构

MySQL 采用分层架构设计：

```
┌─────────────────────────────────────────┐
│           Client Layer (连接池)           │
├─────────────────────────────────────────┤
│         Server Layer (SQL层)            │
│  ┌─────────┬─────────┬─────────┬─────┐ │
│  │ Parser  │ Optimizer│ Exec │ Cache │ │
│  └─────────┴─────────┴─────────┴─────┘ │
├─────────────────────────────────────────┤
│           Storage Engine Layer          │
│      InnoDB / MyISAM / Memory           │
├─────────────────────────────────────────┤
│              OS Layer                   │
└─────────────────────────────────────────┘
```

## 二、存储引擎对比

| 特性 | InnoDB | MyISAM |
|------|--------|--------|
| 事务 | 支持 | 不支持 |
| 行锁 | 支持 | 表锁 |
| 外键 | 支持 | 不支持 |
| MVCC | 支持 | 不支持 |
| 索引 | B+Tree | B+Tree+Fulltext |
| crash-safe | 是 | 否 |

## 三、InnoDB 物理存储结构

- **表空间**（Tablespace）：ibdata1
- **段**（Segment）：数据段、索引段、回滚段
- **区**（Extent）：连续64个页，1MB
- **页**（Page）：16KB（可配置）
- **行**（Row）：InnoDB行格式

### 页结构

```
┌────────────────────────────────────────┐
│ File Header (38B) - 页信息、校验          │
├────────────────────────────────────────┤
│ Page Header (56B) - 槽数、记录数等       │
├────────────────────────────────────────┤
│ Infimum + Supremum Records             │
├────────────────────────────────────────┤
│ User Records - 实际行数据               │
├────────────────────────────────────────┤
│ Free Space - 空闲空间                   │
├────────────────────────────────────────┤
│ Page Directory - 稀疏目录               │
├────────────────────────────────────────┤
│ File Trailer (8B) - 校验                │
└────────────────────────────────────────┘
```

### 行格式

- **Compact**：变长字段长度、NULL标志位
- **Redundant**：字段偏移量数组
- **Dynamic**：大字段完全存储在外部
- **Compressed**：压缩存储
