# OBS 对象存储

> OBS（Object Storage Service）是华为云提供的对象存储服务，兼容 S3 协议，适用于海量数据存储、备份归档、静态网站托管等场景。

See also: [[OBS对接RocksDB性能分析]], [[KeyDB存算分离项目]]

---

## 一、核心特性

### 1.1 对象存储 vs 块存储 vs 文件存储

| 维度 | 对象存储（OBS/S3） | 块存储（ESSD/NVMe） | 文件存储（NAS） |
|------|-------------------|-------------------|----------------|
| 访问方式 | HTTP REST API / SDK | 块设备读写（POSIX） | 文件系统挂载 |
| 延迟 | 毫秒级（1~50ms） | 微秒级（0.1~0.5ms） | 毫秒级 |
| 带宽 | 高（GB/s 级） | 高（GB/s 级） | 中等 |
| 扩展性 | 近乎无限（PB 级） | 有限（TB 级） | 有限 |
| 一致性 | 最终一致性（部分强一致） | 强一致性 | 强一致性 |
| 成本 | 低（按量付费） | 高（预分配） | 中等 |
| 适合场景 | 大文件、归档、备份 | 数据库、高性能计算 | 共享文件 |

### 1.2 访问模型

- **PUT**：上传对象（支持分片上传大对象）
- **GET**：下载对象（支持 Range GET 部分读取）
- **DELETE**：删除对象
- **LIST**：列举对象

## 二、性能特征

### 2.1 延迟

| 场景 | 内网典型延迟 |
|------|------------|
| 小对象 GET（<1MB，热连接） | 3~12 ms |
| 小对象 GET（含建连） | 8~25 ms |
| 大对象 PUT（>10MB） | 20~100+ ms |
| 高负载/跨 Region | 20~100+ ms |

### 2.2 带宽

| 场景 | 内网典型带宽 |
|------|------------|
| 单连接读 | 500~2,000 MB/s |
| 单连接写 | 300~1,000 MB/s |
| 多连接聚合 | 可达 5~10 GB/s+ |

### 2.3 服务端限流

| 限流维度 | 典型配额 |
|----------|---------|
| 单桶 GET QPS | 5,000~20,000/s |
| 单桶 PUT QPS | 500~2,000/s |
| 超限处理 | 返回 503 SlowDown，需退避重试 |

> **关键约束**：PUT QPS 配额远低于 GET，对写密集型场景（如 RocksDB Compaction）是硬天花板。

## 三、与 RocksDB 对接的挑战

### 3.1 访问模式不匹配

- RocksDB：大量小块随机读写（4KB~64KB）
- OBS：优化大对象顺序读写
- 小块 IO 无法利用带宽优势，延迟由处理开销主导

### 3.2 一致性语义冲突

- RocksDB 预期 POSIX fsync 语义（强持久化）
- OBS 提供最终一致性（写入后可能短暂不可见）

### 3.3 成本模型

- OBS 按请求次数计费
- Compaction 写放大会导致请求量爆炸
- 请求费可能远超存储费（可达 78 倍）

## 四、内网 SDK vs 公网 HTTP

| 指标 | 公网 HTTP REST | 内网 SDK |
|------|---------------|----------|
| 单次请求延迟（小对象 GET） | 5~50 ms | 1~5 ms |
| 单次请求延迟（大对象 PUT） | 20~100 ms | 5~20 ms |
| 读带宽（单连接） | 100~500 MB/s | 500~2,000 MB/s |
| 写带宽（单连接） | 50~300 MB/s | 300~1,000 MB/s |
| 连接协议 | HTTP/HTTPS + TLS 开销 | 专有协议，无 TLS 开销 |
| 鉴权方式 | 每次请求 IAM 鉴权 | 长连接 + token 复用 |
