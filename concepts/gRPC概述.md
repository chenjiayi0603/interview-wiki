# gRPC 概述

## 一、什么是 gRPC

gRPC 是 Google 开源的高性能、跨语言的 **RPC（远程过程调用）框架**，基于 HTTP/2 和 Protocol Buffers（protobuf），在微服务、服务间通信场景中广泛使用。

**核心定位**：
- 基于 HTTP/2：多路复用、头部压缩、双向流
- 默认使用 protobuf 序列化：二进制、紧凑、强类型
- 支持多种语言：Go、Java、Python、C++ 等，通过 `.proto` 定义接口即可生成各语言代码


## 三、与 REST/HTTP JSON 对比

| 维度       | gRPC                      | REST (如 Gin)              |
|------------|---------------------------|----------------------------|
| 协议       | HTTP/2                    | 通常 HTTP/1.1              |
| 数据格式   | 二进制 protobuf           | 常见 JSON/XML              |
| 接口定义   | .proto 强类型             | 文档或约定                 |
| 流式       | 原生支持 4 种 RPC 类型    | 需 SSE/WebSocket 等        |
| 浏览器     | 需 gRPC-Web 等            | 直接支持                   |
| 性能/压缩  | 高、头部与 body 均压缩     | 相对较低                   |
