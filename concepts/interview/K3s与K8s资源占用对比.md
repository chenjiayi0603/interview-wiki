## 3.2 详细资源对比表

| 资源类型 | K3s | K8s | 说明 |

| **最小内存（Control Plane）** | 512MB | 2GB | K3s 包含完整 K8s API |
| **推荐内存（Control Plane）** | 1GB | 4GB | 生产环境建议 |

## 3.3 资源占用优化措施

**K3s 的优化策略：**
1. **Go 语言静态编译**：减少运行时依赖
2. **内置存储**：SQLite 替代 etcd，减少内存开销
3. **组件裁剪**：移除非必要的云提供商集成
4. **单进程设计**：减少进程间通信开销

**K8s 的资源优化建议：**
1. 使用 kubeadm 最小化安装
2. 选择合适的 etcd 部署模式
3. 合理配置 API Server 参数
4. 使用垂直 Pod 自动扩缩容（VPA）
