# MongoDB 与 MySQL 成本对比

表格对比了 MySQL 和 MongoDB 在不同资源项上的消耗及成本比。

| 资源项 | MySQL | MongoDB | 成本比 |
|--------|--------|---------|--------|
| 集群数/分片数 | 64×4=256 套 | 4 | 无意义 |
| CPU 总数 | 4×256=1024 | 16×4=64 | **16:1** |
| 内存总数 | 16×256=4096G | 64×4=256G | **16:1** |
| 磁盘（主节点） | 约 30×4=120T | 约 9×4=36T | **3.3:1** |

在相同业务规模下，MongoDB 在 CPU、内存、磁盘上的资源消耗均显著低于 MySQL，成本比分别为 16:1、16:1、3.3:1。
