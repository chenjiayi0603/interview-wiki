# 低延迟高频交易系统硬件层优化

## 2.1 CPU 缓存优化

### 缓存层级与访问延迟

```cpp
// 缓存层级（典型 Intel Xeon 处理器）
// L1: 32KB, ~1ns (3-4 cycles)
// L2: 256KB, ~4ns (10-12 cycles)  
// L3: 25MB, ~15ns (40-50 cycles)
// DRAM: ~100ns (300+ cycles)
```

### 缓存行对齐 (Cache Line Alignment)

```cpp
#include <new>

// 缓存行大小通常为 64 字节
constexpr size_t CACHE_LINE_SIZE = 64;

// 结构体对齐到缓存行边界
struct alignas(CACHE_LINE_SIZE) Order {
    uint64_t order_id;      // 8 bytes
    uint64_t price;         // 8 bytes
    uint32_t quantity;      // 4 bytes
    uint32_t symbol_id;     // 4 bytes
    char side;              // 1 byte
    char padding[39];       // 填充至 64 字节，避免伪共享
};

// 使用 __attribute__((aligned(64))) 在 GCC/Clang
struct __attribute__((aligned(64))) AlignedOrder {
    // ...
};
```

### 伪共享 (False Sharing) 避免

```cpp
// ❌ 错误：多个线程修改同一缓存行的不同字段
struct SharedCounter {
    std::atomic<uint64_t> counter_a;  // Thread A 修改
    std::atomic<uint64_t> counter_b;  // Thread B 修改
    // 两个原子变量在同一缓存行，导致缓存一致性流量
};

// ✅ 正确：每个变量独占一个缓存行
struct alignas(64) PaddedCounter {
    std::atomic<uint64_t> value;
    char padding[64 - sizeof(std::atomic<uint64_t>)];
};

PaddedCounter counter_a;
PaddedCounter counter_b;  // 确保在不同缓存行
```

### 预取指令 (Prefetch)

```cpp
#include <xmmintrin.h>

// 软件预取，提前加载数据到缓存
void process_orders(Order* orders, size_t n) {
    constexpr size_t PREFETCH_DISTANCE = 8;
    
    for (size_t i = 0; i < n; ++i) {
        // 预取未来要访问的数据
        if (i + PREFETCH_DISTANCE < n) {
            _mm_prefetch(
                reinterpret_cast<const char*>(&orders[i + PREFETCH_DISTANCE]),
                _MM_HINT_T0  // 加载到 L1 缓存
            );
        }
        process(orders[i]);
    }
}
```

## 2.2 NUMA 架构优化

```cpp
#include <numa.h>
#include <sched.h>

// NUMA (Non-Uniform Memory Access) 优化
class NumaOptimizer {
public:
    // 绑定到特定 NUMA 节点
    static void bind_to_numa_node(int node) {
        numa_run_on_node(node);
        numa_set_preferred(node);
    }
    
    // 在本地 NUMA 节点分配内存
    static void* allocate_local(size_t size, int node) {
        return numa_alloc_onnode(size, node);
    }
    
    // 获取当前线程所在 NUMA 节点
    static int get_current_numa_node() {
        int cpu = sched_getcpu();
        return numa_node_of_cpu(cpu);
    }
};
```

## 2.3 CPU 亲和性 (CPU Affinity)

```cpp
#include <sched.h>
#include <pthread.h>

// 绑定线程到特定 CPU 核心，避免上下文切换
void set_thread_affinity(int cpu_id) {
    cpu_set_t cpuset;
    CPU_ZERO(&cpuset);
    CPU_SET(cpu_id, &cpuset);
    
    pthread_t thread = pthread_self();
    pthread_setaffinity_np(thread, sizeof(cpu_set_t), &cpuset);
}

// 隔离 CPU 核心（配合 isolcpus 内核参数）
// 启动参数: isolcpus=2,3 nohz_full=2,3 rcu_nocbs=2,3
```

## 2.4 禁用 CPU 节能模式

# 设置 CPU 为性能模式

# 禁用 Turbo Boost
