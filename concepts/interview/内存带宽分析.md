# 内存带宽分析

**内存带宽（Memory Bandwidth）**是指计算机系统在单位时间内可从内存（RAM）传输数据的最大速率，通常以 GB/s（千兆字节每秒）为单位。例如，内存带宽为 50GB/s，则意味着 CPU 或其他设备每秒最多可以从内存读取或写入 50GB 的数据。

## 内存带宽对高性能 C++ 系统的重要性

- **带宽瓶颈**：当应用程序需要访问大量数据时，若内存带宽不足，CPU 只能“等”内存数据，导致性能下降（常见于大数组、数据库、流处理等）。
- **与延迟区别**：带宽描述的是“吞吐量”，即总量多少；而延迟则是单次访问需要多长时间。两者都很关键，但高带宽更适合大规模数据并行处理场景。
- **优化与观测**：现代处理器通常拥有远高于单核的理论内存带宽，因此并发访问和内存访问模式非常重要——比如顺序访问远快于随机访问，可提升缓存命中率和带宽利用率。

## 内存带宽测试工具

### stream 工具

stream 工具就是用来测试主机“极限内存带宽（Peak Bandwidth）”的。

```bash
# 下载 stream 源码
wget https://www.cs.virginia.edu/stream/FTP/Code/stream.c

# 编译
gcc -O3 -fopenmp -DSTREAM_ARRAY_SIZE=80000000 -DNTIMES=10 stream.c -o stream

# 运行
./stream
```

输出结果中 Copy、Scale、Add、Triad 算法的 MB/s，就是该机器实际能达到的最大内存带宽（真实极限值），比 lscpu 理论值更贴近实际性能。

### VTune Memory Access 分析

```
vtune -collect memory-access -result-dir ./mem_bw -- ./your_program
```

VTune 只能观测某次运行的“瞬时/实际带宽利用率”，不能直接测试平台的绝对峰值带宽上限。

## 内存带宽一般多少？举例内存选型

| 内存类型   | 通道数   | 单条频率         | 理论总带宽               |
|------------|----------|------------------|--------------------------|
| DDR4-2666  | 双通道   | 2666 MT/s        | ~42.6 GB/s（21.3×2）     |
| DDR4-3200  | 四通道   | 3200 MT/s        | ~102.4 GB/s（25.6×4）    |
| DDR5-4800  | 双通道   | 4800 MT/s        | ~76.8 GB/s（38.4×2）     |
| DDR5-5600  | 四通道   | 5600 MT/s        | ~179.2 GB/s（44.8×4）    |
| DDR5-7200  | 双通道   | 7200 MT/s        | ~115.2 GB/s（57.6×2）    |

说明：
- 单条 DDR4-3200 最大约 25.6 GB/s（按频宽×通道数）
- DDR5 理论带宽更高，同等通道下带宽大幅提升
- 实际带宽通常比理论值低 10~20%，受主板设计/负载分布影响

**内存选型建议举例：**
- 高频交易、数据库服务器等对带宽敏感场景，推荐 DDR5 四通道+高频条（如 5600/6400 以上）
- 典型 Web/普通服务器推荐 DDR4/DDR5 双通道、主流频率（3200/4800），注重容量性价比
- 科学计算、高性能计算节点，优先选择带宽更高的多通道/高频率 DDR5
