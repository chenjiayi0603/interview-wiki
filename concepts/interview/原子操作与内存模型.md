# 原子操作与内存模型

## std::atomic

```cpp
#include <atomic>

std::atomic<int> counter{0};

// 基本操作
counter.store(10);               // 写
int val = counter.load();        // 读
int old = counter.exchange(20);  // 交换

// 原子加减
counter.fetch_add(1);  // counter++
counter.fetch_sub(1);  // counter--
counter++;
counter--;
counter += 5;

// CAS操作
int expected = 10;
bool success = counter.compare_exchange_strong(expected, 20);
// 如果counter==expected，则设置为20并返回true
// 否则expected被更新为counter的当前值，返回false

// compare_exchange_weak可能虚假失败，需要在循环中使用
while (!counter.compare_exchange_weak(expected, expected + 1)) {
    // expected已被更新
}
```

## 内存序（Memory Order）

```cpp
// 内存序类型
enum memory_order {
    memory_order_relaxed,   // 最弱，只保证原子性
    memory_order_consume,   // 依赖序（已弃用）
    memory_order_acquire,   // 获取操作
    memory_order_release,   // 释放操作
    memory_order_acq_rel,   // acquire + release
    memory_order_seq_cst    // 最强，顺序一致性（默认）
};
```

### 内存序详解

```cpp
std::atomic<bool> ready{false};
std::atomic<int> data{0};

// 生产者
void producer() {
    data.store(42, std::memory_order_relaxed);
    ready.store(true, std::memory_order_release);
    // release保证之前的写操作在ready=true之前完成
}

// 消费者
void consumer() {
    while (!ready.load(std::memory_order_acquire)) {
        // 自旋等待
    }
    // acquire保证之后的读操作在ready==true之后执行
    int value = data.load(std::memory_order_relaxed);
    assert(value == 42);  // 保证成功
}
```

### 各内存序使用场景

| 内存序 | 说明 | 使用场景 |
|--------|------|----------|
| `relaxed` | 只保证原子性，无同步 | 计数器、统计信息 |
| `acquire` | 读操作，同步之后的读写 | 锁的获取、数据消费 |
| `release` | 写操作，同步之前的读写 | 锁的释放、数据发布 |
| `acq_rel` | 读-修改-写操作 | CAS操作 |
| `seq_cst` | 全局顺序一致 | 默认，最安全 |

### 自旋锁内存序示例

```cpp
class SpinLock {
    std::atomic<bool> locked{false};
    
public:
    void lock() {
        while (locked.exchange(true, std::memory_order_acquire)) {
            // exchange是读-修改-写，用acquire保证后续读写在锁之后
        }
    }
    
    void unlock() {
        locked.store(false, std::memory_order_release);
        // release保证之前的读写在解锁前完成
    }
};
```

## 原子标志 atomic_flag

```cpp
#include <atomic>

// atomic_flag是唯一保证无锁的原子类型
std::atomic_flag flag = ATOMIC_FLAG_INIT;

// test_and_set: 设置为true并返回旧值
bool was_set = flag.test_and_set(std::memory_order_acquire);

// clear: 设置为false
flag.clear(std::memory_order_release);

// C++20新增test()
bool current = flag.test(std::memory_order_relaxed);
```

## 原子指针

```cpp
std::atomic<int*> ptr{nullptr};

int* new_ptr = new int(42);
int* old_ptr = ptr.exchange(new_ptr);

// 指针算术
std::atomic<int*> arr_ptr;
arr_ptr++;           // 移动sizeof(int)字节
arr_ptr.fetch_add(2);  // 移动2*sizeof(int)字节
```
