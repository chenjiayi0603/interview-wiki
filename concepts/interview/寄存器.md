# 寄存器

> 本章节介绍 x86 架构下常见寄存器的分类、作用及在函数调用栈中的使用方式。

## 一、寄存器分类

| 类型 | 寄存器 | 主要作用 |
|------|----------|-----------|
| 数据寄存器 | EAX、EBX、ECX、EDX | 存放运算数与结果，可分16位和8位子寄存器 |
| 变址寄存器 | ESI、EDI | 存放数组、字符串的偏移量，用于索引寻址 |
| 指针寄存器 | EBP、ESP | EBP为栈底指针；ESP为栈顶指针，用于函数调用栈 |
| 段寄存器 | CS、DS、ES、SS、FS、GS | 存放当前使用的内存段选择子 |
| 指令指针寄存器 | EIP | 存放下一条要执行的指令地址 |
| 标志寄存器 | EFlags | 保存运算结果与控制状态，如CF、ZF、SF、OF等 |

## 二、主要寄存器说明

- **EAX（累加器）**：算术运算默认寄存器
- **EBX（基址寄存器）**：常用于存放内存基地址
- **ECX（计数寄存器）**：循环、移位操作中的计数器
- **EDX（数据寄存器）**：用于乘除法中的扩展结果或I/O端口

## 三、堆栈与函数调用

```asm
push ebp
mov  ebp, esp
sub  esp, xxx
...
mov  esp, ebp
pop  ebp
ret
```

## 四、标志寄存器常用位

| 标志位 | 含义      |
| :-- | :------ |
| CF  | 进位标志    |
| ZF  | 零标志     |
| SF  | 符号标志    |
| OF  | 溢出标志    |
| PF  | 奇偶标志    |
| IF  | 中断允许    |
| DF  | 字符串方向控制 |
