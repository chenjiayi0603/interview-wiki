# 数据库语言分类（SQL 四大子语言）

数据库语言（SQL语言，Database Language，DBL），是数据库管理和操作的专用语言体系。通常包括：
- **数据定义语言（DDL）**
- **数据操作语言（DML）**
- **数据控制语言（DCL）**
- **事务控制语言（TCL）**

> **SQL = DDL + DML + DCL + TCL**

## 1. 数据定义语言（DDL, Data Definition Language）

用于定义和管理数据库结构、对象等，如：
- `CREATE` 创建表、视图、索引等
- `ALTER` 修改结构
- `DROP` 删除对象

## 2. 数据操作语言（DML, Data Manipulation Language）

查询和修改数据内容，如：
- `SELECT`、`INSERT`、`UPDATE`、`DELETE`

## 3. 数据控制语言（DCL, Data Control Language）

控制数据库访问权限、用户安全，如：
- `GRANT` 授权
- `REVOKE` 回收权限

## 4. 事务控制语言（TCL, Transaction Control Language）

控制事务提交和回滚，如：
- `COMMIT` 提交事务
- `ROLLBACK` 回滚
- `SAVEPOINT` 设置保存点
