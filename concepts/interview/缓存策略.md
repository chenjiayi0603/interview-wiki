# 缓存策略

## 一、LRU缓存

### 1. 手写LRU实现
```cpp
// 手写LRU实现
template<typename K, typename V>
class LRUCache {
    struct Node {
        K key;
        V value;
        Node* prev;
        Node* next;
    };
    unordered_map<K, Node*> cache;
    Node* head;  // 伪头部
    Node* tail;  // 伪尾部
    int capacity;
    
public:
    V get(K key) {
        if (cache.count(key)) {
            moveToHead(cache[key]);
            return cache[key]->value;
        }
        return V{};
    }
    
    void put(K key, V value) {
        if (cache.count(key)) {
            cache[key]->value = value;
            moveToHead(cache[key]);
        } else {
            Node* node = new Node{key, value};
            cache[key] = node;
            addToHead(node);
            if (cache.size() > capacity) {
                Node* removed = removeTail();
                cache.erase(removed->key);
                delete removed;
            }
        }
    }
};
```

## 三、Redis缓存策略
- **Allkeys-LRU**：所有key，最近最少使用
- **Volatile-LRU**：设置过期时间，最近最少使用
- **Allkeys-Random**：随机淘汰
- **Volatile-TTL**：最近过期优先
- **Noeviction**：不淘汰
