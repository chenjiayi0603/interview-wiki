# 编译器优化选项

编译器优化选项通过多种技术提升生成二进制程序的执行速度、减少体积或降低能耗。其主要实现方式包括：

- **指令选择与重排序**：编译器根据目标平台选择更高效的指令，并调整指令顺序以减少流水线停顿和分支延迟。

- **寄存器分配优化**：减少对内存的访问，提升寄存器利用率，尤其是在 `-O2`/`-O3` 下更明显。

- **循环相关优化**：
  - 循环展开（`-funroll-loops`）：将循环体复制多份，减少循环判断与跳转次数，提升流水线效率。
  - 循环向量化（自动SIMD）：将相同操作批量并行处理，充分利用CPU SIMD指令集。

- **内联函数（`-finline-functions`）**：将频繁调用的小函数直接嵌入调用点，避免函数调用开销，增强进一步优化机会。

- **死代码消除**：删除永远不会执行的代码和永远不会用到的数据，减少代码冗余。

- **常量传播和表达式优化**：对于编译期可知的变量和表达式直接在编译时进行替换与计算，减少运行时开销。

- **内存访问优化**：通过提升数据局部性、调整内存布局、合并相邻内存操作等，减少缓存未命中，提高缓存命中率。

- **分支预测提示与消除冗余分支**：通过分支概率推断和代码转换，提升分支预测准确率，避免分支失误带来的性能损失。

- **特定硬件指令集利用**：如 `-march=native`，编译器根据本机CPU支持的特性（比如AVX/FMA/特定流水线结构），启用专有快速指令或自动SIMD优化。

- **链接时优化（LTO）**：跨文件优化，将所有目标文件统一分析后执行全局优化，使得函数内联、常量合并等优化更彻底。

**小结**：
合理组合和使用编译器优化选项，能让程序自动获得基础~高级的性能提升，无需手动改动源代码细节，是高性能应用开发的重要基础。

**GCC/Clang 优化选项**：

```bash
# 最高优化级别
-O3 -march=native -mtune=native

# 链接时优化（LTO）
-flto -fuse-linker-plugin

# 特定优化
-ffast-math          # 快速数学运算（可能损失精度）
-funroll-loops       # 循环展开
-finline-functions   # 内联函数
-fomit-frame-pointer # 省略帧指针（节省寄存器）

# 完整优化命令示例
g++ -O3 -march=native -mtune=native -flto \
    -ffast-math -funroll-loops \
    -fomit-frame-pointer \
    -DNDEBUG \
    -o program program.cpp
```

**完整示例：不同优化级别性能对比**：

```cpp
// optimize_levels.cpp - 演示不同优化级别的性能差异
#include <iostream>
#include <chrono>
#include <vector>
#include <cmath>

double dot_product(const std::vector<double>& a, const std::vector<double>& b) {
    double result = 0.0;
    for (size_t i = 0; i < a.size(); ++i) {
        result += a[i] * b[i];
    }
    return result;
}

double math_intensive(double x, int iterations) {
    double result = x;
    for (int i = 0; i < iterations; ++i) {
        result = std::sin(result) * std::cos(result) + std::sqrt(std::abs(result));
    }
    return result;
}

long long loop_intensive(int n) {
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            sum += i * j;
        }
    }
    return sum;
}

int main() {
    const int RUNS = 100;
    const int SIZE = 100000;
    
    std::vector<double> vec_a(SIZE), vec_b(SIZE);
    for (int i = 0; i < SIZE; ++i) {
        vec_a[i] = static_cast<double>(i) * 0.001;
        vec_b[i] = static_cast<double>(i) * 0.002;
    }
    
    auto start = std::chrono::high_resolution_clock::now();
    double dot_result = 0;
    for (int r = 0; r < RUNS; ++r) {
        dot_result = dot_product(vec_a, vec_b);
    }
    auto end = std::chrono::high_resolution_clock::now();
    auto duration1 = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    start = std::chrono::high_resolution_clock::now();
    double math_result = 0;
    for (int r = 0; r < RUNS; ++r) {
        math_result = math_intensive(1.5, 10000);
    }
    end = std::chrono::high_resolution_clock::now();
    auto duration2 = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    start = std::chrono::high_resolution_clock::now();
    long long loop_result = 0;
    for (int r = 0; r < RUNS; ++r) {
        loop_result = loop_intensive(1000);
    }
    end = std::chrono::high_resolution_clock::now();
    auto duration3 = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
    
    std::cout << "=== 编译优化级别测试 ===" << std::endl;
    std::cout << "向量点积耗时: " << duration1.count() << " 微秒" << std::endl;
    std::cout << "数学运算耗时: " << duration2.count() << " 微秒" << std::endl;
    std::cout << "循环计算耗时: " << duration3.count() << " 微秒" << std::endl;
    
    std::cout << "结果: " << dot_result << ", " << math_result << ", " << loop_result << std::endl;
    
    return 0;
}
```

**编译并对比不同优化级别**：

```bash
# 无优化
g++ -O0 -o opt_O0 optimize_levels.cpp
./opt_O0

# 基本优化
g++ -O2 -o opt_O2 optimize_levels.cpp
./opt_O2

# 最高优化
g++ -O3 -march=native -o opt_O3 optimize_levels.cpp
./opt_O3

# 最高优化 + 快速数学
g++ -O3 -march=native -ffast-math -funroll-loops -o opt_O3_fast optimize_levels.cpp
./opt_O3_fast

# 典型输出对比示例：
# -O0: 向量点积 850000μs, 数学运算 420000μs, 循环 650000μs
# -O2: 向量点积 120000μs, 数学运算 180000μs, 循环 85000μs  
# -O3: 向量点积 45000μs,  数学运算 150000μs, 循环 35000μs
# -O3 + fast-math: 向量点积 42000μs, 数学运算 35000μs, 循环 35000μs
```

**关键优化说明**：
- **-O3**：最高优化级别，包括向量化
- **-march=native**：针对当前 CPU 架构优化
- **-flto**：链接时优化，跨文件优化
- **-ffast-math**：快速数学（交易系统慎用，可能影响精度）
