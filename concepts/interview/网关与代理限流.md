# 网关与代理限流

## 通过 iptables 限流
### 限制 TCP 连接数量和频率（每客户端 IP，对接 nginx / 网关）
- Access 对应 nginx，api 对应 nginx 可分开处理。
- 同一 IP 并发与新建速度示例：
  - 60 秒内 5 个新连接，超出丢弃：
    ```
    iptables -A INPUT -p tcp --dport 80 --syn -m recent --name webpool --rcheck --seconds 60 --hitcount 5 -j DROP
    ```
  - 最大并发 10，超出丢弃：
    ```
    iptables -A INPUT -p tcp --dport 80 -m connlimit --connlimit-above 10 -j DROP
    ```

### 网关 API（高配示例）
- 1 秒 10000 个新连接，超出丢弃：
  ```
  iptables -A INPUT -p tcp --dport 80 --syn -m recent --name webpool --rcheck --seconds 1 --hitcount 10000 -j DROP
  ```
- 最大并发 20000，超出丢弃：
  ```
  iptables -A INPUT -p tcp --dport 80 -m connlimit --connlimit-above 20000 -j DROP
  ```

## Nginx 限流
### HTTP 限流（对接 API 网关：连接数 / 带宽 / QPS）
- 基础容量
  ```
  worker_rlimit_nofile 65535;
  events {
      use epoll;
      worker_connections 65535;
  }
  ```
- 并发连接
  ```
  http {
      limit_conn_zone $binary_remote_addr zone=perip:10m;   # 约16万
      limit_conn_zone $server_name        zone=perserver:10m;
      ...
      server {
          listen 80;
          server_name www.abc.com;
          location / {
              limit_conn perip 20000;      # 每 IP 连接数
              limit_conn perserver 65535;  # 每 server 连接数
              #limit_rate 1000k;          # 每连接下行限速（如需）
          }
      }
  }
  ```
- 访问频率（每客户端 IP）
  ```
  http {
      # 写请求频率 5000 r/s，突发 5000
      limit_req_zone $binary_remote_addr $uri zone=api_write:20m rate=5000r/s;
      #limit_req_zone $binary_remote_addr $uri zone=api_read:20m rate=5000r/s;
      server {
          location = / {        # /api/v1/trade
              limit_req zone=api_write burst=5000;
              proxy_pass http://api_server;
          }
          #location /api/v1/query {
          #    limit_req zone=api_read burst=50;
          #    proxy_pass http://api_server;
          #}
      }
  }
  ```
- 变量说明
  - `$binary_remote_addr`：按客户端 IP 限制；1m 区域约存 16000 状态，耗尽则关连接。
  - `$server_name`：按 server 并发限制。
  - `limit_rate`：按连接限速；同一 IP 多连接则速率叠加。

### TCP 限流（对接 access 网关：连接数 / 带宽）
- 基础容量
  ```
  worker_rlimit_nofile 65535;
  events {
      use epoll;
      worker_connections 65535;
  }
  stream {
      limit_conn_zone $binary_remote_addr zone=perip:10m;  # 约16万
      server {
          ...
          limit_conn perip 5;   # 每 IP 并发连接
      }
  }
  ```
- 变量说明
  - `$binary_remote_addr`：按客户端 IP 限制，1m 区域约 16000 状态，耗尽则关连接。
- 带宽
  ```
  server {
      ...
      #proxy_download_rate 200k;  # 每连接下行
      proxy_upload_rate   200k;   # 每连接上行
  }
  ```

## Access 限流
### 访问频率（每连接）
- Nginx 无法做细粒度 TCP 频控，Access 负责补充，可与 nginx 同时启用（前置规则应更宽）。
- 支持：
  - 单连接总上传次数/秒；
  - 指定消息类型（如命令字 4501）次数/秒；
  - 超限记录本地日志、cat 日志。

## 总体策略
- 顺序：iptables ＞ nginx ＞ access；若多层并存，前层阈值应宽于后层。
- 关注：每 IP 连接总量、每秒新建连接量、单连接消息频率，Access 超限需记录日志便于排查。
