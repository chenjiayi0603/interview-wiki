# 进程与线程内存区别

## 核心概念对比

| 特性 | 进程内存 | 线程内存 |
|------|---------|---------|
| **定义** | 进程拥有的完整虚拟地址空间 | 线程拥有的私有内存区域 |
| **隔离性** | 进程间完全隔离，互不干扰 | 线程间共享进程地址空间 |
| **内存区域** | 代码段、数据段、BSS段、堆、栈、共享库等 | 主要是线程私有栈和线程局部存储（TLS） |
| **寄存器** | 进程切换时保存/恢复所有寄存器 | 线程切换时保存/恢复寄存器上下文 |
| **创建开销** | 较大（需要创建新的地址空间） | 较小（共享进程地址空间） |
| **通信方式** | 进程间通信（IPC）：管道、共享内存、消息队列等 | 共享内存（需要同步机制） |

## 进程内存的组成

进程内存包括进程的完整虚拟地址空间，所有线程共享这些区域：

- **代码段（Text Segment）**：所有线程共享同一份代码段
- **数据段和 BSS 段**：全局变量和静态变量，所有线程共享
- **堆（Heap）**：malloc/new 分配的内存，所有线程共享
- **进程主栈（Main Stack）**：进程的主线程拥有主栈

## 线程内存的组成

每个线程拥有自己的私有内存区域：

### 1. 线程私有栈（Thread Stack）

每个线程有自己独立的栈，用于存储局部变量、函数参数、返回地址等。不同线程的栈完全隔离，线程 A 无法直接访问线程 B 的栈变量。

### 2. 线程局部存储（Thread Local Storage, TLS）

C++11 的 `thread_local` 关键字声明的变量，每个线程有自己独立的副本。

### 3. 线程寄存器上下文

每个线程有自己独立的寄存器集合，包括通用寄存器、栈指针（rsp）、指令指针（rip）、标志寄存器、浮点寄存器等。线程切换时保存/恢复这些寄存器状态。

### 4. 线程控制块（Thread Control Block, TCB）

每个线程都有一个线程控制块，用于存储线程的元数据和状态信息：
- 线程标识（TID、pthread_t）
- 执行上下文（栈基址、栈大小、栈保护区域）
- 寄存器上下文
- 线程属性（分离状态、调度策略、优先级）
- 信号掩码（线程私有）
- 线程局部存储数组
- 取消状态
- 错误码（errno，某些系统）
- 浮点状态
- 线程特定数据（pthread_setspecific/getspecific）
- 同步原语状态
- 资源限制

### 5. 信号掩码（Signal Mask）

每个线程有自己独立的信号掩码，使用 `pthread_sigmask()` 设置。一个线程阻塞某个信号，不影响其他线程接收该信号。

## 信号处理的共享与私有规则

| 信号处理组件 | 共享/私有 | 说明 |
|------------|---------|------|
| **信号处理函数（Handler）** | **进程级共享** | 所有线程共享同一个信号处理函数 |
| **信号掩码（Signal Mask）** | **线程级私有** | 每个线程有独立的信号掩码 |
| **信号挂起队列（Pending Signals）** | **混合** | 进程级挂起 + 线程级挂起 |
| **信号动作（Signal Action）** | **进程级共享** | sigaction 设置对所有线程生效 |

### 信号传递规则

- **`kill(pid, sig)` - 发送给进程**：信号进入进程级挂起队列，系统选择任意一个未阻塞该信号的线程来处理，只有一个线程会处理这个信号。
- **`pthread_kill(tid, sig)` - 发送给线程**：信号进入目标线程的线程级挂起队列，如果目标线程未阻塞则立即处理，如果阻塞则挂起直到解除阻塞。

### 关键要点

1. 信号处理函数是进程级共享的：所有线程使用同一个处理函数
2. 信号掩码是线程级私有的：每个线程可以有不同的信号掩码
3. 信号传递规则：信号会传递给任意一个未阻塞该信号的线程
4. 信号挂起：被阻塞的信号会挂起在进程级或线程级队列中
5. 继承规则：新线程继承进程的信号处理函数和创建线程的信号掩码
6. 阻塞信号 ≠ 禁用信号处理函数，阻塞信号 = 延迟信号处理，信号被挂起
7. 信号处理函数只在一个线程中执行，不是所有未阻塞的线程都执行

## 内存布局对比

### 单进程单线程
```
进程虚拟地址空间
┌─────────────────────────────────────┐
│ 内核空间 (Kernel Space)              │
├─────────────────────────────────────┤
│ 栈 (Stack) - 主线程                  │
├─────────────────────────────────────┤
│ 内存映射段 (Memory Mapping)          │
├─────────────────────────────────────┤
│ 堆 (Heap)                            │
├─────────────────────────────────────┤
│ BSS 段                               │
├─────────────────────────────────────┤
│ 数据段 (Data Segment)                 │
├─────────────────────────────────────┤
│ 代码段 (Text Segment)                │
└─────────────────────────────────────┘
```

### 单进程多线程
```
进程虚拟地址空间（所有线程共享）
┌─────────────────────────────────────┐
│ 内核空间 (Kernel Space)              │
├─────────────────────────────────────┤
│ 栈 (Stack) - 线程 3                 │ ← 线程 3 私有
├─────────────────────────────────────┤
│ 栈 (Stack) - 线程 2                 │ ← 线程 2 私有
├─────────────────────────────────────┤
│ 栈 (Stack) - 线程 1                 │ ← 线程 1 私有
├─────────────────────────────────────┤
│ 栈 (Stack) - 主线程                  │ ← 主线程私有
├─────────────────────────────────────┤
│ 内存映射段 (Memory Mapping)          │ ← 所有线程共享
├─────────────────────────────────────┤
│ 堆 (Heap)                            │ ← 所有线程共享
├─────────────────────────────────────┤
│ BSS 段                               │ ← 所有线程共享
├─────────────────────────────────────┤
│ 数据段 (Data Segment)                 │ ← 所有线程共享
├─────────────────────────────────────┤
│ 代码段 (Text Segment)                │ ← 所有线程共享
└─────────────────────────────────────┘
```

## 关键区别总结

| 内存区域 | 进程级别 | 线程级别 |
|---------|---------|---------|
| 代码段 | 进程私有（但可共享） | 所有线程共享 |
| 数据段/BSS | 进程私有 | 所有线程共享 |
| 堆 | 进程私有 | 所有线程共享 |
| 栈 | 进程主栈 | 每个线程有独立栈 |
| TLS | 不支持 | 每个线程有独立副本 |
