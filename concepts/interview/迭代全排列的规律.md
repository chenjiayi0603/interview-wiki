# 迭代全排列的规律

## 下一个排列

实现获取 下一个排列 的函数，算法需要将给定数字序列重新排列成字典序中下一个更大的排列。如果不存在下一个更大的排列，则将数字重新排列成最小的排列（即升序排列）。

必须 原地 修改，只允许使用额外常数空间。

**示例**：
- 输入：nums = [1,2,3] → 输出：[1,3,2]
- 输入：nums = [3,2,1] → 输出：[1,2,3]
- 输入：nums = [1,1,5] → 输出：[1,5,1]
- 输入：nums = [1] → 输出：[1]

**算法思路**：
1. 从右向左找到第一个升序对 `(pre, cur)` 满足 `*pre < *cur`
2. 从右向左找到第一个大于 `*pre` 的元素 `*cur`
3. 交换 `*pre` 和 `*cur`
4. 反转 `pre+1` 到末尾（使后缀变为升序）

```cpp
class Solution {
public:
    void nextPermutation(vector<int>& nums) {
        auto cur = nums.end() - 1, pre = cur - 1;
        while(cur > nums.begin() && *pre >= *cur) cur--, pre--;
        if(cur <= nums.begin()) { reverse(nums.begin(), nums.end()); return; }
        for(cur = nums.end() - 1; *cur <= *pre; cur--);
        swap(*cur, *pre);
        reverse(pre + 1, nums.end());
    }
};
```

## 下一个更大元素 III

给定一个 32 位正整数 n，你需要找到下一个同样由数字组成且更大的整数。如果不存在，返回 -1。

**算法思路**：
- 将 n 转为字符串，使用 `next_permutation` 找到下一个排列，比较大小即可。

```cpp
class Solution {
public:
    static bool next_permutation(string::iterator start, string::iterator end) {
        auto cur = end - 1, pre = cur - 1;
        while(cur > start && *pre >= *cur) cur--, pre--;
        if(cur <= start) return false;
        for(cur = end - 1; *cur <= *pre; cur--);
        swap(*cur, *pre);
        reverse(pre + 1, end);
        return true;
    }
    int nextGreaterElement(int n) {
        string s = to_string(n);
        sort(s.begin(), s.end());
        while(next_permutation(s.begin(), s.end())) {
            int tmp = atoll(s.c_str());
            if (tmp > n) return tmp;
        }
        return -1;
    }
};
```

## 第k个排列

给出集合 [1,2,3,...,n]，其所有元素共有 n! 种排列。按大小顺序列出所有排列情况，给定 n 和 k，返回第 k 个排列。

**示例**：
- n = 3, k = 3 → "213"
- n = 4, k = 9 → "2314"
- n = 3, k = 1 → "123"

### 简单方法（调用 next_permutation）

```cpp
class Solution {
public:
    string getPermutation(int n, int k) {
        string s;
        for (int i = 1; i <= n; ++i) s += '0' + i;
        for (int i = 0; i < k - 1; ++i)
            next_permutation(s.begin(), s.end());
        return s;
    }
};
```

复杂度 O(k * n)，当 k 很大时效率低。

### 高效方法（数学推导）

**思路**：
- 以 n=6, k=373 为例：
  1. 以 1 开头的全排列有 5! 个，以 2 开头的有 5! 个……共 6! 个
  2. 第一个数字应为 nums[k / 5!] = 4
  3. 删除 4，k = k % 5! = 12
  4. 重复上述步骤

```cpp
class Solution {
public:
    string getPermutation(int n, int k) {
        vector<int> permutation(n, 1);
        for (int i = 1; i < n; ++i) {
            permutation[i] = permutation[i - 1] * i;
        }
        string digits = "123456789";
        string res;
        for (int i = n - 1; i > 0; i--) {
            int t = (k - 1) / permutation[i];
            res.push_back(digits[t]);
            digits.erase(digits.begin() + t);
            k = k - t * permutation[i];
        }
        res.push_back(digits[k - 1]);
        return res;
    }
};
```

复杂度 O(n²)。
