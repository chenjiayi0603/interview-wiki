# 内存分析工具

## 1. Valgrind Massif（堆内存分析）

用于分析程序的堆内存使用峰值、增长点，定位内存占用热点。

**示例：检测堆内存使用高峰**
```bash
valgrind --tool=massif ./program
ms_print massif.out.*    # 生成详细内存分布报告
```

## 2. 常用系统工具（进程内存监控）

用于实时或离线查看进程各类内存用量、映射详情。

**示例：**
- **查看指定进程内存：**
  ```bash
  ps aux | grep program           # 查找进程
  top -p $(pidof program)         # 实时动态监控
  htop -p $(pidof program)        # 更友好视图

  # 查看详细内存映射
  cat /proc/$(pidof program)/maps
  pmap -x $(pidof program)

  # 查看内存使用统计
  cat /proc/$(pidof program)/status | grep -i mem
  ```

## 3. 内存泄漏检测（Sanitizer类工具）

用于发现和定位 C++ 程序的内存越界、非法访问和泄漏问题。

### （1）AddressSanitizer（ASan）
- **检测示例：**
  ```cpp
  // 代码存在数组越界或非法访问
  int* arr = new int[10];
  arr[10] = 42; // 错误：越界写
  delete[] arr;
  ```
  - 编译并运行：
    ```bash
    g++ -fsanitize=address -g -O1 program.cpp
    ./a.out
    ```

### （2）LeakSanitizer
- **检测示例：**
  ```cpp
  // 代码存在内存泄漏
  void foo() { int* p = new int(1); } // 忘记释放p
  ```
  - 编译并运行：
    ```bash
    g++ -fsanitize=leak -g program.cpp
    ./a.out
    ```
