## 8.1 高并发压力测试

### Q27: 如何设计高并发、burst场景的压力测试？

**答案：**
高并发/突发场景的压力测试设计思路：

1. **模拟真实订单流量：**
   - 构造高并发线程池或协程，每个线程持续、频繁地产生订单或请求，尽可能模拟真实市场的订单流和突发流量（burst）。
   - 设置不同的工作负载，例如持续负载和瞬时高峰。

2. **指标采集与监控：**
   - 统计TPS（每秒事务量）、平均和分位延迟（如p99, p999）、成功率、失败率等。
   - 监控资源占用（CPU、内存、网络IO等）。

3. **发现系统瓶颈与极限：**
   - 逐步提升压力，观察系统在哪些条件下延迟陡升或出现丢单、阻塞等异常，确定系统极限能力。

4. **常见技术实现：**
   - 使用多线程或协程模拟高并发，所有线程同时启动，确保burst时刻的压测真实可控。
   - 支持参数化配置（线程数、订单总数、突发批量、速率限制等）。
   - 精确测量和记录每个请求的响应时间。

5. **检测系统恢复与稳定性：**
   - 压测结束后观测系统是否能快速恢复至正常状态，有无内存泄漏、线程死锁等隐患。

**简单C++实现伪代码（见下方示例StressTest类）：**
- continuousLoadTest: 模拟长时间高并发负载。
- burstTest: 线程同步、突发式地批量发单，观察系统瞬时表现。

压力测试不仅关注吞吐极限，更要关注 p99/p999 延迟和极端情况下的稳定性。

```cpp
#include <thread>
#include <atomic>
#include <chrono>

class StressTest {
    std::atomic<uint64_t> total_orders{0};
    std::atomic<uint64_t> success_count{0};
    std::atomic<uint64_t> fail_count{0};
    
public:
    // 1. 持续高并发测试
    void continuousLoadTest(int duration_seconds, int threads) {
        std::vector<std::thread> workers;
        auto start = std::chrono::steady_clock::now();
        
        for (int i = 0; i < threads; ++i) {
            workers.emplace_back([this, duration_seconds, start] {
                while (true) {
                    auto now = std::chrono::steady_clock::now();
                    auto elapsed = std::chrono::duration_cast<std::chrono::seconds>(
                        now - start).count();
                    if (elapsed >= duration_seconds) break;
                    
                    // 发送订单
                    if (sendOrder()) {
                        success_count++;
                    } else {
                        fail_count++;
                    }
                    total_orders++;
                }
            });
        }
        
        for (auto& t : workers) {
            t.join();
        }
        
        report();
    }
    
    // 2. Burst场景测试
    void burstTest(int burst_size, int threads) {
        std::vector<std::thread> workers;
        
        // 同时启动所有线程，模拟突发流量
        for (int i = 0; i < threads; ++i) {
            workers.emplace_back([this, burst_size] {
                for (int j = 0; j < burst_size; ++j) {
                    sendOrder();
                    total_orders++;
                }
            });
        }
        
        for (auto& t : workers) {
            t.join();
        }
        
        report();
    }
    
    // 3. 阶梯式压力测试
    void stepLoadTest(int max_threads, int step_size, int step_duration) {
        for (int threads = step_size; threads <= max_threads; threads += step_size) {
            std::cout << "Testing with " << threads << " threads..." << std::endl;
            
            std::vector<std::thread> workers;
            auto start = std::chrono::steady_clock::now();
            
            for (int i = 0; i < threads; ++i) {
                workers.emplace_back([this, step_duration, start] {
                    while (true) {
                        auto now = std::chrono::steady_clock::now();
                        auto elapsed = std::chrono::duration_cast<std::chrono::seconds>(
                            now - start).count();
                        if (elapsed >= step_duration) break;
                        
                        sendOrder();
                        total_orders++;
                    }
                });
            }
            
            for (auto& t : workers) {
                t.join();
            }
            
            report();
            std::this_thread::sleep_for(std::chrono::seconds(5));  // 休息5秒
        }
    }
    
    bool sendOrder() {
        // 发送订单逻辑
        Order order = generateRandomOrder();
        return trading_engine.submitOrder(order);
    }
    
    void report() {
        std::cout << "Total Orders: " << total_orders << std::endl;
        std::cout << "Success: " << success_count << std::endl;
        std::cout << "Failed: " << fail_count << std::endl;
        std::cout << "Success Rate: " << 
            (double)success_count / total_orders * 100 << "%" << std::endl;
    }
};
```

#### Q28: 如何保证系统在burst场景中的稳定性？

**答案：**

```cpp
class BurstStabilityManager {
public:
    // 1. 限流保护
    class RateLimiter {
        std::atomic<uint64_t> tokens{1000};
        std::chrono::steady_clock::time_point last_refill;
        uint64_t capacity;
        uint64_t refill_rate;  // tokens per second
        
    public:
        bool acquire() {
            refill();
            if (tokens > 0) {
                tokens--;
                return true;
            }
            return false;
        }
        
        void refill() {
            auto now = std::chrono::steady_clock::now();
            auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
                now - last_refill).count();
            uint64_t add = (elapsed * refill_rate) / 1000;
            tokens = std::min(capacity, tokens + add);
            last_refill = now;
        }
    };
    
    // 2. 背压机制
    class Backpressure {
        std::atomic<size_t> queue_size{0};
        size_t max_queue_size;
        
    public:
        bool canAccept() {
            return queue_size < max_queue_size;
        }
        
        void increment() {
            queue_size++;
        }
        
        void decrement() {
            queue_size--;
        }
    };
    
    // 3. 降级策略
    class CircuitBreaker {
        std::atomic<int> failure_count{0};
        std::atomic<bool> open{false};
        int threshold;
        
    public:
        bool isOpen() {
            return open.load();
        }
        
        void recordFailure() {
            if (failure_count++ > threshold) {
                open.store(true);
            }
        }
        
        void recordSuccess() {
            failure_count = 0;
            open.store(false);
        }
    };
    
    // 4. 监控和告警
    void monitor() {
        // 监控关键指标
        // - 队列长度
        // - 延迟
        // - 错误率
        // - 资源使用率
        
        if (queue_size > threshold) {
            // 触发告警
            sendAlert("Queue size exceeded threshold");
        }
    }
};
/*
代码说明：

上述 BurstStabilityManager 类用于高频交易系统中在 burst（突发）场景下保障系统稳定性，包含以下模块：

1. 限流保护 (RateLimiter)
   - 利用令牌桶算法，通过原子变量和定时补充令牌的方式，限制单位时间内订单或请求的处理速率，防止流量过载。

2. 背压机制 (Backpressure)
   - 通过限制内部队列长度，判断队列是否可接受新请求。超过最大容量时，自动开启背压，减缓系统压力。

3. 降级策略 (CircuitBreaker)
   - 实现熔断器模式。若短时间内错误率过高，自动熔断，暂停请求处理，防止雪崩和连锁故障，待恢复后自动关闭熔断。

4. 监控与告警
   - 实时监控队列长度、延迟、错误率等关键性能指标，若发现异常，及时触发告警，便于运维介入。

这些机制协同工作，可显著提升高并发突发下的交易系统韧性和稳定性，防止服务雪崩，有助于保障核心链路稳定运行，并在极端条件下实现平滑降级和自动恢复。

*/
```
