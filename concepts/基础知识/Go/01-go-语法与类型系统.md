## 一、基本语法

### 1.1 变量声明与类型推断

**解决的问题**：Go 提供多种变量声明方式，适应不同场景（简洁/显式/多变量）。

```go
// 显式声明
var name string = "Go"
// 类型推断
var version = 1.21
// 短变量声明（仅限函数内）
count := 42
// 多变量声明
var x, y int = 1, 2
a, b := "hello", true
```

**注意事项**：
- `:=` 左侧必须至少有一个新变量
- `var` 声明零值初始化（int=0, string="", bool=false, pointer=nil）
- 包级别变量不能用 `:=`

### 1.2 常量与 iota

**解决的问题**：编译期常量，避免魔法数字。

```go
const Pi = 3.14159
const MaxConnections = 1000

// iota —— 枚举常量生成器
const (
    StatusOK       = 0
    StatusNotFound
    StatusError
)

const (
    Read  = 1 << iota  // 1
    Write              // 2
    Execute            // 4
)
```

### 1.3 基本类型

| 类型 | 说明 | 零值 |
|:-----|:-----|:-----|
| `bool` | 布尔 | `false` |
| `int` / `uint` | 平台相关（32/64位） | `0` |
| `int8` ~ `int64` | 定长有符号整数 | `0` |
| `float32` / `float64` | 浮点数 | `0.0` |
| `string` | 不可变 UTF-8 字符串 | `""` |
| `byte` (= `uint8`) | 字节 | `0` |
| `rune` (= `int32`) | Unicode 码点 | `0` |
| `error` | 错误接口 | `nil` |

### 1.4 流程控制

**解决的问题**：Go 的控制结构简洁，无需括号包裹条件。

```go
// if —— 条件无需括号，可包含初始化语句
if x := getResult(); x > 0 {
    return x
}

// for —— Go 唯一的循环结构
for i := 0; i < n; i++ { }
for condition { }
for { }
for i, v := range slice { }
for k, v := range m { }

// switch —— 无需 break，默认不穿透
switch status {
case 200:
    fmt.Println("OK")
case 404:
    fmt.Println("Not Found")
    fallthrough
default:
    fmt.Println("Unknown")
}

// defer —— 延迟执行（栈顺序：后进先出）
func readFile(path string) error {
    f, err := os.Open(path)
    if err != nil {
        return err
    }
    defer f.Close()
    return nil
}
```

**性能注意事项**：
- `defer` 有轻微开销（Go 1.14 后优化至约30ns），高频循环中避免
- `range` 遍历时 v 是拷贝，大结构体用 `for i` 索引访问

### 1.5 panic / recover

**解决的问题**：Go 没有异常机制，panic/recover 用于不可恢复的错误。

```go
func safeCall(fn func()) {
    defer func() {
        if r := recover(); r != nil {
            log.Printf("panic recovered: %v", r)
        }
    }()
    fn()
}
```

## 二、内置数据结构

### 2.1 数组

**解决的问题**：固定长度、连续内存的同构集合。

```go
var arr [5]int
arr2 := [3]int{1, 2, 3}
arr3 := [...]int{1, 2, 3}  // 自动推导长度

// 数组是值类型 —— 赋值和传参会拷贝全部元素
a := [3]int{1, 2, 3}
b := a          // 拷贝整个数组
a[0] = 100      // b[0] 仍为 1
```

### 2.2 切片（Slice）

**解决的问题**：动态数组，Go 中最常用的序列类型。

```go
var s []int                 // nil 切片
s2 := []int{1, 2, 3}
s3 := make([]int, 5)
s4 := make([]int, 3, 6)

// append
s = append(s, 1)
s = append(s, []int{5, 6}...)

// 切片操作
sub := s[1:3]
sub2 := s[:2]

// copy
src := []int{1, 2, 3}
dst := make([]int, 2)
copied := copy(dst, src)  // 返回 2
```

**append 扩容策略**：

| 版本 | 策略 |
|:-----|:-----|
| Go 1.0-1.17 | cap < 1024 -> 2x；>=1024 -> 1.25x |
| Go 1.18+ | 更平滑的公式，减少内存浪费 |

**常见陷阱**：
```go
// 陷阱1：切片共享底层数组
original := []int{1, 2, 3, 4, 5}
sub := original[1:3]
sub[0] = 99              // original[1] 也被修改

// 陷阱2：append 超出 cap 产生新数组
s1 := []int{1, 2}
s2 := s1[:1]
s2 = append(s2, 99)      // 没超出 cap，影响 s1
s2 = append(s2, 100)     // 超出 cap，新分配
```

### 2.3 Map

**解决的问题**：键值对存储，哈希表实现。

```go
m := make(map[string]int)
m2 := map[string]int{"a": 1, "b": 2}

m["key"] = 42
value, ok := m["key"]
delete(m, "key")

for k, v := range m {
    fmt.Println(k, v)
}
```

**注意事项**：
- **遍历顺序随机**
- **并发不安全**：并发读写 panic
- **nil map**：读取返回零值，写入 panic
- **key 类型**：必须可比较

### 2.4 Struct

**解决的问题**：组合不同类型字段的自定义类型。

```go
type Person struct {
    Name string
    Age  int
    Tags []string
}

var p Person  // 零值可用

p1 := Person{Name: "Alice", Age: 30}

// 字段标签 —— 元数据
type Config struct {
    Host string `json:"host"`
    Port int    `json:"port" default:"8080"`
}

// 空结构体 —— 零内存占用
type Empty struct{}
fmt.Println(unsafe.Sizeof(Empty{}))  // 0
```

### 2.5 container 标准库

```go
// heap —— 优先队列
import "container/heap"
type IntHeap []int
func (h IntHeap) Len() int { return len(h) }
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }
func (h IntHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }
func (h *IntHeap) Push(x any) { *h = append(*h, x.(int)) }
func (h *IntHeap) Pop() any {
    old := *h; n := len(old); x := old[n-1]; *h = old[0:n-1]; return x
}

// list —— 双向链表
import "container/list"
l := list.New()
l.PushBack(1)
for e := l.Front(); e != nil; e = e.Next() {
    fmt.Println(e.Value)
}
```

## 三、函数与方法

### 3.1 函数声明

```go
// 多返回值
func divide(a, b int) (int, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

// 命名返回值
func split(sum int) (x, y int) {
    x = sum * 4 / 9
    y = sum - x
    return
}

// 变参
func sum(nums ...int) int {
    total := 0
    for _, n := range nums {
        total += n
    }
    return total
}

// 闭包
func counter() func() int {
    i := 0
    return func() int {
        i++
        return i
    }
}
```

### 3.2 方法定义

**解决的问题**：Go 通过 receiver 参数为类型绑定方法。

```go
type Rectangle struct {
    Width, Height float64
}

// 值接收者
func (r Rectangle) Area() float64 {
    return r.Width * r.Height
}

// 指针接收者
func (r *Rectangle) Scale(factor float64) {
    r.Width *= factor
    r.Height *= factor
}
```

**值接收者 vs 指针接收者**：

| 维度 | 值接收者 | 指针接收者 |
|:-----|:---------|:-----------|
| 修改原始对象 | 不能 | 能 |
| 调用者类型 | 值和指针都可调 | 值和指针都可调 |
| 大结构体拷贝 | 有开销 | 无 |
| nil 接收者 | 不可处理 | 可处理 |

**方法集规则**：

| 类型 | 方法集 |
|:-----|:-------|
| `T` | `T` 的所有值接收者方法 |
| `*T` | `T` 的所有值接收者 + 指针接收者方法 |

```go
type Speaker interface { Speak() }

type Dog struct{}
func (d Dog) Speak() {}    // 值接收者

var s Speaker = Dog{}     // OK
var s2 Speaker = &Dog{}   // OK

type Cat struct{}
func (c *Cat) Speak() {}  // 指针接收者

var s3 Speaker = Cat{}    // 编译错误
var s4 Speaker = &Cat{}   // OK
```

### 3.3 与 C++/Java 对比

**关键差异**：
- Go 方法可在任何包中为类型添加
- Go 没有 `this`/`self` 关键字
- Go 不支持方法重载
- Go 没有继承，用组合+接口实现多态

## 四、接口

### 4.1 隐式实现

```go
type Writer interface {
    Write(p []byte) (n int, err error)
}

type FileWriter struct {
    path string
}

// 自动满足 Writer 接口
func (fw FileWriter) Write(p []byte) (n int, err error) {
    return os.WriteFile(fw.path, p, 0644)
}

var w Writer = FileWriter{path: "test.txt"}
```

### 4.2 接口值内部结构

```
接口值 = (type, value) 二元组
```

```go
// 注意：接口持有 nil 指针但不为 nil
var f *FileWriter = nil
var w Writer = f     // w != nil！
```

### 4.3 类型断言

```go
var w Writer = FileWriter{}

if fw, ok := w.(FileWriter); ok {
    fmt.Println(fw.path)
}

switch v := w.(type) {
case FileWriter:
    fmt.Println("FileWriter:", v.path)
default:
    fmt.Println("Unknown")
}
```

### 4.4 空接口 any

**解决的问题**：表示任意类型。

```go
var v any = 42
v = "hello"
v = []int{1, 2, 3}
```

## 六、常见陷阱速查

| 陷阱 | 说明 | 解决方案 |
|:-----|:-----|:---------|
| 循环变量闭包 | 所有 goroutine 看到同一个 i | `go func(i int) { }(i)` |
| map 并发读写 | 直接 panic | `sync.Map` 或 `sync.RWMutex` |
| nil map 写入 | `var m map[int]int; m[1] = 2` panic | 用 `make` 初始化 |
| slice 共享底层数组 | 截取后修改影响原切片 | `copy` 创建独立副本 |
| 接口 nil 判断 | 接口持有 nil 指针 != 接口为 nil | 用反射检查 |
