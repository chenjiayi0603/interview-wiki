## 一、TCP 编程

### 1.1 TCP 服务端

**解决的问题**：可靠、有序的面向连接通信。

```go
func main() {
    listener, err := net.Listen("tcp", ":8080")
    if err != nil { panic(err) }
    defer listener.Close()

    for {
        conn, err := listener.Accept()
        if err != nil { continue }
        go handleConn(conn)  // 每个连接一个 goroutine
    }
}

func handleConn(conn net.Conn) {
    defer conn.Close()
    scanner := bufio.NewScanner(conn)
    for scanner.Scan() {
        fmt.Println("received:", scanner.Text())
        fmt.Fprintln(conn, "echo: "+scanner.Text())
    }
}
```

### 1.2 TCP 客户端

```go
func main() {
    conn, err := net.Dial("tcp", "localhost:8080")
    if err != nil { panic(err) }
    defer conn.Close()

    fmt.Fprintln(conn, "hello server")
    scanner := bufio.NewScanner(conn)
    if scanner.Scan() {
        fmt.Println("response:", scanner.Text())
    }
}
```

### 1.3 并发聊天服务器

**解决的问题**：多客户端实时消息广播。

```go
type ChatServer struct {
    clients map[net.Conn]string
    msgCh   chan string
    addCh   chan net.Conn
    rmCh    chan net.Conn
}

func NewChatServer() *ChatServer {
    return &ChatServer{
        clients: make(map[net.Conn]string),
        msgCh:   make(chan string, 100),
        addCh:   make(chan net.Conn),
        rmCh:    make(chan net.Conn),
    }
}

func (s *ChatServer) Run() {
    for {
        select {
        case conn := <-s.addCh:
            s.clients[conn] = conn.RemoteAddr().String()
        case conn := <-s.rmCh:
            delete(s.clients, conn)
            conn.Close()
        case msg := <-s.msgCh:
            for conn := range s.clients {
                fmt.Fprintln(conn, msg)
            }
        }
    }
}

func (s *ChatServer) HandleConn(conn net.Conn) {
    defer func() { s.rmCh <- conn }()
    s.addCh <- conn
    scanner := bufio.NewScanner(conn)
    for scanner.Scan() {
        s.msgCh <- scanner.Text()
    }
}
```

## 二、UDP 编程

**解决的问题**：无连接、不可靠但高效的数据报通信。

```go
// UDP 服务端
func main() {
    addr, _ := net.ResolveUDPAddr("udp", ":8081")
    conn, _ := net.ListenUDP("udp", addr)
    defer conn.Close()
    buf := make([]byte, 1024)
    for {
        n, remote, _ := conn.ReadFromUDP(buf)
        fmt.Printf("received %s from %s\n", string(buf[:n]), remote)
        conn.WriteToUDP([]byte("ack"), remote)
    }
}

// UDP 客户端
conn, _ := net.DialUDP("udp", nil, addr)
conn.Write([]byte("hello"))
n, _ := conn.Read(buf)
```

**TCP vs UDP**：

| 维度 | TCP | UDP |
|:-----|:-----|:-----|
| 可靠性 | 可靠（重传+校验） | 不可靠 |
| 顺序 | 保证 | 不保证 |
| 连接 | 面向连接 | 无连接 |
| 速度 | 稍慢 | 快 |
| 适用 | HTTP/文件/数据库 | 视频/游戏/DNS |

## 三、HTTP 编程

### 3.1 HTTP 服务端

```go
func main() {
    http.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
        w.Write([]byte("Hello, World!\n"))
    })
    http.HandleFunc("/api/user", userHandler)
    http.ListenAndServe(":8080", nil)
}

func userHandler(w http.ResponseWriter, r *http.Request) {
    switch r.Method {
    case http.MethodGet:
        json.NewEncoder(w).Encode(User{Name: "Alice", Age: 30})
    case http.MethodPost:
        var u User
        json.NewDecoder(r.Body).Decode(&u)
        fmt.Fprintf(w, "created: %s\n", u.Name)
    }
}
```

### 3.2 HTTP 客户端

```go
// GET
resp, err := http.Get("https://api.example.com/users")
defer resp.Body.Close()
body, _ := io.ReadAll(resp.Body)

// POST JSON
data, _ := json.Marshal(map[string]any{"name": "Alice"})
resp, err = http.Post(url, "application/json", bytes.NewReader(data))

// 带超时的 Client
client := &http.Client{Timeout: 5 * time.Second}
resp, err = client.Get(url)

// 连接池配置
client := &http.Client{
    Transport: &http.Transport{
        MaxIdleConns:        100,
        IdleConnTimeout:     90 * time.Second,
        MaxIdleConnsPerHost: 10,
    },
}
```

### 3.3 优雅关闭

```go
srv := &http.Server{Addr: ":8080"}
go srv.ListenAndServe()

quit := make(chan os.Signal, 1)
signal.Notify(quit, syscall.SIGINT, syscall.SIGTERM)
<-quit

ctx, cancel := context.WithTimeout(context.Background(), 30*time.Second)
defer cancel()
srv.Shutdown(ctx)
```

## 四、gRPC

### 4.1 Protobuf 定义

**解决的问题**：高效的语言无关 RPC 框架。

```protobuf
syntax = "proto3";
service Greeter {
    rpc SayHello (HelloRequest) returns (HelloReply);
    rpc SayHelloStream (stream HelloRequest) returns (stream HelloReply);
}
message HelloRequest { string name = 1; }
message HelloReply { string message = 1; }
```

```bash
protoc --go_out=. --go-grpc_out=. proto/hello.proto
```

### 4.2 gRPC Server

```go
type server struct {
    pb.UnimplementedGreeterServer
}

func (s *server) SayHello(ctx context.Context, req *pb.HelloRequest) (*pb.HelloReply, error) {
    return &pb.HelloReply{Message: "Hello " + req.Name}, nil
}

// 流式 RPC
func (s *server) SayHelloStream(stream pb.Greeter_SayHelloStreamServer) error {
    for {
        req, err := stream.Recv()
        if err == io.EOF { return nil }
        if err != nil { return err }
        stream.Send(&pb.HelloReply{Message: "Hello " + req.Name})
    }
}

func main() {
    lis, _ := net.Listen("tcp", ":50051")
    s := grpc.NewServer()
    pb.RegisterGreeterServer(s, &server{})
    s.Serve(lis)
}
```

### 4.3 gRPC Client

```go
conn, _ := grpc.Dial("localhost:50051", grpc.WithInsecure())
defer conn.Close()
client := pb.NewGreeterClient(conn)

// 简单 RPC
reply, _ := client.SayHello(ctx, &pb.HelloRequest{Name: "Alice"})

// 流式 RPC
stream, _ := client.SayHelloStream(ctx)
stream.Send(&pb.HelloRequest{Name: "Alice"})
reply, _ := stream.Recv()
```

### 4.4 拦截器

```go
// 服务端日志拦截器
func loggingInterceptor(ctx context.Context, req any, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (any, error) {
    log.Printf("method: %s", info.FullMethod)
    return handler(ctx, req)
}

// 注册
s := grpc.NewServer(grpc.UnaryInterceptor(loggingInterceptor))
```

### 4.5 gRPC vs REST

| 维度 | gRPC | REST |
|:-----|:-----|:------|
| 协议 | HTTP/2 二进制 | HTTP/1.1 文本 |
| 序列化 | Protobuf | JSON |
| 性能 | 快 (~10x) | 慢 |
| 流式 | 原生双向流 | 需 WebSocket |
| 浏览器 | 需代理 | 原生 |
| 适用 | 微服务间通信 | 对外 API |

## 五、WebSocket

**解决的问题**：全双工通信，服务端主动推送。

```go
import "github.com/gorilla/websocket"

var upgrader = websocket.Upgrader{
    CheckOrigin: func(r *http.Request) bool { return true },
}

func wsHandler(w http.ResponseWriter, r *http.Request) {
    conn, _ := upgrader.Upgrade(w, r, nil)
    defer conn.Close()
    for {
        _, msg, _ := conn.ReadMessage()
        conn.WriteMessage(websocket.TextMessage, []byte("echo: "+string(msg)))
    }
}

func main() {
    http.HandleFunc("/ws", wsHandler)
    http.ListenAndServe(":8080", nil)
}
```

## 六、网络编程速查

| 场景 | 推荐方案 | 说明 |
|:-----|:---------|:------|
| 微服务 RPC | gRPC | 高性能、强类型 |
| 对外 REST API | gin/echo | 易用、生态好 |
| 实时推送 | WebSocket | 全双工 |
| 视频流 | UDP | 容忍丢包 |
| HTTP 客户端 | http.Client (复用) | 连接池 |
