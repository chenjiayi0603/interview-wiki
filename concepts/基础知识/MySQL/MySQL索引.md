# MySQL索引

> 本文档整合了索引核心要点、索引类型分类、B+Tree 与 B-Tree 对比等核心内容。

## 索引核心要点

| 核心概念 | 要点 |
|---------|------|
| **聚簇索引** | InnoDB中主键索引=聚簇索引，数据行存储在叶子节点，每表仅一个 |
| **二级索引** | 叶子节点存储主键值，查询需回表，可创建多个 |
| **覆盖索引** | 索引包含查询所需全部字段，避免回表，性能最优 |
| **最左前缀** | 联合索引必须从最左列开始连续匹配 |
| **B+Tree** | 默认索引结构，支持范围查询和排序 |

**索引失效场景**：函数计算、LIKE '%xxx'、类型转换、OR条件、违反最左前缀

## 索引类型分类

| 索引类型 | 别名/说明 | 索引数据结构 | 关键特性 | 个数限制 |
|---------|---------|-------------|---------|---------|
| **聚簇索引** | 主键索引、聚集索引 | B+Tree | 数据按主键有序存储 | 每表仅有一个 |
| **二级索引** | 辅助索引、非聚簇索引 | B+Tree | 叶子节点只存主键值 | 可创建多个 |
| **普通索引** | 最基本的二级索引 | B+Tree | 支持重复值和NULL | 可创建多个 |
| **唯一索引** | 特殊的二级索引 | B+Tree | 列值唯一，可有NULL | 可创建多个 |
| **联合索引** | 复合索引、组合索引 | B+Tree | 多列索引，最左前缀原则 | 可创建多个 |
| **全文索引** | FULLTEXT索引 | 倒排索引（InnoDB/MyISAM） | 支持全文搜索 | 可创建多个 |
| **空间索引** | SPATIAL索引 | R-Tree/B+Tree | 用于地理空间字段 | 可创建多个 |
