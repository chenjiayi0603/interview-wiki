## 二、技术栈选型路线

```
团队规模          推荐方案                   典型工具
─────────────────────────────────────────────────────
1-5人    →  单机 Docker Compose          Compose + Portainer
5-15人   →  多机 Compose + 脚本           Ansible + 镜像仓库
15-30人  →  轻量编排                     Swarm / Coolify / Nomad
30人+    →  托管 K8s                     ACK / TKE / CCE
```

**核心理念**：不要一步到位上 K8s，Docker Compose 足以支撑绝大多数中小公司。

## 四、技术栈全景

| 层 | 技术 | 作用 |
|----|------|------|
| 容器运行时 | Docker / containerd | 运行和管理容器 |
| 容器编排 | Docker Compose / Swarm / K8s | 多容器调度管理 |
| 服务网格 | Istio / Envoy / Linkerd | 流量管理、安全、可观测 |
| CI/CD | GitHub Actions / Drone / GitLab CI | 自动构建部署 |
| 监控 | Prometheus / Grafana / Loki | 指标、日志、告警 |
| 注册中心 | Consul / Nacos / CoreDNS | 服务发现 |
| RPC | gRPC / Protobuf | 服务间通信 |
