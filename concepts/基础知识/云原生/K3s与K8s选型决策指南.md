### 11.2 选型检查清单

#### 11.2.1 选择 K3s 的场景 ✅

- [ ] 开发/测试环境（资源有限）
- [ ] 单机或少量节点（< 10台）
- [ ] 边缘计算/IoT 设备（ARM/资源受限）
- [ ] 需要离线部署
- [ ] 快速原型验证
- [ ] 学习 Kubernetes 概念
- [ ] 容器化应用简单，无复杂治理需求
- [ ] 需要轻量级 CI/CD Runner

#### 11.2.2 选择 K8s 的场景 ✅

- [ ] 大规模集群（100+ 节点）
- [ ] 多云/混合云部署
- [ ] 强一致性要求（金融/交易系统）
- [ ] 需要高级网络策略
- [ ] 企业级安全合规要求
- [ ] 需要多租户隔离
- [ ] 复杂的微服务治理（Istio/Linkerd）
- [ ] 已有云原生架构团队

### 11.3 混合适景

**从 K3s 迁移到 K8s：**
```bash
# K3s 导出配置
kubectl get all -A -o yaml > cluster-backup.yaml

# 导入 K8s（API 兼容，大多数资源可直接迁移）
kubectl apply -f cluster-backup.yaml
```
