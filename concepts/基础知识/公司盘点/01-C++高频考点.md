# C++ 高频考点速查

> 外企 / 字节 / 基础架构 高频

---

## 一、智能指针

| 指针 | 大小 | 特点 |
|------|------|------|
| `unique_ptr` | 8 字节 | 独占所有权，零开销，只能 move |
| `shared_ptr` | 16 字节+控制块~40 字节 | 引用计数，线程安全 |
| `weak_ptr` | 16 字节 | 不增加 use_count，打破循环引用 |

**高频**: `make_shared` 一次分配（对象+控制块）vs `new shared_ptr` 两次分配

---

## 二、四种 cast

| cast | 时机 | 用途 | 安全 |
|------|------|------|------|
| `static_cast` | 编译期 | 基本类型/类层次 | 中等 |
| `const_cast` | 编译期 | 去除 const | 低 |
| `reinterpret_cast` | 编译期 | 指针/整数互转 | 极低 |
| `dynamic_cast` | 运行期 | 类层次转型(需虚函数) | 高 |

---

## 三、虚函数原理

```
vptr 初始化: 构造函数开始时，按基类→派生类顺序
调用: obj->vptr[index] → 间接调用
开销: 8 字节 vptr + 间接跳转
```

---

## 四、异常安全级别

```
1. No Guarantee: 可能泄漏
2. Basic: 资源不泄漏但状态不确定
3. Strong: 回滚(copy-and-swap)
4. Noexcept: 永不抛

必须 noexcept: 析构 / move / swap
```

---

## 五、内存序 (memory_order)

```
relaxed: 仅原子性
acquire: 之后读不能重排到之前
release: 之前写不能重排到之后
seq_cst: 全局一致（默认）

典型: Producer(release) → Consumer(acquire)
```

---

## 六、STL 容器选择

```
vector:       随机访问+尾插
deque:        双端操作（中控器 T** + 固定缓冲区）
list:         中间插入
unordered_map: 键值查找 O(1)
map/set:      有序需求 O(logn)
priority_queue: TopK / 任务调度

高频: emplace_back(vs push_back) / noexcept移动构造 / string_view
```
