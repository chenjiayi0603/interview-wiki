## 二、第二梯队（理解思路，备选）

| 算法 | 要点 | 公司偏好 |
|------|------|---------|
| 课程表（拓扑排序） | 建图+入度，BFS 判环 | 字节⭐⭐⭐ |
| 前序+中序构造二叉树 | 前序首为根，中序分左右 | 外企⭐⭐ |
| LIS（最长递增子序列） | O(nlogn) tail+二分 | 字节⭐⭐ |
| LCS（最长公共子序列） | dp[i][j] 递推 | 外企⭐⭐ |
| 0-1 背包 | 逆序枚举容量 | 阿里⭐⭐ |
| 完全背包 | 正序枚举容量 | 阿里⭐⭐ |
| 单词拆分 | dp[i] 分段检查 | 字节⭐ |
| 买卖股票 III | 双状态记录两次交易 | 外企⭐⭐ |
| 不同路径 | dp[i][j]=dp[i-1][j]+dp[i][j-1] | 必刷 |
| 相交链表 | 两指针换道走 | 必刷 |
| 全排列 II（有重复） | used 数组 + 排序去重 | 高频 |
| 三数之和 | 排序 + 双指针去重 | 高频 |
| 岛屿数量 | DFS/BFS 标记 | 高频 |

## 三、第三梯队（存储/基础架构方向加练）

| 算法 | 考点 | 说明 |
|------|------|------|
| 跳表 SkipList | 概率平衡 O(logn) | RocksDB MemTable 默认实现 |
| BloomFilter | 快速判断 key 是否存在 | SST 读取加速，减少 IO |
| 一致性哈希 | 虚拟节点 + 哈希环 | 分布式分片路由 |

## 四、刷题策略

```
字节/快手: 第一梯队全部 + 课程表/LIS/单词拆分
阿里/美团: 第一梯队全部 + 0-1背包/三数之和
外企:     第一梯队全部 + 买卖股票/LCS/岛屿数量
华为云:   第一梯队(除LRU) + 跳表/BloomFilter
中小公司:  第一梯队前10个足矣

时间不够: 先刷 LRU/反转链表/快排/第K大/有效括号
  这5个覆盖 80% 的面试手写环节
```
