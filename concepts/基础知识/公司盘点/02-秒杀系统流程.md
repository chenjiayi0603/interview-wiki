# 流程图 · 秒杀系统

---

## 一、整体架构

```
CDN(静态页) → Nginx(限流) → 网关(限流+防刷) → 应用层
  → Redis Lua 原子扣库存 → MQ(削峰) → DB(最终落库)
```

---

## 二、库存扣减流程

```
用户请求
  → 布隆过滤器(防刷)
    → Redis Lua: GET stock → DECRBY
      → 成功 → 创建订单 → MQ → DB 异步扣减
      → 失败 → 返回"库存不足"
```

---

## 三、热点 Key 优化

```
单个 Key 热点:
  商品 stock:{id} → 拆分为 stock:{id}:{shard}
  请求随机路由到分片
  失败时尝试其他分片
```

---

## 四、降级策略

```
Redis 正常 → 全力服务
Redis 过载 → 限流 50% 请求
Redis 挂 → 降级到 DB 乐观锁（限流 10%）
DB 也挂 → 返回"系统繁忙"（缓存旧数据兜底）
```
