# 流程图 · 存算分离架构

---

## 一、整体架构

```
KeyDB → RocksDB → 自定义 Env 插件 → [Etcd + OBS]
  ├── 热: 本地 RocksDB (Block Cache + MemTable)
  ├── 冷: OBS 对象存储
  └── 元数据: Etcd
```

---

## 二、读写路径

```
读:
  请求 → 查Block Cache → 命中返回
                      → 未命中查本地SST → 命中返回
                                        → 未命中查OBS → 加载到本地 → 返回

写:
  请求 → 写WAL → 写MemTable → MemTable满 → Flush成SST
    → 热SST存本地 + 异步上传OBS → Etcd更新元数据
```

---

## 三、冷热分层判断

```
时间: > 7 天未访问 → 标记冷
频次: 滑动窗口 < 阈值 → 标记冷
迁移: SST 上传 OBS → 释放本地 → 更新 Etcd
回热: 访问冷数据 → OBS 拉到本地 → 插入 LRU
```
