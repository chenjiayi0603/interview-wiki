## 一、TCP 状态（闭眼能画）

```
CLOSED → LISTEN（被动打开）
CLOSED → SYN_SENT（主动打开）
LISTEN → SYN_RCVD → ESTABLISHED
ESTABLISHED → FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT(2MSL) → CLOSED
ESTABLISHED → CLOSE_WAIT → LAST_ACK → CLOSED
```

---

## 二、TCP 拥塞控制

| 阶段 | 行为 | 触发 |
|------|------|------|
| 慢启动 | cwnd 指数增长 | 初始/超时 |
| 拥塞避免 | cwnd 线性增长 | cwnd ≥ ssthresh |
| 快速重传 | 3 个重复 ACK | 丢包 |
| 快速恢复 | cwnd 减半 | 快速重传后 |
| 超时重传 | cwnd=1，重慢启动 | RTO |

**发送窗口** = min(rwnd, cwnd)

## 四、TLS 握手

```
TLS 1.2: ClientHello → ServerHello+证书 → 密钥交换 → Finished（2 RTT）
TLS 1.3: 1-RTT（合并 Hello 和密钥交换），0-RTT（重连）
```

## 五、HTTP

```
1.1: keep-alive 复用 / 管线化（队头阻塞）
2.0: 多路复用 / 二进制分帧 / 头部压缩 / 服务端推送
3.0: QUIC (UDP) / 0-RTT / 无队头阻塞
```
