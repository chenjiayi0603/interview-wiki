# 操作系统速查

---

## 一、进程 vs 线程

| 维度 | 进程 | 线程 |
|------|------|------|
| 地址空间 | 独立 | 共享 |
| 调度开销 | 1-10μs | 100ns-1μs |
| 通信 | IPC(管道/共享内存/MQ) | 直接读写 |
| 崩溃影响 | 不影响其他 | 同进程全挂 |

---

## 二、虚拟内存

```
虚拟地址 → (MMU + TLB) → 物理地址
  页大小: 4KB(默认) / 2MB(大页) / 1GB
  页表: 多级页表（x86-64 四级）
  swap: 内存不足换页到磁盘
```

---

## 三、进程调度算法

```
FCFS: 先来先服务
SJF: 短作业优先（最优平均等待）
RR: 时间片轮转
优先级调度: 可能饥饿（需老化）
多级反馈队列: Linux 默认
```
