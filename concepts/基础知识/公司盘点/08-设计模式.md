## 四、SOLID 原则

```
S - 单一职责: 一个类只做一件事
O - 开闭原则: 对扩展开放，对修改关闭
L - 里氏替换: 派生类必须能替换基类
I - 接口隔离: 客户端不依赖不用的接口
D - 依赖反转: 依赖抽象，不依赖具体
```

## 五、单例模板

```cpp
class Singleton {
public:
    static Singleton& instance() {
        static Singleton obj;  // C++11 线程安全
        return obj;
    }
private:
    Singleton() = default;
    Singleton(const Singleton&) = delete;
    Singleton& operator=(const Singleton&) = delete;
};
```
