# 面试突击 · 使用指南

> 目标：按分类精准备战，不再一把抓
> 定位：面试前的冲刺弹药库，不是教科书

---

## 📐 目录结构

```
00-使用指南/          ← 你在这
01-公司专题/           ← 按目标公司分类，只含公司特色考点
02-算法专项/           ← 高频题 + 手写模板 + 大厂考频
03-系统设计专项/       ← 秒杀/IM/KV存储/短URL/AI对话
05-通用考点/           ← C++/Go/网络/OS/MySQL/Redis/分布式/设计模式
06-流程图解/           ← 关键流程的可视化（IM/秒杀/存算分离）

项目深挖 → 已移至 ../项目/ 各项目目录下的 项目名-项目性能分析.md
```

## 🎯 使用方式

### 场景 1：你正在准备某家公司面试

```
① 翻 01-公司专题/ 对应公司 → 了解考点方向
② 翻 ../项目/对应项目/项目名-项目性能分析.md 把项目话术练熟
③ 翻 02-算法专项/ 刷对应公司高频题
④ 翻 03-系统设计专项/ 准备对应设计题
⑤ 面试前两天看 05-通用考点/ 薄弱环节
```

### 场景 2：你还在探索方向

```
先看 01-公司专题/ 各公司对比表 → 选 2-3 家目标
```

### 场景 3：你时间很少（< 3 天）

```
最小路径：
  公司专题（30min）→ 项目/xxx/项目名-项目性能分析.md（1h）→ 算法手写（30min）→ 流程图（15min）
```

## 📝 各类文件关系
