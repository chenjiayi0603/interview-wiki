## 二、内存管理全景图

### 2.1 进程地址空间

```
┌─────────────────────┐ 高地址
│      内核空间        │
├─────────────────────┤
│       栈            │ 向下增长（每线程 ~8MB）
├─────────────────────┤
│   内存映射段          │ mmap / 共享库 / 大内存分配
├─────────────────────┤
│       堆            │ 向上增长（brk/sbrk）
├─────────────────────┤
│    BSS段             │ 未初始化全局/静态变量
├─────────────────────┤
│    数据段             │ 已初始化全局/静态变量
├─────────────────────┤
│    代码段             │ 只读文本（.text）
└─────────────────────┘ 低地址
```

### 2.2 内存分配路径

```
用户代码 → new/delete → operator new/delete → malloc/free
    → glibc malloc (ptmalloc) → brk (<128KB) / mmap (≥128KB) → 内核
```

### 2.3 关键指标

| 指标 | 含义 | 关系 |
|------|------|------|
| VSZ | 虚拟地址空间总量（承诺） | VSZ ≥ RSS |
| RSS | 实际物理内存占用 | RSS = 驻留页 |
| PSS | 按比例分摊的物理内存 | 共享库按进程数分摊 |
