# OpenMP vs 线程池

> 对比 OpenMP 与线程池在不同场景下的适用性。

## 场景对比

| 场景 | OpenMP | 线程池 |
| ---- | ------ | ------ |
| CPU 密集型（矩阵乘等） | ⭐⭐⭐⭐⭐ 最快 | ⭐⭐⭐ 较慢 |
| I/O 密集型 | ⭐⭐ 不合适 | ⭐⭐⭐⭐ 较好 |
| 不规则并行（树/图遍历） | ⭐⭐ 难并行 | ⭐⭐⭐⭐⭐ 灵活 |

- **选 OpenMP**：循环/数据并行、CPU 密集、追求性能。
- **选线程池**：I/O、复杂任务图、不规则并行。
