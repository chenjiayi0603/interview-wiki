# I/O 优化

## 一、零拷贝技术

### 1.1 sendfile（文件 → socket）

```cpp
#include <sys/sendfile.h>

// 零拷贝发送文件到 socket
off_t offset = 0;
ssize_t sent;
while (offset < filesize) {
    sent = sendfile(client_fd, file_fd, &offset, filesize - offset);
    if (sent <= 0) break;
}
// 数据直接从文件页缓存 → socket 缓冲区，无需用户空间拷贝
```

**sendfile 限制**：
- file_fd 必须是支持 mmap 的本地文件（ext4/xfs 等常规文件系统）
- socket_fd 仅支持 TCP（AF_INET/AF_INET6）
- 不支持加密 socket（TLS/SSL）

### 1.2 mmap（内存映射）

```cpp
#include <sys/mman.h>

// 映射文件到进程地址空间（零拷贝读取）
void* mapped = mmap(NULL, filesize, PROT_READ, MAP_PRIVATE, fd, 0);
// 文件内容直接映射到内存，读取时无需 read() 系统调用
// 缺点：映射大文件占用地址空间，页错误可能抖动

// 共享内存 IPC（进程间零拷贝通信）
void* shm = mmap(NULL, SHM_SIZE, PROT_READ | PROT_WRITE,
                 MAP_SHARED | MAP_ANONYMOUS, -1, 0);
```

### 1.3 splice（管道到 socket 零拷贝）

```cpp
// splice: 在两个文件描述符间移动数据，无需用户空间拷贝
// 常用于 pipe → socket 的零拷贝
int pipefd[2];
pipe(pipefd);
// 从文件读入 pipe
splice(file_fd, NULL, pipefd[1], NULL, count, SPLICE_F_MORE);
// 从 pipe 写入 socket（零拷贝）
splice(pipefd[0], NULL, socket_fd, NULL, count, SPLICE_F_MORE);
```

### 1.4 零拷贝技术对比

| 技术 | 源 → 目标 | 场景 | 内核版本 |
|------|-----------|------|----------|
| `sendfile` | 文件 → socket | 文件服务 | 2.6+ |
| `mmap` | 文件 → 用户空间 | 大文件读取 | 长期支持 |
| `splice` | 管道 → socket | 代理/转发 | 2.6.17+ |
| `MSG_ZEROCOPY` | 用户空间 → socket | 零拷贝发送 | 4.14+ |

## 二、网络 I/O 优化

### 2.1 批量化

```cpp
// readv: 批量接收
struct iovec iov[32];
for (int i = 0; i < 32; i++) {
    iov[i].iov_base = buffers[i];
    iov[i].iov_len = 1024;
}
ssize_t n = readv(sockfd, iov, 32);  // 一次系统调用收多个包

// writev: 批量发送
struct iovec iov[32];
// ... 填充数据
writev(sockfd, iov, count);  // 一次系统调用发多个包

// recvmmsg / sendmmsg（UDP 批量化）
struct mmsghdr msgs[32];
int ret = recvmmsg(sockfd, msgs, 32, 0, NULL);
```

### 2.2 缓冲区优化

```cpp
// 增大套接字缓冲区
int bufsize = 1024 * 1024;  // 1MB
setsockopt(sockfd, SOL_SOCKET, SO_SNDBUF, &bufsize, sizeof(bufsize));
setsockopt(sockfd, SOL_SOCKET, SO_RCVBUF, &bufsize, sizeof(bufsize));

// 禁用 Nagle 算法（低延迟必选）
int flag = 1;
setsockopt(sockfd, IPPROTO_TCP, TCP_NODELAY, &flag, sizeof(flag));

// 禁用延迟确认（进一步减少延迟）
setsockopt(sockfd, IPPROTO_TCP, TCP_QUICKACK, &flag, sizeof(flag));
```

### 2.3 epoll 使用要点

```cpp
// 推荐 ET（边缘触发）模式 + 非阻塞 I/O
int epoll_fd = epoll_create1(0);

struct epoll_event ev;
ev.events = EPOLLIN | EPOLLET;  // 边缘触发
ev.data.fd = sockfd;
epoll_ctl(epoll_fd, EPOLL_CTL_ADD, sockfd, &ev);

// ET 模式下必须循环读取直到 EAGAIN
while (1) {
    ssize_t n = read(sockfd, buf, sizeof(buf));
    if (n > 0) {
        process(buf, n);
    } else if (n == 0) {
        // 连接关闭
        break;
    } else {
        if (errno == EAGAIN) break;  // 数据已读完
        // 错误处理
    }
}
```

**epoll 与 io_uring 对比**：

| 特性 | epoll | io_uring |
|------|-------|----------|
| 内核版本 | 2.6+ | 5.1+ |
| 模式 | 事件通知 | 异步提交/完成队列 |
| 系统调用次数 | 每事件多次 | 批量提交（减少 syscall） |
| 支持操作 | 读写事件 | 读写、open、accept、等 |
| 零拷贝 | 不支持 | 支持 |
| 适用场景 | 成熟稳定 | 高性能新项目 |

## 三、异步 I/O

### 3.1 io_uring（Linux 5.1+）

```cpp
// io_uring 简化示例
#include <liburing.h>

struct io_uring ring;
io_uring_queue_init(256, &ring, 0);

// 提交读请求
struct io_uring_sqe* sqe = io_uring_get_sqe(&ring);
io_uring_prep_read(sqe, fd, buf, count, offset);
io_uring_submit(&ring);

// 等待完成
struct io_uring_cqe* cqe;
io_uring_wait_cqe(&ring, &cqe);
// 处理完成事件
io_uring_cqe_seen(&ring, cqe);
```

### 3.2 异步日志

```cpp
// 异步日志架构：业务线程只入队，专用线程写盘
class AsyncLogger {
    SPSCQueue<std::string, 65536> queue_;
    std::thread writer_;
    
    void writer_loop() {
        std::string entry;
        while (true) {
            if (queue_.pop(entry)) {
                // 批量写盘
                write(fd_, entry.data(), entry.size());
                if (entry.size() == 0) break;  // 退出信号
            }
        }
    }
    
public:
    void log(const std::string& msg) {
        queue_.push(msg);  // 无锁入队，不阻塞业务
    }
};
```

## 四、磁盘 I/O 优化

### 4.1 顺序写入

```
机械硬盘: 顺序 200MB/s vs 随机 2MB/s（100 倍差距）
SSD: 顺序 3000MB/s vs 随机 500MB/s（6 倍差距）
```

**策略**：
- WAL（Write-Ahead Logging）：顺序追加写
- 大块写入（4K→64K→1MB 块）
- mmap 小文件读写
- 避免 fsync 每个操作（批量 fsync）

### 4.2 I/O 调度器

```bash
# 查看当前调度器
cat /sys/block/sda/queue/scheduler

# 低延迟推荐：none（NVMe）或 deadline（HDD）
echo none > /sys/block/sda/queue/scheduler
echo deadline > /sys/block/sda/queue/scheduler
```

## 五、内核网络参数调优

```bash
# /etc/sysctl.conf

# 网络缓冲区最大值
net.core.rmem_max = 134217728    # 128MB
net.core.wmem_max = 134217728    # 128MB

# 默认缓冲区
net.core.rmem_default = 262144
net.core.wmem_default = 262144

# TCP 缓冲区（min, default, max）
net.ipv4.tcp_rmem = 4096 87380 134217728
net.ipv4.tcp_wmem = 4096 65536 134217728

# 队列长度
net.core.netdev_max_backlog = 500000

# TCP Fast Open
net.ipv4.tcp_fastopen = 3

# 连接超时
net.ipv4.tcp_syn_retries = 2          # 减少 SYN 重试次数
net.ipv4.tcp_synack_retries = 2
net.ipv4.tcp_fin_timeout = 5

# 端口范围（高并发）
net.ipv4.ip_local_port_range = 1024 65535

# 长连接保活
net.ipv4.tcp_keepalive_time = 600
net.ipv4.tcp_keepalive_intvl = 30
net.ipv4.tcp_keepalive_probes = 3

# 拥塞控制算法（低延迟推荐 bbr）
net.ipv4.tcp_congestion_control = bbr
```

## 六、文件系统与磁盘参数

### 6.1 挂载参数

```bash
# noatime：不更新访问时间（减少磁盘写）
# nodiratime：同上，针对目录
# data=writeback（ext4）：写回模式，减少元数据写
mount -o noatime,nodiratime,data=writeback /dev/sda1 /data
```
