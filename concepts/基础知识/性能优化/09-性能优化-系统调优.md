# 系统调优

## 一、内核参数优化（sysctl）

### 1.1 低延迟系统推荐配置

```bash
# /etc/sysctl.conf

# ===== 网络调优 =====
# 缓冲区最大值（单位：字节）
net.core.rmem_max = 134217728
net.core.wmem_max = 134217728

# 默认缓冲区
net.core.rmem_default = 262144
net.core.wmem_default = 262144

# TCP 缓冲区（min, default, max）
net.ipv4.tcp_rmem = 4096 87380 134217728
net.ipv4.tcp_wmem = 4096 65536 134217728

# 网络设备 backlog（数据包队列长度上限）
net.core.netdev_max_backlog = 500000

# TCP Fast Open（减少 1 次 RTT）
net.ipv4.tcp_fastopen = 3

# 快速回收 TIME_WAIT（高并发）
net.ipv4.tcp_tw_reuse = 1

# 连接超时
net.ipv4.tcp_syn_retries = 2
net.ipv4.tcp_synack_retries = 2
net.ipv4.tcp_fin_timeout = 5

# 拥塞控制（低延迟推荐 bbr）
net.ipv4.tcp_congestion_control = bbr

# ===== 内存调优 =====
# 禁用 swap（低延迟系统）
vm.swappiness = 0

# 允许内存超分配（适合突发大内存低延迟场景）
vm.overcommit_memory = 1

# 脏页阈值
vm.dirty_ratio = 20
vm.dirty_background_ratio = 5

# ===== 调度调优 =====
# 对实时进程的 CPU 时间无限制
kernel.sched_rt_runtime_us = -1
kernel.sched_rt_period_us = 1000000

# 禁用 NUMA balancing（避免自动迁移导致抖动）
kernel.numa_balancing = 0

# 应用配置
sysctl -p
```

### 1.2 参数说明

**sched_rt_period_us 与 sched_rt_runtime_us**：
- `period_us`：评估周期（常用 1000000 = 1秒）
- `runtime_us`：周期内实时进程可用 CPU 时间
- `-1`：不做限制（推荐低延迟系统）
- `950000`（举例）：每1秒最多950ms给实时进程，剩余50ms给普通进程

## 二、CPU 调优

### 2.1 性能模式

```bash
# 所有 CPU 设为 performance 模式
echo performance | sudo tee /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor

# 禁用 Turbo Boost（需稳定频率场景）
echo 1 | sudo tee /sys/devices/system/cpu/intel_pstate/no_turbo

# 禁用 C-States（减少从深度睡眠唤醒的延迟）
sudo cpupower set -b 0
```

### 2.2 CPU 隔离

```bash
# 内核参数 isolcpus：将指定 CPU 从默认调度中隔离
# /etc/default/grub
GRUB_CMDLINE_LINUX_DEFAULT="quiet isolcpus=1,2,3 nohz_full=1,2,3 rcu_nocbs=1,2,3"

# 更新引导
update-grub

# 验证隔离
cat /sys/devices/system/cpu/isolated
```

## 三、内存调优

### 3.1 透明大页（THP）

```bash
# 禁用 THP（低延迟系统必须）
echo never > /sys/kernel/mm/transparent_hugepage/enabled
echo never > /sys/kernel/mm/transparent_hugepage/defrag

# 永久禁用
# /etc/default/grub 添加
transparent_hugepage=never

# 或写入 /etc/rc.local
```

**为什么禁用 THP**：
- 分配/合并时的不可控抖动
- kcompactd 可能在关键路径抢占 CPU
- 内存碎片风险
- 分配延迟不确定（可能数百微秒）

### 3.2 显式大页（HugePages）

```bash
# 分配 1024 个 2MB 大页
echo 1024 > /sys/devices/system/node/node0/hugepages/hugepages-2048kB/nr_hugepages

# 挂载大页文件系统
mkdir -p /mnt/huge
mount -t hugetlbfs none /mnt/huge

# 查看大页状态
cat /proc/meminfo | grep Huge
```

### 3.3 内存锁定资源

```bash
# 查看当前限制
ulimit -l

# 设置为 unlimited
# /etc/security/limits.conf
* soft memlock unlimited
* hard memlock unlimited
```

## 四、中断绑定

### 4.1 IRQ 亲和性配置

```bash
# 停止 irqbalance
systemctl stop irqbalance

# 查看中断分布
cat /proc/interrupts | grep eth0

# 绑定指定中断到 CPU0
echo 1 > /proc/irq/24/smp_affinity

# 获取网卡队列详情
ethtool -l eth0
ethtool -S eth0 | grep queue
```

### 4.2 RPS/RFS（软件分发）

```bash
# 当硬件不支持多队列时，用 RPS 做软中断分发
echo f > /sys/class/net/eth0/queues/rx-0/rps_cpus
# (f = 二进制 1111，表示分发给 CPU0-3)

# RFS 进一步确保软中断和消费线程在同一 CPU
echo 256 > /sys/class/net/eth0/queues/rx-0/rps_flow_cnt
```

## 五、文件系统与磁盘

### 5.1 文件系统优化

```bash
# 挂载选项
mount -o noatime,nodiratime,data=writeback /dev/sda1 /data
# noatime: 不更新 inode 访问时间（减少写）
# nodiratime: 不更新目录访问时间
# data=writeback: ext4 写回模式（减少元数据写）

# 预读设置
blockdev --setra 4096 /dev/sda   # 2MB 预读
```

### 5.2 I/O 调度器

```bash
# 查看
cat /sys/block/sda/queue/scheduler

# NVMe 推荐 none（原 mq-deadline）
# HDD 推荐 deadline
echo none > /sys/block/sda/queue/scheduler

# 调整队列深度
echo 256 > /sys/block/sda/queue/nr_requests
```

## 六、系统监控

### 6.1 关键监控指标

| 指标 | 工具 | 说明 |
|------|------|------|
| CPU 利用率 | `top`, `mpstat` | 是否满负荷 |
| 上下文切换 | `vmstat 1` | cs 列，高则锁竞争/线程过多 |
| 中断分布 | `cat /proc/interrupts` | 是否在预期 CPU 上 |
| 内存使用 | `free -h`, `cat /proc/meminfo` | RSS, HugePages |
| 网络丢包 | `netstat -i`, `ethtool -S` | 驱动/硬件丢包 |
| NUMA 统计 | `numastat` | 本地 vs 远程内存访问比例 |

### 6.2 抖动排查

```bash
# 检查上下文切换率
vmstat 1 | awk '{print $12}'  # cs 列

# 检查中断分布
watch -n 1 cat /proc/interrupts

# 检查 CPU 频率调整
watch -n 1 cat /sys/devices/system/cpu/cpu*/cpufreq/scaling_cur_freq

# 检查 C-State 分布
cpupower monitor

# 检查 NUMA 远程访问
numastat -p <pid>
```

### 6.3 调优效果验证

```bash
# 延迟测试
cyclictest -t1 -p99 -i10000 -l100000

# 性能对比
perf stat -e cycles,instructions,cache-misses,branch-misses \
         -I 1000 -p <pid>

# 网络性能
netperf -t TCP_RR -H <server>  # 请求-响应延迟
```
