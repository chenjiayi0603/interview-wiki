# 分支预测优化

**问题**：分支预测失败会导致流水线停顿，增加延迟。

## 优化技巧

### 1. 使用 likely/unlikely 提示编译器

```cpp
#define likely(x)   __builtin_expect(!!(x), 1)
#define unlikely(x) __builtin_expect(!!(x), 0)

int process(int value) {
    if (likely(value > 0)) {
        return value * 2;
    } else {
        return 0;
    }
}
```

### 2. 减少分支数量

```cpp
// 优化前：多个分支
int get_value(int type) {
    if (type == 0) return 10;
    if (type == 1) return 20;
    if (type == 2) return 30;
    return 0;
}

// 优化后：查找表
int get_value(int type) {
    static const int values[] = {10, 20, 30};
    if (type >= 0 && type < 3) {
        return values[type];
    }
    return 0;
}
```

### 3. 使用条件移动指令（避免分支）

```cpp
int max(int a, int b) {
    return a > b ? a : b;  // 可能编译为 CMOV
}
```
