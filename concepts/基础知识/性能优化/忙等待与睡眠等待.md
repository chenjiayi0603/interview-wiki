# 忙等待 vs 睡眠等待

> 忙等待（Busy-Waiting）和睡眠等待（Sleep-Waiting）是两种不同的等待策略，在低延迟场景中需要根据具体需求权衡选择。

See also: [[C++多线程与并发]], [[同步问题与解决方案]]

## 忙等待策略（低延迟场景）

```cpp
#include <emmintrin.h>
#include <atomic>

// 忙等待策略（低延迟场景）
template<typename Predicate>
void spin_wait(Predicate&& pred, int spin_count = 1000) {
    int spins = 0;
    while (!pred()) {
        if (spins < spin_count) {
            // 自旋阶段：PAUSE 指令降低功耗
            _mm_pause();
            ++spins;
        } else {
            // 退避阶段：短暂睡眠让出 CPU
            sched_yield();
        }
    }
}

// 自适应忙等待
class AdaptiveSpinLock {
    std::atomic<bool> locked_{false};
    
public:
    void lock() {
        // 先尝试快速获取
        if (!locked_.exchange(true, std::memory_order_acquire)) {
            return;
        }
        
        // 忙等待
        while (locked_.load(std::memory_order_relaxed) ||
               locked_.exchange(true, std::memory_order_acquire)) {
            _mm_pause();
        }
    }
    
    void unlock() {
        locked_.store(false, std::memory_order_release);
    }
};
```
