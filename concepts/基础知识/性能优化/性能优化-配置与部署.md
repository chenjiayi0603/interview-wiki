# 性能优化：配置与部署

## 全局：观测与防回退 / 配置与部署

### 配置与部署

- CPU/NUMA 绑核、隔离噪声干扰进程；cgroup 限额与突发；关闭频繁超频抖动。
- 编译：开启 LTO/PGO 时要验证稳定性；调低异常开销（-fno-exceptions 在可接受时）。

**举例**：

- 绑定 CPU + cgroup：
  ```
  # 进程绑定到 CPU 0-15 上运行
  taskset -c 0-15 ./myserver

  # 创建名为 group1 的 cgroup (cpu、memory 子系统)
  cgcreate -g cpu,memory:group1

  # 设置 group1 的 cpu.shares（粗粒度分配权重）
  cgset -r cpu.shares=2048 group1   # 设置 group1 cgroup 的 cpu.shares 为 2048（即“分配权重”，越大优先级越高，属于相对分配而不是硬限制，多个 cgroup 抢同一核时，cpu.shares 比例决定抢到 CPU 时间片的几率）

  # 在 group1 cgroup 下运行进程，限制资源
  cgexec -g cpu,memory:group1 ./myserver
  ```
- 关闭 intel_pstate 超频:
  ```
  echo performance > /sys/devices/system/cpu/cpu*/cpufreq/scaling_governor
  ```
- 编译加 LTO PGO:
  ```
  g++ -O3 -flto -o mybinary ...
  (跑一遍生产流量采 .gcda)
  g++ -O3 -flto -fprofile-use -o mybinary ...
  ```
- 禁用异常:
  ```
  # 例：g++ 编译时关闭异常支持，减少栈展开等带来的开销
  g++ -O2 -fno-exceptions -o mybinary main.cpp
  ```

- NUMA 绑核举例（numactl）:
  ```
  # 仅使用节点0的前8个物理CPU，绑定内存为NUMA节点0
  numactl --physcpubind=0-7 --membind=0 ./myserver

  # 生产环境常用：跨socket部署多进程，每进程绑本地核和内存，降低跨node访问
  numactl --cpunodebind=1 --membind=1 ./worker2
  ```
- C++ 检查NUMA节点与分配内存（伪代码，依赖numa库）:
  ```cpp
  #include <numa.h>
  if (numa_available() != -1) {
      numa_set_preferred(0); // 绑到0号NUMA节点
      void* mem = numa_alloc_onnode(4096, 0); // 在节点0分配内存，避免跨节点访问
      // ... 使用mem ...
      numa_free(mem, 4096);
  }
  ```

**分析**：配置与部署决定"资源是否稳定可用"；绑核与隔离优先保证稳定性，再通过 LTO/PGO 榨取性能。
