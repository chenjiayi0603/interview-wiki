# 双指针与滑动窗口

> 左右指针、快慢指针、滑动窗口 —— 双指针是解决数组/字符串问题的核心技巧。

---

## 一、左右指针

### 1.1 两数之和（有序数组）

> LeetCode 167: https://leetcode.cn/problems/two-sum-ii-input-array-is-sorted

**思路**：有序数组，左右指针向中间逼近。和太小左指针右移，和太大右指针左移。O(n) 时间，比暴力 O(n²) 或哈希 O(n) 省空间。

```cpp
vector<int> twoSum(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l < r) {
        int s = nums[l] + nums[r];
        if (s == target) return {l+1, r+1};  // 1-indexed
        s < target ? l++ : r--;
    }
    return {-1, -1};
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **变体**：无序的两数之和（LeetCode 1）→ 哈希表 O(n)；三数之和 → 固定一个 + 双指针

### 1.2 三数之和

> LeetCode 15: https://leetcode.cn/problems/3sum

**思路**：先排序，固定 i，用双指针 l、r 在 i 右边找两数之和等于 -nums[i]。**去重关键**：nums[i] 跳过重复值；找到三元组后，l/r 也跳过重复值。

```cpp
vector<vector<int>> threeSum(vector<int>& nums) {
    vector<vector<int>> res;
    sort(nums.begin(), nums.end());
    for (int i = 0; i < (int)nums.size() - 2; i++) {
        if (i > 0 && nums[i] == nums[i-1]) continue;  // 去重
        int l = i + 1, r = nums.size() - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (s == 0) {
                res.push_back({nums[i], nums[l++], nums[r--]});
                while (l < r && nums[l] == nums[l-1]) l++;  // 去重
                while (l < r && nums[r] == nums[r+1]) r--;  // 去重
            } else s < 0 ? l++ : r--;
        }
    }
    return res;
}
```
- **复杂度**：时间 O(n²)，空间 O(log n)（排序栈空间）
- **边界**：nums 长度 < 3 返回空
- **变体**：最接近的三数之和（LeetCode 16）→ 记录最小差值

### 1.3 盛水最多的容器

> LeetCode 11: https://leetcode.cn/problems/container-with-most-water

**思路**：双指针从两端向中间逼近。面积由短板决定，移动较短的木板，因为移动长板面积不可能变大（高度 ≤ 短板，宽度减小）。

```cpp
int maxArea(vector<int>& h) {
    int l = 0, r = h.size() - 1, res = 0;
    while (l < r) {
        res = max(res, min(h[l], h[r]) * (r - l));
        h[l] < h[r] ? l++ : r--;  // 移动短板
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **变体**：接雨水（见 1.4）→ 也是一类双指针求积水量问题

### 1.4 接雨水

> LeetCode 42: https://leetcode.cn/problems/trapping-rain-water

**思路**：双指针往中间扫描，维护左右当前最大高度。对于每个位置，它能接的水量 = min(左侧最高, 右侧最高) - 自身高度。哪边当前更矮，就处理哪边——因为矮的一边决定了水位的上限。

```cpp
int trap(vector<int>& height) {
    int l = 0, r = height.size() - 1, lm = 0, rm = 0, res = 0;
    while (l < r) {
        if (height[l] < height[r]) {
            lm = max(lm, height[l]);
            res += lm - height[l++];  // 当前位置接水量
        } else {
            rm = max(rm, height[r]);
            res += rm - height[r--];
        }
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **其他解法**：单调递减栈（按行计算）、前缀和（预计算 leftMax/rightMax）
- **变体**：接雨水 II（LeetCode 407）→ 三维，用最小堆 BFS

### 1.5 最接近的三数之和

> LeetCode 16: https://leetcode.cn/problems/3sum-closest

找和最接近 target 的三元组，返回该和。

```cpp
int threeSumClosest(vector<int>& nums, int target) {
    if (nums.size() < 3) return 0;
    sort(nums.begin(), nums.end());
    int res = 0, diff = INT_MAX;
    for (int i = 0; i < (int)nums.size() - 2; i++) {
        int l = i + 1, r = nums.size() - 1;
        while (l < r) {
            int s = nums[i] + nums[l] + nums[r];
            if (s == target) return s;
            if (abs(target - s) < diff) { res = s; diff = abs(target - s); }
            s < target ? l++ : r--;
        }
    }
    return res;
}
```

### 1.6 搜索二维矩阵 II

> LeetCode 240: https://leetcode.cn/problems/search-a-2d-matrix-ii

每行每列升序矩阵中找 target。

```cpp
bool searchMatrix(vector<vector<int>>& matrix, int target) {
    if (matrix.empty() || matrix[0].empty()) return false;
    int x = matrix.size() - 1, y = 0;  // 从左下角开始
    while (x >= 0 && y < matrix[0].size()) {
        if (matrix[x][y] < target) y++;
        else if (matrix[x][y] > target) x--;
        else return true;
    }
    return false;
}
```

### 1.7 最短无序连续子数组

> LeetCode 581: https://leetcode.cn/problems/shortest-unsorted-continuous-subarray

找最短子数组，排序后整个数组升序。

```cpp
int findUnsortedSubarray(vector<int>& nums) {
    if (nums.empty()) return 0;
    int left = 0, right = -1;
    for (int i = 0, maxNum = nums[0]; i < nums.size(); i++) {
        if (nums[i] >= maxNum) maxNum = nums[i];
        else right = i;
    }
    for (int i = nums.size() - 1, minNum = nums.back(); i >= 0; i--) {
        if (nums[i] <= minNum) minNum = nums[i];
        else left = i;
    }
    return right - left + 1;
}
```

## 二、快慢指针

### 2.1 删除有序数组重复项

> LeetCode 26: https://leetcode.cn/problems/remove-duplicates-from-sorted-array

```cpp
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); fast++)
        if (nums[fast] != nums[slow]) nums[++slow] = nums[fast];
    return slow + 1;
}
```

### 2.2 移动零

> LeetCode 283: https://leetcode.cn/problems/move-zeroes

```cpp
void moveZeroes(vector<int>& nums) {
    int slow = 0;
    for (int fast = 0; fast < nums.size(); fast++)
        if (nums[fast] != 0) swap(nums[slow++], nums[fast]);
}
```

## 三、滑动窗口

### 3.1 滑动窗口最大值（单调递减队列）

> LeetCode 239: https://leetcode.cn/problems/sliding-window-maximum

**思路**：用双端队列维护窗口内候选最大值下标。队列保持递减——新元素从尾部弹出所有更小的值。队首始终是当前最大值，当它离开窗口时出队。

```cpp
vector<int> maxSlidingWindow(vector<int>& nums, int k) {
    vector<int> res;
    deque<int> dq;  // 存放下标，维护递减
    for (int i = 0; i < nums.size(); i++) {
        while (!dq.empty() && nums[dq.back()] <= nums[i]) dq.pop_back();
        dq.push_back(i);
        if (dq.front() == i - k) dq.pop_front();  // 移出窗口
        if (i >= k - 1) res.push_back(nums[dq.front()]);
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(k)
- **边界**：k=0 或 nums 为空
- **变体**：滑动窗口中位数（LeetCode 480）→ 双堆 + 延迟删除

### 3.2 无重复字符的最长子串

> LeetCode 3: https://leetcode.cn/problems/longest-substring-without-repeating-characters

**思路**：滑动窗口，r 向右扩展，遇到重复字符时 left 跳到上次出现位置的下一个。用数组记录每个字符最近出现位置。

```cpp
int lengthOfLongestSubstring(string s) {
    vector<int> last(128, -1);  // ASCII 128，记录最近位置
    int l = 0, res = 0;
    for (int r = 0; r < s.size(); r++) {
        if (last[s[r]] >= l) l = last[s[r]] + 1;  // 重复了，左边界右移
        last[s[r]] = r;
        res = max(res, r - l + 1);
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(1)（固定 128 长度）
- **边界**：空字符串返回 0
- **变体**：最多包含 k 个不同字符的最长子串（LeetCode 340）→ 用哈希表计数
