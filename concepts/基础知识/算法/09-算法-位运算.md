## 一、核心技巧

| 操作 | 表达式 | 说明 |
|------|--------|------|
| 取最低位的 1 | `x & -x` | 如 `6(110)` → `2(010)` |
| 去掉最低位的 1 | `x & (x-1)` | 如 `6(110)` → `4(100)` |
| 相同异或为 0 | `x ^ x = 0` | 用于找出现奇数次的数 |
| 判断奇偶 | `x & 1` | 1 为奇，0 为偶 |
| 判断 2 的幂 | `x > 0 && (x & (x-1)) == 0` | — |
| 第 k 位 | `(x >> k) & 1` | 取第 k 位值 |

## 二、只出现一次的数字

> LeetCode 136: https://leetcode.cn/problems/single-number

**思路**：异或运算——相同数异或为 0，任何数与 0 异或不变。所有数异或一遍，剩下的就是出现一次的数。**复杂度**：O(n) 时间，O(1) 空间。**变体**：找出两个只出现一次的数（见下节），需要分组异或。

```cpp
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;
    return res;
}
```

## 三、只出现一次的数字 III

> LeetCode 260: https://leetcode.cn/problems/single-number-iii

**思路**：全部异或得到 xorAll = a ^ b。用 lowbit（xorAll 最低位的 1）将原数组分为两组——该位为 0 和为 1，a 和 b 必然分到不同组。组内分别异或即得结果。**复杂度**：O(n) 时间，O(1) 空间。

```cpp
vector<int> singleNumberIII(vector<int>& nums) {
    int xorAll = 0;
    for (int x : nums) xorAll ^= x;
    int lowbit = xorAll & -xorAll;  // 取最低位的 1 作为分组依据
    int a = 0, b = 0;
    for (int x : nums) {
        if (x & lowbit) a ^= x;
        else b ^= x;
    }
    return {a, b};
}
```

## 四、数字范围按位与

> LeetCode 201: https://leetcode.cn/problems/bitwise-and-of-numbers-range

**思路**：求 [m, n] 区间所有数的按位与，等价于找 m 和 n 的公共前缀（二进制）。不断右移 m 和 n 直到相等，记录移位数，最后左移回去。**原理**：区间内所有数的公共前缀之外的位必然出现过 0。**复杂度**：O(log n) 时间，O(1) 空间。

```cpp
int rangeBitwiseAnd(int m, int n) {
    int shift = 0;
    while (m < n) { m >>= 1; n >>= 1; shift++; }
    return m << shift;
}
```

- **变体**：也可用 `n & (n-1)` 直接清除低位的 1 直到 n ≤ m
