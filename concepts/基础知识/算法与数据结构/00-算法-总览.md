## Big-O 速查表

### 数据结构操作复杂度

| 数据结构 | 访问 | 搜索 | 插入 | 删除 |
|----------|:----:|:----:|:----:|:----:|
| 数组 | O(1) | O(n) | O(n) | O(n) |
| 链表 | O(n) | O(n) | O(1) | O(1) |
| 栈 | O(n) | O(n) | O(1) | O(1) |
| 队列 | O(n) | O(n) | O(1) | O(1) |
| 哈希表 | — | O(1) | O(1) | O(1) |
| BST（平衡） | O(log n) | O(log n) | O(log n) | O(log n) |
| 红黑树 | O(log n) | O(log n) | O(log n) | O(log n) |
| 跳表 | O(log n) | O(log n) | O(log n) | O(log n) |

### 排序算法复杂度

| 算法 | 平均 | 最坏 | 空间 | 稳定 |
|------|:----:|:----:|:----:|:----:|
| 快排 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | **稳定** |
| 堆排 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 计数 | O(n + k) | O(n + k) | O(k) | 稳定 |

### 图算法复杂度

| 算法 | 时间复杂度 | 空间复杂度 |
|------|:----------:|:----------:|
| DFS/BFS | O(V + E) | O(V) |
| Dijkstra | O((V+E) log V) | O(V) |
| Floyd-Warshall | O(V³) | O(V²) |
| 并查集（路径压缩） | O(α(n)) | O(n) |
| 拓扑排序 | O(V + E) | O(V) |
