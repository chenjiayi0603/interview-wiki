## 一、数组与字符串

### 1.1 数组基础操作

```cpp
int arr[10];
std::vector<int> vec;
```

**有序数组去重**（双指针）：慢指针指向已处理区域末尾，快指针扫描。遇到新元素时慢指针前进并赋值。**复杂度**：O(n) 时间，O(1) 空间。

```cpp
// LeetCode 26: https://leetcode.cn/problems/remove-duplicates-from-sorted-array
int removeDuplicates(vector<int>& nums) {
    if (nums.empty()) return 0;
    int slow = 0;
    for (int fast = 1; fast < nums.size(); ++fast) {
        if (nums[fast] != nums[slow]) {
            nums[++slow] = nums[fast];
        }
    }
    return slow + 1;
}
```

**前缀和 + 哈希表**：`sum[i] - sum[j] = k` → `sum[j] = sum[i] - k`。用哈希表记录每个前缀和首次出现位置。**复杂度**：O(n) 时间，O(n) 空间。**边界**：prefix[0] = -1 处理从开头开始的子数组。

```cpp
// LeetCode 325: https://leetcode.cn/problems/maximum-size-subarray-sum-equals-k
int maxSubArrayLen(vector<int>& nums, int k) {
    unordered_map<int, int> prefix;
    prefix[0] = -1;
    int sum = 0, maxLen = 0;
    for (int i = 0; i < nums.size(); ++i) {
        sum += nums[i];
        if (prefix.count(sum - k))
            maxLen = max(maxLen, i - prefix[sum - k]);
        if (!prefix.count(sum))
            prefix[sum] = i;
    }
    return maxLen;
}
```

## 二、链表

### 2.1 基础结构

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};
```

### 2.2 核心操作

**反转链表**（迭代）：三指针 prev/curr/next 依次逆转指向。**复杂度**：O(n) 时间，O(1) 空间。**边界**：空链表或单节点返回自身。

```cpp
// LeetCode 206: https://leetcode.cn/problems/reverse-linked-list
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr) {
        ListNode* next = curr->next;
        curr->next = prev;
        prev = curr;
        curr = next;
    }
    return prev;
}
```

**环形链表检测**：快慢指针，快 2 慢 1，相遇即有环。**复杂度**：O(n) 时间，O(1) 空间。**易错**：while 条件必须检查 `f && f->next`。

```cpp
// LeetCode 141: https://leetcode.cn/problems/linked-list-cycle
bool hasCycle(ListNode* head) {
    if (!head || !head->next) return false;
    ListNode* slow = head;
    ListNode* fast = head;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}
```

**环形链表入口**：快慢相遇后，快指针回头，同速再相遇即入口。**数学原理**：头→入口距离 = 相遇点→入口距离。

```cpp
// LeetCode 142: https://leetcode.cn/problems/linked-list-cycle-ii
ListNode* detectCycle(ListNode* head) {
    ListNode *s = head, *f = head;
    while (f && f->next) {
        s = s->next;
        f = f->next->next;
        if (s == f) {
            f = head;
            while (s != f) { s = s->next; f = f->next; }
            return s;
        }
    }
    return nullptr;
}
```

**合并两个有序链表**：虚拟头节点 + 双指针遍历。**复杂度**：O(n+m) 时间，O(1) 空间。

```cpp
// LeetCode 21: https://leetcode.cn/problems/merge-two-sorted-lists
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (l1 && l2) {
        if (l1->val < l2->val) { tail->next = l1; l1 = l1->next; }
        else { tail->next = l2; l2 = l2->next; }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}
```

**相交链表**：两指针分别遍历 A→B 和 B→A，相遇点即交点。**复杂度**：O(n+m) 时间，O(1) 空间。

```cpp
// LeetCode 160: https://leetcode.cn/problems/intersection-of-two-linked-lists
ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    ListNode *a = headA, *b = headB;
    while (a != b) {
        a = a ? a->next : headB;
        b = b ? b->next : headA;
    }
    return a;
}
```

**删除倒数第 N 个**：快指针先走 n+1 步，快慢同时走，快到头时慢指针指向待删节点前驱。**复杂度**：O(n) 时间，O(1) 空间。**技巧**：使用虚拟头节点避免处理头节点删除的特例。

```cpp
// LeetCode 19: https://leetcode.cn/problems/remove-nth-node-from-end-of-list
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);
    ListNode *fast = &dummy, *slow = &dummy;
    for (int i = 0; i <= n; ++i) fast = fast->next;
    while (fast) { fast = fast->next; slow = slow->next; }
    slow->next = slow->next->next;
    return dummy.next;
}
```

### 2.3 LRU 缓存

> LeetCode 146: https://leetcode.cn/problems/lru-cache

**思路**：双向链表 + 哈希表，O(1) 时间完成 get/put。链表维护访问顺序（头=最近使用，尾=最久未使用）。哈希表 key → 链表节点指针。get 时移到头部，put 时更新/插入到头部，超容量则删除尾部。

```cpp
class LRUCache {
    struct Node {
        int key, val;
        Node *prev, *next;
        Node(int k, int v) : key(k), val(v), prev(nullptr), next(nullptr) {}
    };
    unordered_map<int, Node*> cache;
    Node *head, *tail;
    int capacity;

    void removeNode(Node* node) {
        node->prev->next = node->next;
        node->next->prev = node->prev;
    }
    void addToHead(Node* node) {
        node->prev = head;
        node->next = head->next;
        head->next->prev = node;
        head->next = node;
    }
    void moveToHead(Node* node) { removeNode(node); addToHead(node); }
    Node* removeTail() {
        Node* node = tail->prev;
        removeNode(node);
        return node;
    }

public:
    LRUCache(int c) : capacity(c) {
        head = new Node(0, 0); tail = new Node(0, 0);
        head->next = tail; tail->prev = head;
    }
    int get(int key) {
        if (!cache.count(key)) return -1;
        moveToHead(cache[key]);
        return cache[key]->val;
    }
    void put(int key, int value) {
        if (cache.count(key)) {
            cache[key]->val = value;
            moveToHead(cache[key]);
        } else {
            Node* node = new Node(key, value);
            cache[key] = node;
            addToHead(node);
            if (cache.size() > capacity) {
                Node* removed = removeTail();
                cache.erase(removed->key);
                delete removed;
            }
        }
    }
};
```
- **复杂度**：get O(1)，put O(1)
- **边界**：capacity ≤ 0 不存在（题目保证 ≥ 1）
- **变体**：LFU 缓存（LeetCode 460）→ 频率维度，双哈希表

## 三、栈与队列

### 3.1 栈

**有效括号**：遇到左括号入栈，右括号与栈顶匹配。**复杂度**：O(n) 时间，O(n) 空间。**边界**：左括号多余或右括号多余都返回 false。

```cpp
// LeetCode 20: https://leetcode.cn/problems/valid-parentheses
bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') { st.push(c); }
        else {
            if (st.empty()) return false;
            char top = st.top(); st.pop();
            if ((c == ')' && top != '(') ||
                (c == ']' && top != '[') ||
                (c == '}' && top != '{')) return false;
        }
    }
    return st.empty();
}
```

**单调栈（下一个更大元素）**：维护递减栈，遇到比栈顶大的元素则弹出并记录结果。循环数组用取模遍历两倍长度。**复杂度**：O(n) 时间，O(n) 空间。**变体**：每日温度（LeetCode 739）、接雨水（LeetCode 42）。

```cpp
// LeetCode 503: https://leetcode.cn/problems/next-greater-element-ii
vector<int> nextGreaterElement(vector<int>& nums) {
    vector<int> res(nums.size(), -1);
    stack<int> st;
    for (int i = 0; i < nums.size() * 2; ++i) {
        while (!st.empty() && nums[i % nums.size()] > nums[st.top()]) {
            res[st.top()] = nums[i % nums.size()];
            st.pop();
        }
        if (i < nums.size()) st.push(i);
    }
    return res;
}
```

**最小栈**：辅助栈同步存储当前最小值。`push` 时如果新值 ≤ 辅助栈顶则入辅助栈；`pop` 时如果栈顶等于辅助栈顶则辅助栈也 pop。**复杂度**：所有操作 O(1)。**变体**：用差值法 O(1) 空间（`stack<long>` 存 diff）。

```cpp
// LeetCode 155: https://leetcode.cn/problems/min-stack
class MinStack {
    stack<int> st, minSt;
public:
    void push(int x) { st.push(x); if (minSt.empty() || x <= minSt.top()) minSt.push(x); }
    void pop() { if (st.top() == minSt.top()) minSt.pop(); st.pop(); }
    int top() { return st.top(); }
    int getMin() { return minSt.top(); }
};
```

### 3.2 队列

**用队列实现栈**：push 时将新元素放到队尾，然后把前面所有元素依次出队再入队，使新元素在队首。**复杂度**：push O(n)，其他 O(1)。**变体**：用栈实现队列（LeetCode 232）→ 双栈，一个输入栈一个输出栈。

```cpp
// LeetCode 225: https://leetcode.cn/problems/implement-stack-using-queues
class MyStack {
    queue<int> q;
public:
    void push(int x) { q.push(x); for (int i = 0; i < q.size()-1; ++i) { q.push(q.front()); q.pop(); } }
    int pop() { int x = q.front(); q.pop(); return x; }
    int top() { return q.front(); }
    bool empty() { return q.empty(); }
};
```

## 四、哈希表

### 4.1 核心原理

哈希表通过哈希函数将 key 映射到数组下标，解决冲突常用**拉链法**（数组 + 链表）或**开放地址法**。查找平均 O(1)，最坏 O(n)。

- 数组 + 链表（拉链法）或开放地址法
- 扰动函数减少碰撞（如 `hash = key ^ (key >> 16)`）
- 负载因子触发扩容（Java 0.75，C++ unordered_map 约 1.0）
- 线程不安全（ConcurrentHashMap 分段锁保证安全）
- **变体**：一致性哈希 → 解决分布式节点增减时的数据迁移问题

### 4.2 布隆过滤器 vs 哈希表

| | 布隆过滤器 | 哈希表 |
|---|-----------|--------|
| 空间 | 省（位数组） | 大（存完整 key） |
| 准确性 | 有假阳性（不存在一定假，存在不一定） | 精确 |
| 适用 | 去重、缓存穿透拦截、黑名单 | 需要精确查找的场景 |
| 删除 | 不支持 | 支持 |

**布隆过滤器原理**：多个哈希函数映射到位数组，查时全部命中才可能存在。**变体**：计数布隆过滤器（支持删除）。

## 五、图

### 5.1 DFS / BFS

**DFS**（深度优先）：递归/栈实现，沿一条路径走到底再回溯。**BFS**（广度优先）：队列实现，逐层遍历，保证最短路径（无权图）。**复杂度**：O(V+E) 时间，O(V) 空间（visited + 栈/队列）。**visited 作用**：防止重复访问和环路死循环。

```cpp
// DFS
void dfs(vector<vector<int>>& graph, int v, vector<bool>& visited) {
    visited[v] = true;
    for (int neighbor : graph[v]) {
        if (!visited[neighbor]) dfs(graph, neighbor, visited);
    }
}

// BFS
vector<int> bfs(vector<vector<int>>& graph, int start) {
    vector<int> res;
    vector<bool> visited(graph.size());
    queue<int> q;
    q.push(start);
    visited[start] = true;
    while (!q.empty()) {
        int v = q.front(); q.pop();
        res.push_back(v);
        for (int neighbor : graph[v]) {
            if (!visited[neighbor]) {
                visited[neighbor] = true;
                q.push(neighbor);
            }
        }
    }
    return res;
}
```

### 5.2 最短路径

**Dijkstra**（单源，非负边）：贪心 + 优先队列。每次选当前距离最小的未处理节点，松弛其邻居。**复杂度**：O((V+E)logV)（优先队列实现）。**局限**：不能处理负权边（负权边用 Bellman-Ford）。**变体**：堆优化 Dijkstra（必须）、双向 Dijkstra（起点终点同时搜索）。

```cpp
// Dijkstra（有权图非负边）
vector<int> dijkstra(int n, vector<vector<pair<int,int>>>& graph, int src) {
    vector<int> dist(n, INT_MAX);
    dist[src] = 0;
    priority_queue<pair<int,int>, vector<pair<int,int>>, greater<>> pq;
    pq.push({0, src});
    while (!pq.empty()) {
        auto [d, u] = pq.top(); pq.pop();
        if (d > dist[u]) continue;          // 过期节点跳过
        for (auto [v, w] : graph[u]) {
            if (dist[v] > dist[u] + w) {
                dist[v] = dist[u] + w;
                pq.push({dist[v], v});
            }
        }
    }
    return dist;
}
```

**Floyd-Warshall**（多源最短路）：动态规划，三层循环枚举中间点 k。**复杂度**：O(V³) 时间，O(V²) 空间。**适用**：小图（V ≤ 500）、需要所有点对距离、可处理负权边（但不能有负环）。

```cpp
// Floyd-Warshall（多源最短路）
void floyd(vector<vector<int>>& dist) {
    int n = dist.size();
    for (int k = 0; k < n; ++k)
        for (int i = 0; i < n; ++i)
            for (int j = 0; j < n; ++j)
                if (dist[i][k] + dist[k][j] < dist[i][j])
                    dist[i][j] = dist[i][k] + dist[k][j];
}
```

### 5.3 并查集（Union-Find）

**思路**：管理元素分组的数据结构。`find` 查所属集合（路径压缩优化），`unite` 合并两集合（按秩合并优化）。两个优化同时使用时时间复杂度接近 O(α(n))（反阿克曼函数，几乎常数）。**应用**：连通分量判断、Kruskal 最小生成树、冗余连接检测。

```cpp
class UnionFind {
    vector<int> parent, rank;
public:
    UnionFind(int n) {
        parent.resize(n); rank.resize(n);
        iota(parent.begin(), parent.end(), 0);  // parent[i] = i
    }
    int find(int x) {
        if (parent[x] != x) parent[x] = find(parent[x]);  // 路径压缩
        return parent[x];
    }
    void unite(int x, int y) {
        int px = find(x), py = find(y);
        if (px == py) return;
        if (rank[px] < rank[py]) swap(px, py);  // 按秩合并
        parent[py] = px;
        if (rank[px] == rank[py]) rank[px]++;
    }
};
```
- **复杂度**：均摊 O(α(n))，α(10⁹) < 5
- **变体**：可撤销并查集（栈记录操作历史）、带权并查集（维护节点到根的距离）
