## 一、快速排序

### 1.1 递归实现

**思路**：选一个基准（pivot），将小于基准的放左边，大于的放右边，基准归位。递归处理左右。应用最广、常数因子最小的 O(n log n) 排序。

```cpp
void qs(vector<int>& v, int l, int r) {
    if (l >= r) return;
    int pi = v[r], k = l;
    for (int i = l; i <= r; i++)
        if (v[i] < pi) swap(v[k++], v[i]);
    swap(v[k], v[r]);
    qs(v, l, k - 1);
    qs(v, k + 1, r);
}
// 调用: qs(v, 0, v.size()-1);
```

| 版本 | 时间复杂度 | 空间 | 稳定 |
|------|:----------:|:----:|:----:|
| 随机选基准 | 平均 O(n log n) | O(log n) | ❌ |
| 最坏（已排序+选最右） | O(n²) | O(n) | ❌ |

**优化**：三数取中（mid = l+(r-l)/2，从 l/mid/r 选中间值做 pivot）、随机选 pivot、小数组切插入排序（一般 n < 16）。

### 1.2 栈模拟递归（DFS）

避免递归栈溢出（深度 > 1000 的场景，如近乎有序的数组）。

```cpp
void qs_stack(vector<int>& v, int l, int r) {
    if (l >= r) return;
    stack<pair<int,int>> s;
    s.push({l, r});
    while (!s.empty()) {
        auto [L, R] = s.top(); s.pop();
        if (L >= R) continue;
        int pi = v[R], k = L;
        for (int i = L; i <= R; i++)
            if (v[i] < pi) swap(v[k++], v[i]);
        swap(v[k], v[R]);
        s.push({k + 1, R});
        s.push({L, k - 1});
    }
}
```

**复杂度**：平均 O(n log n)，最坏 O(n²)（已排序数组+选最右基准），空间 O(log n)

## 二、堆排序

大顶堆下沉建堆，每次取堆顶与末尾交换，重新堆化。

```cpp
void adjust(vector<int>& nums, int l, int r) {
    int pi = nums[l], k = l;
    for (int i = 2*l+1; i <= r; i = 2*i+1) {
        if (i < r && nums[i] < nums[i+1]) i++;
        if (pi >= nums[i]) break;
        nums[k] = nums[i]; k = i;
    }
    nums[k] = pi;
}

void heapSort(vector<int>& nums) {
    // 建堆
    for (int i = nums.size()/2; i >= 0; i--)
        adjust(nums, i, nums.size()-1);
    // 排序
    for (int i = nums.size()-1; i > 0; i--) {
        swap(nums[0], nums[i]);
        adjust(nums, 0, i-1);
    }
}
```

**复杂度**：O(n log n) 原地排序，不稳定

## 三、归并排序

分治思想，左右有序后合并，稳定排序。

```cpp
void mergeSort(vector<int>& nums, int l, int r) {
    if (l >= r) return;
    int m = l + (r - l) / 2;
    mergeSort(nums, l, m);
    mergeSort(nums, m + 1, r);
    vector<int> tmp(r - l + 1);
    int i = l, j = m + 1, k = 0;
    while (i <= m && j <= r) tmp[k++] = nums[i] <= nums[j] ? nums[i++] : nums[j++];
    while (i <= m) tmp[k++] = nums[i++];
    while (j <= r) tmp[k++] = nums[j++];
    for (int i = 0; i < k; i++) nums[l + i] = tmp[i];
}
```

**复杂度**：O(n log n)，空间 O(n)，**稳定排序**

## 四、计数排序（非比较排序）

整数范围有限时使用，O(n + k)。

```cpp
void countingSort(vector<int>& nums, int maxVal) {
    vector<int> count(maxVal + 1);
    for (int x : nums) ++count[x];
    for (int i = 1; i <= maxVal; ++i) count[i] += count[i-1];
    vector<int> tmp(nums.size());
    for (int i = nums.size() - 1; i >= 0; --i)
        tmp[--count[nums[i]]] = nums[i];
    nums = tmp;
}
```

## 五、STL 排序技巧

### 5.1 三种自定义排序方法

```cpp
struct Student { int id; string name; double grade; };

// 方法1：重载 operator<
struct Student {
    int id; string name; double grade;
    bool operator<(const Student& s) { return id < s.id; }
};
sort(V.begin(), V.end());

// 方法2：仿函数
struct Less {
    bool operator()(const Student& s1, const Student& s2) { return s1.id < s2.id; }
};
sort(V.begin(), V.end(), Less());

// 方法3：函数指针
bool cmp(int a, int b) { return a < b; }
sort(A, A + n, cmp);
```

### 5.3 STL sort 底层实现（内省排序）

`std::sort` 不是纯快排，而是**内省排序（introspective sort）**：

1. 默认**快排**，递归深度 `≤ 2log₂n`
2. 深度超限 → 切换**堆排**（保证 O(n log n)）
3. 分区规模 `≤ 16` → 插入排序（小数组常数更优）

稳定排序用 `std::stable_sort`（归并+插入）。

### 5.4 排序选型速查

| 场景 | 推荐 | 原因 |
|------|------|------|
| 通用 | `std::sort`（内省排序） | 平均最快，O(n log n) |
| 需要稳定 | `std::stable_sort` / 归并 | 相等元素保持原序 |
| Top-K 元素 | 堆排序 | 只维护 k 个，海量数据友好 |
| 数据范围 ≤ 10⁷ | 计数排序 | O(n)，但需要整数 |
| 链表排序 | 归并排序 | 链表不支持随机访问 |
| 近乎有序 | 插入排序 | 可降到 O(n) |
| 大量重复值 | 三路快排 | 避免退化为 O(n²) |

## 六、Top-K 问题

### 6.1 小顶堆（O(n log k)）

> LeetCode 215: https://leetcode.cn/problems/kth-largest-element-in-an-array

```cpp
vector<int> topK(vector<int>& nums, int k) {
    priority_queue<int, vector<int>, greater<int>> pq;
    for (int x : nums) {
        pq.push(x);
        if (pq.size() > k) pq.pop();
    }
    vector<int> res;
    while (!pq.empty()) { res.push_back(pq.top()); pq.pop(); }
    return res;
}
```

### 6.2 解法对比

| 解法 | 时间复杂度 | 空间 | 适用场景 |
|------|:----------:|:----:|----------|
| 堆排序 | O(n log k) | O(k) | 海量数据（n 极大） |
| 快速选择（partition） | O(n) 平均 | O(1) | 数据可全部加载 |
| 分治法 | O(n log n) | O(n) | MapReduce 场景 |
