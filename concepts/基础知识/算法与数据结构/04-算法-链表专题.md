## 一、基础操作

### 1.1 反转链表

> LeetCode 206: https://leetcode.cn/problems/reverse-linked-list

**思路**：迭代法——三指针 prev/curr/next 依次逆转每个节点的指向。递归法——假设后续已反转，head->next->next = head 相当于把 head 接到反转后的尾部。

```cpp
// 迭代（面试推荐，不易错）
ListNode* reverseList(ListNode* head) {
    ListNode* prev = nullptr;
    ListNode* curr = head;
    while (curr) {
        ListNode* next = curr->next;  // 保存后继
        curr->next = prev;            // 反转指向
        prev = curr;                  // 前移
        curr = next;
    }
    return prev;
}

// 递归（更简洁）
ListNode* reverseListRecur(ListNode* head) {
    if (!head || !head->next) return head;
    ListNode* newHead = reverseListRecur(head->next);
    head->next->next = head;  // 反转：后一个指向前一个
    head->next = nullptr;
    return newHead;
}
```
- **复杂度**：时间 O(n)，空间 O(1)（迭代）/ O(n)（递归栈）
- **边界**：空链表或单节点返回自身
- **变体**：反转链表前 N 个节点、反转区间（LeetCode 92）、K 个一组翻转（见 1.7）

### 1.2 合并两个有序链表

> LeetCode 21: https://leetcode.cn/problems/merge-two-sorted-lists

```cpp
ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* tail = &dummy;
    while (l1 && l2) {
        if (l1->val < l2->val) { tail->next = l1; l1 = l1->next; }
        else { tail->next = l2; l2 = l2->next; }
        tail = tail->next;
    }
    tail->next = l1 ? l1 : l2;
    return dummy.next;
}
```

### 1.3 合并 K 个升序链表

> LeetCode 23: https://leetcode.cn/problems/merge-k-sorted-lists

```cpp
// 分治合并
ListNode* mergeKLists(vector<ListNode*>& lists) {
    if (lists.empty()) return nullptr;
    int step = 1;
    while (step < lists.size()) {
        for (int i = 0; i + step < lists.size(); i += step * 2)
            lists[i] = mergeTwoLists(lists[i], lists[i + step]);
        step *= 2;
    }
    return lists[0];
}
```

### 1.4 删除链表中的节点

> LeetCode 237: https://leetcode.cn/problems/delete-node-in-a-linked-list

```cpp
// 只给待删除节点，将下一节点值复制过来
void deleteNode(ListNode* node) {
    node->val = node->next->val;
    node->next = node->next->next;
}
```

### 1.5 删除倒数第 N 个节点

> LeetCode 19: https://leetcode.cn/problems/remove-nth-node-from-end-of-list

```cpp
ListNode* removeNthFromEnd(ListNode* head, int n) {
    ListNode dummy(0, head);
    ListNode *fast = &dummy, *slow = &dummy;
    for (int i = 0; i <= n; ++i) fast = fast->next;
    while (fast) { fast = fast->next; slow = slow->next; }
    slow->next = slow->next->next;
    return dummy.next;
}
```

### 1.6 旋转链表

> LeetCode 61: https://leetcode.cn/problems/rotate-list

```cpp
ListNode* rotateRight(ListNode* head, int k) {
    if (!head || !head->next || k == 0) return head;
    int n = 1;
    ListNode* tail = head;
    while (tail->next) { tail = tail->next; n++; }
    k %= n;
    if (k == 0) return head;
    tail->next = head;  // 成环
    for (int i = 0; i < n - k; i++) tail = tail->next;
    head = tail->next;
    tail->next = nullptr;
    return head;
}
```

## 二、链表判环与相交

### 2.1 环形链表检测

> LeetCode 141: https://leetcode.cn/problems/linked-list-cycle

**思路**：快慢指针。快指针每次两步，慢指针每次一步，有环必相遇。相当于追及问题——快指针速度是慢的两倍，在环上总能追上。

```cpp
bool hasCycle(ListNode* head) {
    ListNode *s = head, *f = head;
    while (f && f->next) {
        s = s->next; f = f->next->next;
        if (s == f) return true;
    }
    return false;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **边界**：空链表或单节点无环
- **易错**：while 条件必须检查 `f && f->next`，否则空指针访问

### 2.2 环形链表入口

> LeetCode 142: https://leetcode.cn/problems/linked-list-cycle-ii

**思路**：快慢指针相遇后，快指针回到头，两个慢指针同速前进，再次相遇点就是环入口。数学原理：头到入口距离 = 相遇点到入口距离。

```cpp
ListNode* detectCycle(ListNode* head) {
    ListNode *s = head, *f = head;
    while (f && f->next) {
        s = s->next; f = f->next->next;
        if (s == f) {
            f = head;           // 快指针从头开始
            while (s != f) {    // 同速走到相遇
                s = s->next;
                f = f->next;
            }
            return s;
        }
    }
    return nullptr;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **面试追问**：为什么第二次相遇就是入口？→ 数学推导：头→入口 = 相遇→入口（环上距离）

### 2.3 相交链表

> LeetCode 160: https://leetcode.cn/problems/intersection-of-two-linked-lists

```cpp
ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
    ListNode *a = headA, *b = headB;
    while (a != b) {
        a = a ? a->next : headB;
        b = b ? b->next : headA;
    }
    return a;
}
```

## 三、排序链表

> LeetCode 148: https://leetcode.cn/problems/sort-list

链表的归并排序（与数组不同，需找中点）。

```cpp
ListNode* sortList(ListNode* head) {
    if (!head || !head->next) return head;
    // 快慢指针找中点
    ListNode *slow = head, *fast = head->next;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
    }
    ListNode* mid = slow->next;
    slow->next = nullptr;
    // 分治
    ListNode* left = sortList(head);
    ListNode* right = sortList(mid);
    return mergeTwoLists(left, right);
}
```

## 四、两数相加

> LeetCode 2: https://leetcode.cn/problems/add-two-numbers

逆序链表表示的两个数相加。

```cpp
ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
    ListNode dummy(0);
    ListNode* cur = &dummy;
    int carry = 0;
    while (l1 || l2 || carry) {
        int sum = carry + (l1 ? l1->val : 0) + (l2 ? l2->val : 0);
        cur->next = new ListNode(sum % 10);
        carry = sum / 10;
        if (l1) l1 = l1->next;
        if (l2) l2 = l2->next;
        cur = cur->next;
    }
    return dummy.next;
}
```

## 五、LRU 缓存

> LeetCode 146: https://leetcode.cn/problems/lru-cache

双向链表 + 哈希表，O(1) 时间完成 get/put。

见 **01-基础数据结构.md** 的 LRUCache 完整实现。

**核心思路**：
- get：存在则移到链表头部
- put：存在则更新并移到头部；不存在则新建并添加到头部，超容量则删除尾部
