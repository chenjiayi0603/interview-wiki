## 一、二叉树遍历

### 1.1 前序遍历（根-左-右）

> LeetCode 144: https://leetcode.cn/problems/binary-tree-preorder-traversal

```cpp
// 递归
void preorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    res.push_back(root->val);
    preorder(root->left, res);
    preorder(root->right, res);
}

// 迭代：先压右再压左
vector<int> preorder(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> stk;
    if (root) stk.push(root);
    while (!stk.empty()) {
        auto node = stk.top(); stk.pop();
        res.push_back(node->val);
        if (node->right) stk.push(node->right);
        if (node->left) stk.push(node->left);
    }
    return res;
}
```

### 1.2 中序遍历（左-根-右）

> LeetCode 94: https://leetcode.cn/problems/binary-tree-inorder-traversal

```cpp
// 递归
void inorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    inorder(root->left, res);
    res.push_back(root->val);
    inorder(root->right, res);
}

// 迭代：往左压到底，弹栈即访问
vector<int> inorder(TreeNode* root) {
    vector<int> res;
    stack<TreeNode*> stk;
    TreeNode* cur = root;
    while (cur || !stk.empty()) {
        while (cur) { stk.push(cur); cur = cur->left; }
        cur = stk.top(); stk.pop();
        res.push_back(cur->val);
        cur = cur->right;
    }
    return res;
}
```

### 1.3 后序遍历（左-右-根）

> LeetCode 145: https://leetcode.cn/problems/binary-tree-postorder-traversal

```cpp
// 递归
void postorder(TreeNode* root, vector<int>& res) {
    if (!root) return;
    postorder(root->left, res);
    postorder(root->right, res);
    res.push_back(root->val);
}

// 迭代：按右-左-根 push，再 reverse
vector<int> postorder(TreeNode* root) {
    if (!root) return {};
    vector<int> res;
    stack<TreeNode*> s;
    TreeNode* p = root;
    while (p || !s.empty()) {
        while (p) {
            res.push_back(p->val);
            s.push(p);
            p = p->right;
        }
        p = s.top(); s.pop();
        p = p->left;
    }
    reverse(res.begin(), res.end());
    return res;
}
```

### 1.4 层序遍历（BFS）

> LeetCode 102: https://leetcode.cn/problems/binary-tree-level-order-traversal

**思路**：逐层出队，记录每层节点数。每次处理完整一层，避免混淆层边界。

```cpp
vector<vector<int>> levelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        for (int i = 0; i < sz; i++) {
            auto node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(level);
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(n)
- **易错**：必须用 `sz = q.size()` 固定每层大小，不能直接在循环中用 `q.size()`（会变）
- **变体**：自底向上层序（LeetCode 107）→ 最后 reverse；锯齿形遍历（见 4.4）

## 二、二叉搜索树（BST）

### 2.1 BST 验证

> LeetCode 98: https://leetcode.cn/problems/validate-binary-search-tree

**思路**：BST 性质——左子树所有节点 < 根，右子树所有节点 > 根。递归传递上下界，每个节点检查是否在 `(min, max)` 范围内。中序遍历应该是递增序列，也可用此法。

```cpp
bool isValidBST(TreeNode* root) {
    return validate(root, LONG_MIN, LONG_MAX);
}
bool validate(TreeNode* node, long min, long max) {
    if (!node) return true;
    if (node->val <= min || node->val >= max) return false;
    return validate(node->left, min, node->val) &&
           validate(node->right, node->val, max);
}
```
- **复杂度**：时间 O(n)，空间 O(h)（递归栈深度）
- **易错**：不能只检查 `left->val < root->val < right->val`，必须保证所有祖先约束
- **变体**：中序遍历解法——左→根→右递增，看前驱是否 >= 当前值
- **面试追问**：为什么用 LONG_MIN/LONG_MAX 而不是 INT_MIN/INT_MAX？→ 因为节点值可能等于 INT_MIN

### 2.2 BST 第 K 小（中序遍历）

> LeetCode 230: https://leetcode.cn/problems/kth-smallest-element-in-a-bst

```cpp
int kthSmallest(TreeNode* root, int k) {
    stack<TreeNode*> stk;
    TreeNode* p = root;
    int cnt = 0;
    while (p || !stk.empty()) {
        while (p) { stk.push(p); p = p->left; }
        p = stk.top(); stk.pop();
        if (++cnt == k) return p->val;
        p = p->right;
    }
    return -1;
}
```

### 2.3 BST 插入

> LeetCode 701: https://leetcode.cn/problems/insert-into-a-binary-search-tree

```cpp
TreeNode* insertIntoBST(TreeNode* root, int val) {
    if (!root) return new TreeNode(val);
    if (val < root->val) root->left = insertIntoBST(root->left, val);
    else root->right = insertIntoBST(root->right, val);
    return root;
}
```

## 三、LCA 与路径问题

### 3.1 二叉树最近公共祖先

> LeetCode 236: https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree

**思路**：后序遍历。如果当前节点是 p 或 q，直接返回。分别去左右子树找 p、q。如果左右都找到了，说明当前节点就是 LCA；只找到一边，返回那边。核心思想：**p 和 q 分别在左右子树时，当前节点就是 LCA**。

```cpp
TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    if (!root || root == p || root == q) return root;
    auto L = lowestCommonAncestor(root->left, p, q);
    auto R = lowestCommonAncestor(root->right, p, q);
    return L && R ? root : (L ? L : R);
}
```
- **复杂度**：时间 O(n)，空间 O(h)
- **边界**：如果 p 或 q 不存在，算法会返回存在的那个（面试题通常保证都存在）
- **变体**：BST 的 LCA（见 3.2）只需比较值即可，O(h)；找两个节点的最近公共祖先的路径（LeetCode 1644）

### 3.2 BST 最近公共祖先

> LeetCode 235: https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-search-tree

```cpp
TreeNode* lowestCommonAncestorBST(TreeNode* root, TreeNode* p, TreeNode* q) {
    while (root) {
        if (max(p->val, q->val) < root->val) root = root->left;
        else if (min(p->val, q->val) > root->val) root = root->right;
        else return root;
    }
    return root;
}
```

### 3.3 二叉树最大路径和

> LeetCode 124: https://leetcode.cn/problems/binary-tree-maximum-path-sum

```cpp
int maxPathSum(TreeNode* root) {
    int ans = INT_MIN;
    function<int(TreeNode*)> dfs = [&](TreeNode* node) {
        if (!node) return 0;
        int L = max(0, dfs(node->left));
        int R = max(0, dfs(node->right));
        ans = max(ans, node->val + L + R);
        return node->val + max(L, R);
    };
    dfs(root);
    return ans;
}
```

### 3.4 二叉树最大 / 最小深度

> 最大深度 LeetCode 104: https://leetcode.cn/problems/maximum-depth-of-binary-tree
> 最小深度 LeetCode 111: https://leetcode.cn/problems/minimum-depth-of-binary-tree

```cpp
int maxDepth(TreeNode* root) {
    if (!root) return 0;
    return max(maxDepth(root->left), maxDepth(root->right)) + 1;
}

int minDepth(TreeNode* root) {
    if (!root) return 0;
    if (!root->left) return minDepth(root->right) + 1;
    if (!root->right) return minDepth(root->left) + 1;
    return min(minDepth(root->left), minDepth(root->right)) + 1;
}
```

### 3.5 路径总和 III

> LeetCode 437: https://leetcode.cn/problems/path-sum-iii

```cpp
// 路径和等于 targetSum 的路径数（不要求从根开始）
int pathSum(TreeNode* root, int targetSum) {
    unordered_map<long, int> prefix;
    prefix[0] = 1;
    function<int(TreeNode*, long)> dfs = [&](TreeNode* node, long cur) {
        if (!node) return 0;
        cur += node->val;
        int res = prefix[cur - targetSum];
        prefix[cur]++;
        res += dfs(node->left, cur) + dfs(node->right, cur);
        prefix[cur]--;
        return res;
    };
    return dfs(root, 0);
}
```

## 四、BFS 应用

### 4.1 二叉树的右视图

> LeetCode 199: https://leetcode.cn/problems/binary-tree-right-side-view

```cpp
vector<int> rightSideView(TreeNode* root) {
    vector<int> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        for (int i = 0; i < sz; i++) {
            auto node = q.front(); q.pop();
            if (i == sz - 1) res.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
    }
    return res;
}
```

### 4.2 对称二叉树

> LeetCode 101: https://leetcode.cn/problems/symmetric-tree

```cpp
bool isSymmetric(TreeNode* root) {
    if (!root) return true;
    function<bool(TreeNode*, TreeNode*)> check = [&](TreeNode* l, TreeNode* r) {
        if (!l && !r) return true;
        if (!l || !r || l->val != r->val) return false;
        return check(l->left, r->right) && check(l->right, r->left);
    };
    return check(root->left, root->right);
}
```

### 4.3 二叉树的层平均值

> LeetCode 637: https://leetcode.cn/problems/average-of-levels-in-binary-tree

```cpp
vector<double> averageOfLevels(TreeNode* root) {
    vector<double> res;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int sz = q.size();
        double sum = 0;
        for (int i = 0; i < sz; i++) {
            auto node = q.front(); q.pop();
            sum += node->val;
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        res.push_back(sum / sz);
    }
    return res;
}
```

### 4.4 锯齿形层序遍历

> LeetCode 103: https://leetcode.cn/problems/binary-tree-zigzag-level-order-traversal

```cpp
vector<vector<int>> zigzagLevelOrder(TreeNode* root) {
    vector<vector<int>> res;
    if (!root) return res;
    queue<TreeNode*> q;
    q.push(root);
    bool rev = false;
    while (!q.empty()) {
        int sz = q.size();
        vector<int> level;
        for (int i = 0; i < sz; i++) {
            auto node = q.front(); q.pop();
            level.push_back(node->val);
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        if (rev) reverse(level.begin(), level.end());
        res.push_back(level);
        rev = !rev;
    }
    return res;
}
```

## 五、构造二叉树

### 5.1 前序 + 中序

> LeetCode 105: https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal

```cpp
TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
    unordered_map<int, int> idx;
    for (int i = 0; i < inorder.size(); i++) idx[inorder[i]] = i;
    function<TreeNode*(int, int, int, int)> build = [&](int pl, int pr, int il, int ir) {
        if (pl > pr) return (TreeNode*)nullptr;
        auto root = new TreeNode(preorder[pl]);
        int k = idx[root->val];
        int leftLen = k - il;
        root->left = build(pl+1, pl+leftLen, il, k-1);
        root->right = build(pl+leftLen+1, pr, k+1, ir);
        return root;
    };
    return build(0, preorder.size()-1, 0, inorder.size()-1);
}
```

### 5.2 中序 + 后序

> LeetCode 106: https://leetcode.cn/problems/construct-binary-tree-from-inorder-and-postorder-traversal

```cpp
TreeNode* buildTree(vector<int>& inorder, vector<int>& postorder) {
    unordered_map<int, int> idx;
    for (int i = 0; i < inorder.size(); i++) idx[inorder[i]] = i;
    function<TreeNode*(int, int, int, int)> build = [&](int il, int ir, int pl, int pr) {
        if (il > ir) return (TreeNode*)nullptr;
        auto root = new TreeNode(postorder[pr]);
        int k = idx[root->val];
        root->left = build(il, k-1, pl, pl + (k-il) - 1);
        root->right = build(k+1, ir, pl + (k-il), pr-1);
        return root;
    };
    return build(0, inorder.size()-1, 0, postorder.size()-1);
}
```
