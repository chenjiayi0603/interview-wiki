# 动态规划

> 线性 DP、背包问题、LCS/LIS、股票买卖、区间 DP —— 核心思路是"定义状态 → 推导转移方程 → 初始化 → 迭代求解"。

---

## 一、线性 DP

### 1.1 斐波那契 / 爬楼梯

> LeetCode 70: https://leetcode.cn/problems/climbing-stairs

**思路**：到达第 i 阶可以从 i-1 或 i-2 阶过来，所以 `f(i) = f(i-1) + f(i-2)`。本质就是斐波那契，滚动变量优化 O(1) 空间。

```cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int a = 1, b = 2;
    for (int i = 3; i <= n; ++i) {
        int c = a + b;
        a = b; b = c;
    }
    return b;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **变体**：每次可走 1/2/3 步 → `dp[i] = dp[i-1] + dp[i-2] + dp[i-3]`；最小花费爬楼梯（LeetCode 746）

### 1.2 最长连续递增序列

> LeetCode 674: https://leetcode.cn/problems/longest-continuous-increasing-subsequence

**思路**：子序列必须连续，只要 `nums[i] > nums[i-1]` 就延续递增，否则重置为 1。实时取最大值。

```cpp
int findLengthOfLCIS(vector<int>& nums) {
    if (nums.empty()) return 0;
    int res = 1, cur = 1;
    for (int i = 1; i < nums.size(); i++) {
        cur = nums[i] > nums[i-1] ? cur + 1 : 1;
        res = max(res, cur);
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **对比**：下面 LIS 不要求连续，难度完全不同

### 1.3 最长上升子序列（LIS）

> LeetCode 300: https://leetcode.cn/problems/longest-increasing-subsequence

**O(n²) 思路**：`dp[i]` 表示以 nums[i] 结尾的 LIS 长度。遍历 j < i，若 `nums[j] < nums[i]` 则 `dp[i] = max(dp[i], dp[j] + 1)`。O(n²) 超大规模会超时。

**O(n log n) 思路**：`tails[i]` 维护长度为 i+1 的上升子序列的最小末尾值。用贪心 + 二分，新数替换 tails 中第一个 ≥ 它的位置。正确性：tails 越长，越有机会在后面接上更大值。

```cpp
// O(n²) DP
int lengthOfLIS(vector<int>& nums) {
    int n = nums.size(), res = 1;
    vector<int> dp(n, 1);
    for (int i = 1; i < n; i++) {
        for (int j = 0; j < i; j++)
            if (nums[j] < nums[i]) dp[i] = max(dp[i], dp[j] + 1);
        res = max(res, dp[i]);
    }
    return res;
}

// O(n log n) 贪心 + 二分（面试推荐，必须手写）
int lengthOfLIS(vector<int>& nums) {
    vector<int> tails;
    for (int x : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
```
- **复杂度**：O(n²) / O(n log n)，空间 O(n)
- **边界**：空数组返回 0
- **变体**：最长递减子序列 → 取负或反向比较；最长山脉数组（LeetCode 845）

### 1.4 最大子序和

> LeetCode 53: https://leetcode.cn/problems/maximum-subarray

**思路**：`dp[i]` 以 i 结尾的最大子数组和。要么自己单干（nums[i]），要么延续之前的（cur + nums[i]）。Kadane 算法。

```cpp
int maxSubArray(vector<int>& nums) {
    int cur = nums[0], res = nums[0];
    for (int i = 1; i < nums.size(); i++) {
        cur = max(nums[i], cur + nums[i]);
        res = max(res, cur);
    }
    return res;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **变体**：最大子矩阵（按行压缩成一维再 Kadane）；乘积最大子数组（LeetCode 152，需同时维护最大值和最小值）

## 二、背包问题

### 2.1 0-1 背包

**思路**：`dp[w]` 表示容量 w 能装的最大价值。每个物品选或不选。**倒序遍历容量**保证每个物品只用一次。

```cpp
// W = 总容量, wt = 重量, val = 价值, n = 物品数
int knapSack(int W, vector<int>& wt, vector<int>& val, int n) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; ++i)
        for (int w = W; w >= wt[i]; --w)  // 倒序！避免重复使用同一物品
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
    return dp[W];
}
```
- **复杂度**：时间 O(nW)，空间 O(W)
- **边界**：W=0 或 n=0 返回 0
- **变体**：分割等和子集（LeetCode 416）→ 容量 = sum/2；目标和（LeetCode 494）

### 2.2 完全背包

**思路**：和 0-1 背包的唯一区别：**正序遍历容量**，允许同一物品选多次。

```cpp
int completeKnapSack(int W, vector<int>& wt, vector<int>& val, int n) {
    vector<int> dp(W + 1, 0);
    for (int i = 0; i < n; ++i)
        for (int w = wt[i]; w <= W; ++w)  // 正序！允许重复选
            dp[w] = max(dp[w], dp[w - wt[i]] + val[i]);
    return dp[W];
}
```
- **复杂度**：时间 O(nW)，空间 O(W)
- **变体**：零钱兑换（LeetCode 322）→ 求最少硬币数；组合总和 IV（LeetCode 377）→ 求排列数（先遍历容量再遍历物品）

### 2.3 不同路径

> LeetCode 62: https://leetcode.cn/problems/unique-paths

**思路**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。第一行和第一列只有一条路径。空间优化为一维：`dp[j] += dp[j-1]`。

```cpp
int uniquePaths(int m, int n) {
    vector<int> dp(n, 1);
    for (int i = 1; i < m; i++)
        for (int j = 1; j < n; j++)
            dp[j] += dp[j-1];
    return dp[n-1];
}
```
- **复杂度**：时间 O(mn)，空间 O(n)
- **变体**：带障碍物的不同路径（LeetCode 63）→ 有障碍物则 dp = 0；不同路径 III（LeetCode 980）→ 回溯

## 三、字符串 DP

### 3.1 最长公共子序列（LCS）

> LeetCode 1143: https://leetcode.cn/problems/longest-common-subsequence

**思路**：`dp[i][j]` 表示 s1[0..i-1] 和 s2[0..j-1] 的 LCS 长度。字符相等则加 1，不等则取上方或左方的较大值。

```cpp
int longestCommonSubsequence(string s1, string s2) {
    int m = s1.size(), n = s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1));
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1] + 1;
            else
                dp[i][j] = max(dp[i-1][j], dp[i][j-1]);
        }
    }
    return dp[m][n];
}
```
- **复杂度**：时间 O(mn)，空间 O(mn)，可优化为 O(min(m,n))
- **边界**：任一字符串为空返回 0
- **变体**：最长公共子串 → 要求连续，相等时 `dp[i][j] = dp[i-1][j-1] + 1`，否则为 0

### 3.2 编辑距离

> LeetCode 72: https://leetcode.cn/problems/edit-distance

**思路**：`dp[i][j]` 表示 s1[0..i-1] 转换为 s2[0..j-1] 的最小操作数。三种操作：插入 `dp[i][j-1] + 1`、删除 `dp[i-1][j] + 1`、替换 `dp[i-1][j-1] + 1`。遍历时取三者最小值。

```cpp
int minDistance(string s1, string s2) {
    int m = s1.size(), n = s2.size();
    vector<vector<int>> dp(m + 1, vector<int>(n + 1));
    for (int i = 0; i <= m; ++i) dp[i][0] = i;
    for (int j = 0; j <= n; ++j) dp[0][j] = j;
    for (int i = 1; i <= m; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (s1[i-1] == s2[j-1])
                dp[i][j] = dp[i-1][j-1];
            else
                dp[i][j] = 1 + min({dp[i-1][j], dp[i][j-1], dp[i-1][j-1]});
        }
    }
    return dp[m][n];
}
```
- **复杂度**：时间 O(mn)，空间 O(mn)
- **边界**：空字符串的距离 = 非空字符串长度
- **变体**：一次编辑（LeetCode 161）→ 距离是否 ≤ 1；最长回文子串也可以用 DP（见下一题）

### 3.3 最长回文子串

> LeetCode 5: https://leetcode.cn/problems/longest-palindromic-substring

**思路**：`dp[i][j]` 表示 s[i..j] 是否回文。长度为 1 必回文，长度为 2 字符相等即回文，长度 > 2 则 `dp[i][j] = (s[i]==s[j] && dp[i+1][j-1])`。按长度从小到大遍历。

```cpp
string longestPalindrome(string s) {
    int n = s.size(), start = 0, maxLen = 1;
    vector<vector<bool>> dp(n, vector<bool>(n, false));
    for (int i = 0; i < n; i++) dp[i][i] = true;
    for (int len = 2; len <= n; len++) {
        for (int i = 0; i + len - 1 < n; i++) {
            int j = i + len - 1;
            if (s[i] == s[j] && (len <= 2 || dp[i+1][j-1])) {
                dp[i][j] = true;
                if (len > maxLen) { start = i; maxLen = len; }
            }
        }
    }
    return s.substr(start, maxLen);
}
```
- **复杂度**：时间 O(n²)，空间 O(n²)，可用中心扩展法优化到 O(1) 空间
- **边界**：空字符串或单字符
- **变体**：回文子串个数（LeetCode 647）→ 同上 DP 计数

## 四、股票问题

### 4.1 通用状态机模板

> LeetCode 121-123, 188, 309, 714: 一系列股票买卖问题

**核心思路**：每天只有两种状态——持有（buy）或卖出（sell）。无限交易时，`buy = max(buy, sell - prices[i])`（买入用之前赚的利润抵消成本），`sell = max(sell, buy + prices[i])`。限制交易次数时，多开几组变量分别表示第 k 次买入/卖出。

```cpp
// 不限交易次数（LeetCode 122）
int maxProfitII(vector<int>& prices) {
    if (prices.empty()) return 0;
    int buy = -prices[0], sell = 0;
    for (int i = 1; i < prices.size(); ++i) {
        buy = max(buy, sell - prices[i]);
        sell = max(sell, buy + prices[i]);
    }
    return sell;
}

// 限制最多 2 次交易（LeetCode 123，困难）
int maxProfitIII(vector<int>& prices) {
    int b1 = INT_MIN, b2 = INT_MIN;
    int s1 = 0, s2 = 0;
    for (int p : prices) {
        b1 = max(b1, -p);          // 第1次买入
        s1 = max(s1, b1 + p);       // 第1次卖出
        b2 = max(b2, s1 - p);       // 第2次买入（用第1次利润抵成本）
        s2 = max(s2, b2 + p);       // 第2次卖出
    }
    return s2;
}
```
- **复杂度**：时间 O(n)，空间 O(1)
- **变体**：含冷冻期（LeetCode 309）→ 卖出的下一天不能买，多一个 preSell 变量；含手续费（LeetCode 714）→ 卖出时扣手续费

## 五、其他经典 DP

### 5.1 完全平方数

> LeetCode 279: https://leetcode.cn/problems/perfect-squares

**思路**：`dp[i]` 表示 i 的最少完全平方数个数。对每个小于 i 的平方数 j*j，`dp[i] = min(dp[i], dp[i - j*j] + 1)`。

```cpp
int numSquares(int n) {
    vector<int> dp(n + 1, INT_MAX);
    dp[0] = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j * j <= i; j++)
            dp[i] = min(dp[i], dp[i - j*j] + 1);
    return dp[n];
}
```
- **复杂度**：时间 O(n√n)，空间 O(n)
- **边界**：n=0 返回 0
- **变体**：每个平方数可使用多次 → 类似完全背包

### 5.2 丑数 II

> LeetCode 264: https://leetcode.cn/problems/ugly-number-ii

**思路**：三指针法，每个丑数乘以 2/3/5 产生下一个候选。dp[i] 表示第 i 个丑数，三指针指向 dp 中还未乘过对应因子的位置。

```cpp
int nthUglyNumber(int n) {
    vector<int> dp(n);
    dp[0] = 1;
    int p2 = 0, p3 = 0, p5 = 0;
    for (int i = 1; i < n; i++) {
        dp[i] = min({dp[p2]*2, dp[p3]*3, dp[p5]*5});
        if (dp[i] == dp[p2]*2) p2++;
        if (dp[i] == dp[p3]*3) p3++;
        if (dp[i] == dp[p5]*5) p5++;
    }
    return dp[n-1];
}
```
- **复杂度**：时间 O(n)，空间 O(n)
- **边界**：n=1 返回 1
- **变体**：超级丑数（LeetCode 313）→ 质因数列表不固定

### 5.3 单词拆分

> LeetCode 139: https://leetcode.cn/problems/word-break

**思路**：`dp[i]` 表示 s[0..i-1] 能否被拆分成字典中的单词。对每个 i，遍历所有可能的切割点 j，若 `dp[j]` 为 true 且 s[j..i-1] 在字典中，则 `dp[i] = true`。

```cpp
bool wordBreak(string s, vector<string>& wordDict) {
    unordered_set<string> dict(wordDict.begin(), wordDict.end());
    vector<bool> dp(s.size() + 1, false);
    dp[0] = true;  // 空字符串可拆分
    for (int i = 1; i <= s.size(); i++)
        for (int j = 0; j < i; j++)
            if (dp[j] && dict.count(s.substr(j, i - j)))
                { dp[i] = true; break; }  // 找到就行
    return dp[s.size()];
}
```
- **复杂度**：时间 O(n²)，空间 O(n + dict 大小)
- **边界**：空字符串返回 true
- **变体**：单词拆分 II（LeetCode 140）→ 返回所有拆法，用记忆化 DFS

## 附：DP 解题四步法

1. **状态定义**：`dp[i]` / `dp[i][j]` 表示什么
2. **转移方程**：当前状态如何从之前状态推导过来
3. **初始化**：边界条件（dp[0]、dp[i][0]、dp[0][j]）
4. **迭代方向**：按什么顺序填表（正序/倒序、按长度/按坐标）

**常见错误**：
- 状态定义模糊 → 先写清楚"dp[i] 表示以 i 结尾..."还是"dp[i] 表示前 i 个..."
- 忘记初始化边界 → 画个表格，把第一行第一列填好
- 背包容量遍历方向搞反 → 0-1 背包倒序，完全背包正序
