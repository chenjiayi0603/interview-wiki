## 一、位运算

### 1.1 核心技巧

| 操作 | 表达式 | 说明 |
|------|--------|------|
| 取最低位的 1 | `x & -x` | 如 `6(110)` → `2(010)` |
| 去掉最低位的 1 | `x & (x-1)` | 如 `6(110)` → `4(100)` |
| 相同异或为 0 | `x ^ x = 0` | 用于找出现奇数次的数 |
| 判断奇偶 | `x & 1` | 1 为奇，0 为偶 |
| 判断 2 的幂 | `x > 0 && (x & (x-1)) == 0` | — |
| 第 k 位 | `(x >> k) & 1` | 取第 k 位值 |

### 1.2 只出现一次的数字

> LeetCode 136: https://leetcode.cn/problems/single-number

**思路**：异或运算——相同数异或为 0，任何数与 0 异或不变。所有数异或一遍，剩下的就是出现一次的数。**复杂度**：O(n) 时间，O(1) 空间。**变体**：找出两个只出现一次的数（见 1.3），需要分组异或。

```cpp
int singleNumber(vector<int>& nums) {
    int res = 0;
    for (int x : nums) res ^= x;
    return res;
}
```

### 1.3 只出现一次的数字 III

> LeetCode 260: https://leetcode.cn/problems/single-number-iii

**思路**：全部异或得到 xorAll = a ^ b。用 lowbit（xorAll 最低位的 1）将原数组分为两组——该位为 0 和为 1，a 和 b 必然分到不同组。组内分别异或即得结果。**复杂度**：O(n) 时间，O(1) 空间。

```cpp
vector<int> singleNumberIII(vector<int>& nums) {
    int xorAll = 0;
    for (int x : nums) xorAll ^= x;
    int lowbit = xorAll & -xorAll;  // 取最低位的 1 作为分组依据
    int a = 0, b = 0;
    for (int x : nums) {
        if (x & lowbit) a ^= x;
        else b ^= x;
    }
    return {a, b};
}
```

### 1.4 数字范围按位与

> LeetCode 201: https://leetcode.cn/problems/bitwise-and-of-numbers-range

**思路**：求 [m, n] 区间所有数的按位与，等价于找 m 和 n 的公共前缀（二进制）。不断右移 m 和 n 直到相等，记录移位数，最后左移回去。**原理**：区间内所有数的公共前缀之外的位必然出现过 0。**复杂度**：O(log n) 时间，O(1) 空间。

```cpp
int rangeBitwiseAnd(int m, int n) {
    int shift = 0;
    while (m < n) { m >>= 1; n >>= 1; shift++; }
    return m << shift;
}
```
- **变体**：也可用 `n & (n-1)` 直接清除低位的 1 直到 n ≤ m

## 二、数学运算

### 2.1 Pow(x, n) — 二分求幂

> LeetCode 50: https://leetcode.cn/problems/powx-n

**思路**：快速幂——将指数按二进制展开，每次平方底数。如 x¹³ = x⁸ · x⁴ · x¹。**注意**：INT_MIN 取反溢出，用 long 接收。时间复杂度 O(log n)。

```cpp
double myPow(double x, int n) {
    if (n == 0) return 1;
    long N = n;  // 防止 INT_MIN 取反溢出
    if (N < 0) { x = 1 / x; N = -N; }
    double res = 1;
    while (N) {
        if (N & 1) res *= x;  // 当前位为 1，乘入结果
        x *= x;               // 底数平方
        N >>= 1;              // 指数右移
    }
    return res;
}
```
- **复杂度**：O(log n) 时间，O(1) 空间
- **边界**：x=0, n=0, n=INT_MIN
- **变体**：快速幂求矩阵幂（用于斐波那契数列 O(log n) 求解）

### 2.2 两数相除（减法代替除法）

> LeetCode 29: https://leetcode.cn/problems/divide-two-integers

**思路**：不用乘除取模实现除法。用**倍增减法**——不断将除数翻倍（左移），从被除数中减去尽可能大的倍数。**核心技巧**：`t <<= 1` 相当于 `t *= 2`，找到最大的 t 使 `m >= t`。**边界**：INT_MIN / -1 溢出，返回 INT_MAX。

```cpp
int divide(int dividend, int divisor) {
    if (dividend == INT_MIN && divisor == -1) return INT_MAX;  // 溢出
    long m = labs(dividend), n = labs(divisor), res = 0;
    int sign = (dividend < 0) ^ (divisor < 0) ? -1 : 1;
    while (m >= n) {
        long t = n, c = 1;
        while (m >= (t << 1)) { t <<= 1; c <<= 1; }  // 翻倍
        m -= t; res += c;
    }
    return sign * res;
}
```
- **复杂度**：O(log²n) 时间（外层 O(log n)，内层 O(log n)），可优化到 O(log n)
- **变体**：不用 long 的实现——注意负数范围比正数大 1

### 2.3 计数质数

> LeetCode 204: https://leetcode.cn/problems/count-primes

**思路**：埃拉托斯特尼筛法——从 2 开始，将每个质数的倍数标记为合数。**优化**：从 `i*i` 开始标记（因为更小的倍数已被更小的质数标记），j 步进 i。**复杂度**：O(n log log n) 时间，O(n) 空间。

```cpp
int countPrimes(int n) {
    if (n <= 2) return 0;
    vector<bool> isPrime(n, true);
    isPrime[0] = isPrime[1] = false;
    for (int i = 2; i * i < n; i++)
        if (isPrime[i])
            for (int j = i * i; j < n; j += i)  // 从 i*i 开始标记
                isPrime[j] = false;
    return count(isPrime.begin(), isPrime.end(), true);
}
```
- **变体**：线性筛（欧拉筛）→ 每个合数只被标记一次，O(n)

### 2.4 整数反转 / 回文数

> LeetCode 7: https://leetcode.cn/problems/reverse-integer
> LeetCode 9: https://leetcode.cn/problems/palindrome-number

**整数反转**：逐位取模构建反转值，注意溢出返回 0。**复杂度**：O(log x) 时间（位数），O(1) 空间。

```cpp
int reverse(int x) {
    long res = 0;
    while (x) { res = res * 10 + x % 10; x /= 10; }
    return (res > INT_MAX || res < INT_MIN) ? 0 : (int)res;
}
```

**回文数**：反转一半数字与另一半比较。**技巧**：只反转后半部分（当 `x > rev` 时继续），避免溢出。**边界**：负数或末位为 0 的非零数不是回文。

```cpp
bool isPalindrome(int x) {
    if (x < 0 || (x % 10 == 0 && x != 0)) return false;
    int rev = 0;
    while (x > rev) { rev = rev * 10 + x % 10; x /= 10; }
    return x == rev || x == rev / 10;  // 奇偶长度处理
}
```

### 2.5 多数元素（摩尔投票）

> LeetCode 169: https://leetcode.cn/problems/majority-element

**思路**：摩尔投票算法——成对抵消。不同元素相互抵消，剩下的就是出现次数 > ⌊n/2⌋ 的元素。**核心原理**：多数元素的出现次数 > 其他所有元素出现次数之和。**复杂度**：O(n) 时间，O(1) 空间。**变体**：找出现次数 > ⌊n/3⌋ 的元素（LeetCode 229）→ 两个候选。

```cpp
int majorityElement(vector<int>& nums) {
    int candidate = 0, count = 0;
    for (int x : nums) {
        if (count == 0) candidate = x;    // 更新候选
        count += (x == candidate) ? 1 : -1;  // 投票或抵消
    }
    return candidate;
}
```

## 三、二分搜索

### 3.1 搜索旋转排序数组

> LeetCode 33: https://leetcode.cn/problems/search-in-rotated-sorted-array

**思路**：二分搜索——旋转数组的特点是"总有一半是有序的"。判断 `nums[l] <= nums[mid]` 来确定哪半有序，然后在有序半段中判断 target 是否在其中，缩小搜索范围。**复杂度**：O(log n) 时间，O(1) 空间。**边界**：空数组返回 -1；旋转 0 个元素也适用。

```cpp
int search(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        if (nums[l] <= nums[mid]) {         // 左半有序
            if (target >= nums[l] && target < nums[mid]) r = mid - 1;
            else l = mid + 1;
        } else {                            // 右半有序
            if (target > nums[mid] && target <= nums[r]) l = mid + 1;
            else r = mid - 1;
        }
    }
    return -1;
}
```
- **变体**：有重复元素的旋转数组（LeetCode 81）→ 当 `nums[l]==nums[mid]==nums[r]` 时退化为 O(n)

### 3.2 寻找两个正序数组的中位数

> LeetCode 4: https://leetcode.cn/problems/median-of-two-sorted-arrays

**思路**：二分 + 划分数组。在较短的数组上二分切分位置 i，计算另一数组切分位置 j = (m+n+1)/2 - i。保证左半所有元素 ≤ 右半所有元素（即 `nums1[i-1] ≤ nums2[j]` 且 `nums2[j-1] ≤ nums1[i]`）。**复杂度**：O(log(min(m,n))) 时间，O(1) 空间。

```cpp
double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
    if (nums1.size() > nums2.size()) swap(nums1, nums2);  // 确保 nums1 较短
    int m = nums1.size(), n = nums2.size();
    int l = 0, r = m;
    while (l <= r) {
        int i = (l + r) / 2;
        int j = (m + n + 1) / 2 - i;
        int leftMax1  = (i == 0) ? INT_MIN : nums1[i-1];
        int rightMin1 = (i == m) ? INT_MAX : nums1[i];
        int leftMax2  = (j == 0) ? INT_MIN : nums2[j-1];
        int rightMin2 = (j == n) ? INT_MAX : nums2[j];
        if (leftMax1 <= rightMin2 && leftMax2 <= rightMin1) {
            if ((m + n) % 2 == 0)
                return (max(leftMax1, leftMax2) + min(rightMin1, rightMin2)) / 2.0;
            else
                return max(leftMax1, leftMax2);
        } else if (leftMax1 > rightMin2) {
            r = i - 1;   // i 太大，左移
        } else {
            l = i + 1;   // i 太小，右移
        }
    }
    return 0;
}
```
- **边界**：处理 i=0 / i=m / j=0 / j=n 的边缘情况用 ±INT_MAX
- **变体**：两个有序数组的第 K 小元素 → 类似思路，递归排除较小的一半

## 四、高频面试题速记

### Q1: HashMap 实现原理？
- **数据结构**：数组 + 链表（JDK 8+ 链表长度 ≥ 8 转红黑树）
- **put 流程**：计算 hash → 定位桶 → 插入链表尾部（尾插法）
- **扰动函数**：`hash = key.hashCode() ^ (key.hashCode() >>> 16)` 混合高低位，减少碰撞
- **负载因子**：默认 0.75，超过时扩容为 2 倍并 rehash
- **线程安全**：不安全（扩容时头插法可能死循环）；ConcurrentHashMap 用分段锁/CAS 保证安全

### Q2: 红黑树和 AVL 树区别？
- **平衡度**：AVL 更严格（左右子树高度差 ≤ 1），红黑树较松（最长路径 ≤ 2 倍最短路径）
- **查找**：AVL 更快（更平衡），O(log n)
- **插入/删除**：红黑树开销小（旋转少），AVL 可能需要多次旋转
- **适用**：AVL 适合查多写少（数据库索引）；红黑树适合写多查多（`std::map`, Java TreeMap）
- **C++ `std::map`**：红黑树实现，有序关联容器

### Q3: 一致性哈希？
- **问题**：普通哈希取模在增删节点时导致大量 key 迁移
- **方案**：哈希环 0~2³²-1，节点和 key 都哈希到环上，key 顺时针找第一个节点
- **虚拟节点**：每个物理节点复制多个虚拟节点，解决数据倾斜
- **应用**：Redis 集群、分布式缓存、负载均衡

### Q4: LRU 和 LFU 的区别？
- **LRU（最近最少使用）**：时间维度，最近访问的保留。实现：双向链表 + 哈希表 O(1)
- **LFU（最不经常使用）**：频率维度，访问次数最少的淘汰。实现：双哈希表（频率→key列表 + key→频率值）O(log n) 或 O(1)
- **适用场景**：LRU 适合局部性强的访问模式；LFU 适合突发流量后冷热分明的场景

### Q5: 跳表为什么广泛应用？
- **结构**：多层链表，每层是下层的"快速通道"
- **优点**：实现简单（比红黑树好写）；范围查询 O(log n + k) 高效；插入删除 O(log n) 概率保证；无锁并发友好（可 CAS 指针）
- **Redis ZSet**：有序集合用跳表 + 哈希表实现
- **时间/空间**：O(log n) 平均，空间 O(n)

### Q6: 布隆过滤器？
- **原理**：位数组 + k 个哈希函数。插入时 k 个位置置 1；查询时全部为 1 才可能存在
- **特点**：不存在一定不存在（无假阴性），存在不一定存在（有假阳性）
- **不能删除**：多位映射同一位，删一位会影响其他元素（计数 BF 可解决）
- **应用**：缓存穿透拦截、黑名单、爬虫 URL 去重、数据库查询优化
- **参数**：位数组大小 m、哈希函数数 k、预期元素数 n 决定假阳性率

### Q7: Top-K 解法总结？

| 解法 | 时间复杂度 | 空间 | 适合场景 |
|------|:----------:|:----:|----------|
| 堆排序（小顶堆） | O(n log k) | O(k) | **海量数据**（n 极大，k 小），流式处理 |
| 快速选择（partition） | O(n) 平均，O(n²) 最坏 | O(1) | **数据可全部加载**，需要第 K 大/小 |
| 分治（MapReduce） | O(n log n) | O(n) | **分布式场景**，如海量数据 Top-K |

### Q8: 字符串转换整数 (atoi) 要点？
- 跳过前导空格（`while (isspace(*s)) s++`）
- 处理正负号（`int sign = (*s == '-') ? -1 : 1`）
- 逐位累加（`res = res * 10 + (*s - '0')`）
- **溢出判断**：乘 10 前检查 `res > INT_MAX/10` 或 `res == INT_MAX/10 && digit > 7`
- 遇到非数字字符停止

### Q9: N 皇后问题思路？
- **回溯法**：逐行放置皇后，每列检查是否与已放置的冲突
- **冲突判断**：列冲突（col set）、主对角线冲突（`row - col` 常数）、副对角线冲突（`row + col` 常数）
- **复杂度**：时间复杂度 O(n!)，空间 O(n)
- **变体**：N 皇后 II（LeetCode 52）→ 只返回计数，可用位运算加速

### Q10: 如何判断链表有环？
- **快慢指针**：快指针每次 2 步，慢指针每次 1 步，相遇则有环
- **找入口**：相遇后快指针从头开始，慢指针继续，同速再相遇即环入口（数学证明见 04-链表专题.md）
- **复杂度**：O(n) 时间，O(1) 空间

### Q11: 堆和栈的区别？
| 维度 | 栈（Stack） | 堆（Heap） |
|------|------------|-----------|
| 管理方式 | 自动（编译器） | 手动（new/delete） |
| 内存大小 | 小（~8MB Windows，~1MB Linux） | 大（可用内存） |
| 分配速度 | 快（SP 加减） | 慢（查找空闲块） |
| 碎片 | 无（连续分配） | 有（反复分配释放） |
| 存放内容 | 局部变量、函数参数、返回地址 | 动态分配对象 |
| 生命周期 | 函数返回即释放 | 直到 delete |

### Q12: 排序算法选型？
- **通用排序** → `std::sort`（内省排序 = 快排 + 堆排保底 + 插入排序小数组）
- **需要稳定** → `std::stable_sort`（归并排序）或手写归并
- **Top-K / 优先级调度** → 堆排序 O(n log k)，空间 O(k)
- **数据范围小（≤ 10⁷）** → 计数排序 O(n + k)，线性时间
- **链表排序** → 归并排序（链表不支持随机访问，归并天然适合）
- **近乎有序** → 插入排序，可降到 O(n)
- **大量重复值** → 三路快排（荷兰国旗问题），避免退化为 O(n²)
