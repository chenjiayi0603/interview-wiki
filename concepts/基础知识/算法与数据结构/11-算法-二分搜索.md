## 一、搜索旋转排序数组

> LeetCode 33: https://leetcode.cn/problems/search-in-rotated-sorted-array

**思路**：二分搜索——旋转数组的特点是"总有一半是有序的"。判断 `nums[l] <= nums[mid]` 来确定哪半有序，然后在有序半段中判断 target 是否在其中，缩小搜索范围。**复杂度**：O(log n) 时间，O(1) 空间。**边界**：空数组返回 -1；旋转 0 个元素也适用。

```cpp
int search(vector<int>& nums, int target) {
    int l = 0, r = nums.size() - 1;
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (nums[mid] == target) return mid;
        if (nums[l] <= nums[mid]) {         // 左半有序
            if (target >= nums[l] && target < nums[mid]) r = mid - 1;
            else l = mid + 1;
        } else {                            // 右半有序
            if (target > nums[mid] && target <= nums[r]) l = mid + 1;
            else r = mid - 1;
        }
    }
    return -1;
}
```

- **变体**：有重复元素的旋转数组（LeetCode 81）→ 当 `nums[l]==nums[mid]==nums[r]` 时退化为 O(n)

## 二、寻找两个正序数组的中位数

> LeetCode 4: https://leetcode.cn/problems/median-of-two-sorted-arrays

**思路**：二分 + 划分数组。在较短的数组上二分切分位置 i，计算另一数组切分位置 j = (m+n+1)/2 - i。保证左半所有元素 ≤ 右半所有元素（即 `nums1[i-1] ≤ nums2[j]` 且 `nums2[j-1] ≤ nums1[i]`）。**复杂度**：O(log(min(m,n))) 时间，O(1) 空间。

```cpp
double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
    if (nums1.size() > nums2.size()) swap(nums1, nums2);  // 确保 nums1 较短
    int m = nums1.size(), n = nums2.size();
    int l = 0, r = m;
    while (l <= r) {
        int i = (l + r) / 2;
        int j = (m + n + 1) / 2 - i;
        int leftMax1  = (i == 0) ? INT_MIN : nums1[i-1];
        int rightMin1 = (i == m) ? INT_MAX : nums1[i];
        int leftMax2  = (j == 0) ? INT_MIN : nums2[j-1];
        int rightMin2 = (j == n) ? INT_MAX : nums2[j];
        if (leftMax1 <= rightMin2 && leftMax2 <= rightMin1) {
            if ((m + n) % 2 == 0)
                return (max(leftMax1, leftMax2) + min(rightMin1, rightMin2)) / 2.0;
            else
                return max(leftMax1, leftMax2);
        } else if (leftMax1 > rightMin2) {
            r = i - 1;   // i 太大，左移
        } else {
            l = i + 1;   // i 太小，右移
        }
    }
    return 0;
}
```

- **边界**：处理 i=0 / i=m / j=0 / j=n 的边缘情况用 ±INT_MAX
- **变体**：两个有序数组的第 K 小元素 → 类似思路，递归排除较小的一半
