# 哈希快速记位

## 三数之和

[题目链接](https://leetcode-cn.com/problems/3sum)

给你一个包含 n 个整数的数组 nums，判断 nums 中是否存在三个元素 a，b，c ，使得 a + b + c = 0

排序、记位、遍历找数

```go
func threeSum(nums []int) [][]int {
    if len(nums) < 3 {return [][]int{}}
    sort.Ints(nums)
    m := make(map[int]int)
    for i,v := range nums {
        m[v] = i
    }
    res := [][]int{}
    for i:=0;i < len(nums);i++ {
        if i > 0 && nums[i - 1] == nums[i] {continue}
        for j:=i+1;j < len(nums);j++ {
            if j > i + 1 && nums[j - 1] == nums[j] {continue}
            other := -(nums[i] + nums[j])
            if v ,ok := m[other];ok && v > j {
                res = append(res,[]int{nums[i],nums[j],other})
            }
        }
    }
    return res
}
```

## 存在重复元素

[题目链接](https://leetcode-cn.com/problems/contains-duplicate)

给定一个整数数组，判断是否存在重复元素。如果任意一值在数组中出现至少两次，函数返回 true 。如果数组中每个元素都不相同，则返回 false 。

使用哈希表来判断重复

```go
func containsDuplicate(nums []int) bool {
	m := make(map[int]bool)
	for _, n := range nums {
		if _, ok := m[n]; ok {
			return true
		}
		m[n] = true
	}
	return false
}
```

## 四数之和

[题目链接](https://leetcode-cn.com/problems/4sum)

需要利用哈希表访问快，以及数组的有序性来去重。复杂度 n*n

```go
func fourSum(nums []int, target int) [][]int {
	res := [][]int{}
	sort.Ints(nums)
	hmap := map[int][][]int{}
	for i := 0;i < len(nums);i++ {
		for j := i+1;j < len(nums);j++ {
			hmap[nums[i] + nums[j]] = append(hmap[nums[i] + nums[j]],[]int{i,j})
		}
	}
	for i := 0;i < len(nums);i++ {
		if i > 0 && nums[i] == nums[i-1] {continue}
		for j := i+1;j < len(nums);j++ {
			if j > i + 1 && nums[j] == nums[j-1] {continue}
			if mv ,ok := hmap[target - nums[i] - nums[j]];ok {
				for _,v := range mv {
					if v[0] <= j {continue}
					tmp := []int{nums[i],nums[j],nums[v[0]],nums[v[1]]}
					if len(res) > 0 && reflect.DeepEqual(res[len(res)-1],tmp) {continue}
                    res = append(res,tmp)										
				}
			}
		}
	}
	return res
}
```

## 四数相加 II

[题目链接](https://leetcode-cn.com/problems/4sum-ii)

给你四个整数数组 nums1、nums2、nums3 和 nums4 ，数组长度都是 n ，请你计算有多少个元组 (i, j, k, l) 能满足：
0 <= i, j, k, l < n
nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0

```go
func fourSumCount(nums1 []int, nums2 []int, nums3 []int, nums4 []int) int {
    res := 0
    m1,m2 := map[int]int{},map[int]int{}      
    for _,v := range nums1 {
        for _,v2 := range nums2 {
            m1[v + v2] = m1[v + v2] + 1
        }    
    }
    for _,v := range nums3 {
        for _,v2 := range nums4 {
            m2[v + v2] = m2[v + v2] + 1
        }    
    }
    for k,v := range m1 {
        v2,ok := m2[-k]
        if ok {
            res = res + v2 * v
        }
    }
    return res
}
```
