## 术语表

| 缩写 | 全称 | 说明 |
|------|------|------|
| MSS | Maximum Segment Size | TCP 最大报文段长度，通常 1460 字节 |
| MTU | Maximum Transmission Unit | 最大传输单元，以太网通常 1500 字节 |
| RTT | Round-Trip Time | 往返时间 |
| RTO | Retransmission TimeOut | 重传超时时间 |
| SACK | Selective Acknowledgment | 选择性确认 |
| DSACK | Duplicate SACK | 重复选择性确认 |
| cwnd | Congestion Window | 拥塞窗口 |
| rwnd | Receiver Window | 接收窗口 |
| ssthresh | Slow Start Threshold | 慢启动门限 |
| TFO | TCP Fast Open | TCP 快速打开 |
| MSL | Maximum Segment Lifetime | 最大报文生存时间 |
| BDP | Bandwidth-Delay Product | 带宽时延积 |
| BBR | Bottleneck Bandwidth and Round-trip | Google 基于模型的拥塞控制算法 |
| CUBIC | — | Linux 默认基于丢包的拥塞控制算法 |
| QUIC | Quick UDP Internet Connections | Google 基于 UDP 的可靠传输协议 |
