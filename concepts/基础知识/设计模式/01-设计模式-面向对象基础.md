# 面向对象基础

> 封装、继承、多态、抽象 —— OOP 四大特性，以及 C++ 特有的访问控制、friend、RAII、多范式。

---

## 一、OOP 四大特性

### 1. 封装（Encapsulation）

将数据和操作数据的方法绑定在一起，通过访问控制隐藏实现细节。

```cpp
class BankAccount {
private:
    double balance;  // 私有数据，外部无法直接访问
public:
    void deposit(double amount) {
        if (amount > 0) balance += amount;
    }
    double getBalance() const { return balance; }
};
```

### 2. 继承（Inheritance）

新类基于现有类创建，实现代码复⽤和层次化设计。

```cpp
class Animal {
protected:
    std::string name;
public:
    virtual void makeSound() = 0;
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void makeSound() override { std::cout << "Woof!" << std::endl; }
};
```

### 3. 多态（Polymorphism）

同一接口有不同的实现。分为编译期多态和运行期多态。

```cpp
// 运行期多态：虚函数 + 动态绑定
class Shape {
public:
    virtual double area() = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double radius;
public:
    double area() override { return 3.14159 * radius * radius; }
};

void printArea(Shape* shape) {
    std::cout << shape->area() << std::endl;  // 根据实际类型调用
}
```

**两种多态**：
- **编译期多态**：函数重载、运算符重载、模板（静态绑定）
- **运行期多态**：虚函数 + 动态绑定（晚绑定）

### 4. 抽象（Abstraction）

隐藏实现细节，仅暴露必要接口，让使⽤者关注"做什么"而不是"怎么做"。

```cpp
// 抽象类：包含纯虚函数
class Database {
public:
    virtual void connect() = 0;
    virtual void query(const std::string& sql) = 0;
    virtual ~Database() = default;
};
```

## 二、访问控制

| 修饰符 | 本类 | 派生类 | 外部 |
|--------|:----:|:------:|:----:|
| `private` | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ |

```cpp
class Base {
private:
    int secret;     // 仅本类可访问
protected:
    int value;      // 本类和子类可访问
public:
    int data;       // 任何地方可访问
};

class Derived : public Base {
    void foo() {
        value = 1;   // ✅ 可访问 protected 成员
        // secret = 1; // ❌ 不能访问 private 成员
    }
};
```

## 三、友元（friend）

让其他类或函数访问本类的 `private/protected` 成员。**谨慎使用**，打破了封装性。

```cpp
class Box {
private:
    int width;
public:
    Box(int w) : width(w) {}
    friend void printWidth(const Box& b);  // 友元函数
};

void printWidth(const Box& b) {
    std::cout << b.width << std::endl;  // 可访问 private 成员
}

// 友元类
class SecretHolder {
private:
    int secret;
    friend class SecretAgent;
};

class SecretAgent {
public:
    void reveal(const SecretHolder& holder) {
        std::cout << holder.secret << std::endl;
    }
};
```

## 四、C++ 特有的 OOP 特性

### 4.1 构造与析构

构造/析构函数是 C++ OOP 自动资源管理的基石，结合 RAII 管理资源生命周期。

```cpp
class Resource {
    int* data;
public:
    Resource() : data(new int[100]) {}  // 获取资源
    ~Resource() { delete[] data; }       // 释放资源
};
```

### 4.2 RAII（Resource Acquisition Is Initialization）

资源随对象生命周期自动获得与释放，是 C++ 独有的资源管理范式。

```cpp
// 智能指针是 RAII 的典型应用
{
    std::shared_ptr<int> sp = std::make_shared<int>(42);
    // 离开作用域自动释放
}
```

### 4.3 运算符重载

允许自定义类型像内置类型一样使用运算符，属于编译期多态。

```cpp
class Complex {
    double real, imag;
public:
    Complex operator+(const Complex& other) const {
        return {real + other.real, imag + other.imag};
    }
};
```

### 4.4 多继承

C++ 支持一个类继承多个基类（Java 不支持），需注意菱形继承问题。

```cpp
class A {}; class B {};
class C : public A, public B {};  // 多继承

// 虚继承解决菱形继承
class Base {};
class Mid1 : virtual public Base {};
class Mid2 : virtual public Base {};
class Derived : public Mid1, public Mid2 {};  // 只有一份 Base
```

## 五、多范式语言

C++ 不是纯 OOP 语言，它支持多种编程范式：

| 范式 | C++ 支持方式 |
|------|-------------|
| 面向对象 | 类、继承、虚函数、多态 |
| 过程式 | 函数、控制流程（C 兼容） |
| 泛型编程 | 模板（`vector`、`algorithm`） |
| 函数式 | lambda、函数对象、`std::function` |

**核心结论**：C++ 提供原生且完整的 OOP 支持，但不强制使用。

## 六、面试高频追问

### Q1: 虚函数的实现原理（vtable/vptr）？
- 每个含有虚函数的类有一个虚函数表（vtable），存储函数指针
- 每个对象有一个虚指针（vptr），指向所属类的 vtable
- 调用虚函数时：`vptr` → `vtable` → 函数指针，**运行时动态绑定**
- **代价**：一次间接寻址 + 一次指针解引用，vptr 占用 8 字节（64位）

### Q2: 抽象类 vs 接口的区别？
- C++ 没有 `interface` 关键字，用纯虚类模拟接口
- 抽象类可以有成员变量和普通方法；接口通常只有纯虚函数
- 接口的派生类必须实现所有纯虚函数

### Q3: 虚析构函数的作用？
- 基类析构函数必须为 `virtual`，否则 `delete` 派生类对象时只调用基类析构，**内存泄漏**
- 只要类有虚函数，就应该将析构函数声明为虚函数

### Q4: 多继承的菱形问题？
- 两个中间类都继承同一个基类，派生类多重继承两个中间类 → 基类出现两次
- 解决：**虚继承** (`class Mid1 : virtual public Base`)，保证只保留一份基类子对象
- 虚继承的代价：访问虚基类成员速度略慢（通过指针偏移）

### Q5: RAII 的核心价值？
- 将资源（内存、锁、文件句柄）绑定到对象生命周期
- 构造时获取，析构时释放，**异常安全**
- **三/五法则**：如果自定义了析构/拷贝构造/拷贝赋值，通常需要同时定义三者（C++11 为五：+移动构造+移动赋值）
