# 存储成本降低 70%+

**简历原文**：存储成本降低约 70%+

## 数据支撑

| 存储类型 | 单价 | 说明 |
|---------|------|------|
| 华为云内存（Redis 类缓存折算） | ~¥2/GB·月 | 内存贵 |
| 华为 OBS 标准存储 | ¥0.099/GB·月 | OBS 便宜约 20× |
| OBS 内网访问费 | 忽略 | 同 AZ 内网无流量费 |

成本计算（1TB 全量，100GB 热内存，900GB 冷数据）：

| 内存单价 | 老架构（全内存） | 新架构 | 净节省率 |
|---------|----------------|--------|---------|
| ¥0.5/GB·月 | ¥500/月 | ¥149/月 | **70%** |
| ¥1.0/GB·月 | ¥1,000/月 | ¥199/月 | **80%** |
| ¥2.0/GB·月 | ¥2,000/月 | ¥299/月 | **85%** |

数据量越大，节省比例越高（热数据受内存容量限制，不随总量等比增长）。

## 理论支撑

核心公式：
```
老架构：Cost_old = N × P_mem
新架构：Cost_new = N_hot × P_mem + N × P_obs
净节省率 = 1 - r_hot - P_obs/P_mem
```
其中 `r_hot = N_hot/N`（热数据占比，~10%），`P_obs/P_mem ≈ 0.099/2 ≈ 5%`，净节省 ≈ 85%。

## 业界对标

- **AWS S3 + EBS 存储分层**：内存 → SSD → S3 三级成本递减，业界存储分层的标准模式
- **阿里云 Tair 冷热分层**：热数据留内存，冷数据落 OSS，原理相同
- **Cassandra Tiered Storage**：Google Cloud Bigtable 的分层案例，冷热存储成本差距在同等数量级

## 追问预案

**Q：70% 怎么算出来的，实测还是估算？**
> 基于公开价格和实际架构推演。华为 OBS 标准存储公开价 ¥0.099/GB·月，内存（云缓存实例折算）约 ¥2/GB·月。代入 1TB 数据（热数据 100GB，冷数据 900GB）：老架构全内存 ¥1000/月，新架构 100GB 内存 + 1TB OBS = ¥200 + ¥99 ≈ ¥299/月，节省率 ≈ 70%。这是业务可推演的估算，实际节省率受热数据比例和具体定价影响。
