# 布隆过滤器

## 一、原理
- 位数组 + 多个哈希函数
- 添加：k个哈希位置1
- 查询：k个哈希全为1则可能存在
- **假阳性，不可假阴性**

## 二、参数计算
```
n = 预期元素数量
p = 期望假阳性率
m = -n * ln(p) / (ln(2)^2)  # 位数组大小
k = m/n * ln(2)  # 哈希函数数量
```

## 三、Redis实现
```bash
# 安装RedisBloom
redis-cli BF.ADD myfilter item
redis-cli BF.EXISTS myfilter item
redis-cli BF.MADD myfilter item1 item2
redis-cli BF.MEXISTS myfilter item1 item2
```

## 四、应用场景
- **大Key检测**：key映射到布隆过滤器
- **缓存穿透**：不存在的数据快速拦截
- **爬虫URL去重**
- **反垃圾邮件**

## 五、手写Bloom Filter实现
```cpp
#include <vector>
#include <functional>

class BloomFilter {
private:
    std::vector<bool> bits;
    int k;  // 哈希函数数量
    size_t size;
    
    size_t hash(const std::string& key, int i) {
        std::hash<std::string> h1;
        std::hash<std::string> h2;
        size_t hash1 = h1(key);
        size_t hash2 = h2(key);
        return (hash1 + i * hash2) % size;
    }
    
public:
    BloomFilter(size_t n, double p) {
        // n: 预期元素数, p: 期望误判率
        size = static_cast<size_t>(-n * log(p) / (log(2) * log(2)));
        k = static_cast<int>(size * log(2) / n);
        bits.resize(size, false);
    }
    
    void add(const std::string& key) {
        for (int i = 0; i < k; ++i) {
            bits[hash(key, i)] = true;
        }
    }
    
    bool mightContain(const std::string& key) {
        for (int i = 0; i < k; ++i) {
            if (!bits[hash(key, i)]) {
                return false;
            }
        }
        return true;
    }
};
```
