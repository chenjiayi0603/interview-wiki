# 快速判断字符串前缀在不在字典中

## 问题描述：单词替换

在英语中，我们有一个叫做 词根(root) 的概念，可以词根后面添加其他一些词组成另一个较长的单词——我们称这个词为 继承词(successor)。例如，词根an，跟随着单词 other(其他)，可以形成新的单词 another(另一个)。

现在，给定一个由许多词根组成的词典 dictionary 和一个用空格分隔单词形成的句子 sentence。你需要将句子中的所有继承词用词根替换掉。如果继承词有许多可以形成它的词根，则用最短的词根替换它。

你需要输出替换之后的句子。

示例 1：
输入：dictionary = ["cat","bat","rat"], sentence = "the cattle was rattled by the battery"
输出："the cat was rat by the bat"

示例 2：
输入：dictionary = ["a","b","c"], sentence = "aadsfasf absbs bbab cadsfafs"
输出："a a b c"

提示：
1 <= dictionary.length <= 1000
1 <= dictionary[i].length <= 100
dictionary[i] 仅由小写字母组成。
1 <= sentence.length <= 10^6
sentence 仅由小写字母和空格组成。
sentence 中单词的总量在范围 [1, 1000] 内。
sentence 中每个单词的长度在范围 [1, 1000] 内。
sentence 中单词之间由一个空格隔开。
sentence 没有前导或尾随空格。

## 解法一：字典树（Trie）

字典树（多叉树）查找字符串和替换，最后成员需要标记结束位（isWord）

```cpp
class Tire{
    bool isWord = false;
    Tire* next[26] = {0};
public:
    void insert(const string& word){
        Tire* cur = this;
        for(auto& ch : word){
            int idx = ch - 'a';
            if(cur->next[idx] == nullptr){
                cur->next[idx] = new Tire();
            }
            cur = cur->next[idx];
        }
        cur->isWord = true;
    }
    int find(const string& word){
        Tire* cur = this;
        for(int i = 0; i < word.size(); i++){
            int idx = word[i] - 'a';
            if(cur->next[idx] == nullptr){
                return -1;
            }
            cur = cur->next[idx];
            if(cur->isWord){
                return i;
            }
        }
        return -1;
    }
};

class Solution {
public:
    string replaceWords(vector<string>& dictionary, string sentence) {
        Tire* root = new Tire();
        for(auto& word : dictionary){
            root->insert(word);
        }
        string res, str;
        stringstream ss(sentence);
        while(ss >> str){
            int pos = root->find(str);//字典树查词前缀
            if(pos == -1){
                res += str + " ";
            }
            else{
                res += str.substr(0, pos + 1) + " ";//只保留前缀
            }
        }
        if(res.size())res.pop_back();
        return res;
    }
};
```

执行用时: 56 ms
内存消耗: 50.3 MB

## 解法二：哈希集合

哈希集合查找字符串和替换

```cpp
class Solution {
public:
    string replaceWords(vector<string>& dict, string sentence) {
        unordered_set<string> wordSet(dict.begin(),dict.end());
        string res, word;
        stringstream ss(sentence);
        while(ss >> word){
        	bool found(false);
            for(int j = 1; j <= word.length();j++)//遍历word，查wordSet
            {
                const string &subWord = word.substr(0,j);  //这个比较消耗
                if(wordSet.count(subWord)){
                    res += subWord + " ";
                    found = true;
                    break;
                }
            }
            if (!found) res += word + " ";
        }
        if (res.size()) res.pop_back();
        return res;
    }
};
```
