# 性能优化

## 一、性能优化概述

### 1. 性能指标
- **延迟（Latency）**：请求到响应的时间
- **吞吐量（Throughput）**：单位时间处理请求数（QPS/TPS）
- **资源利用率**：CPU、内存、磁盘、网络使用率
- **并发数**：同时处理的请求数
- **错误率**：失败请求比例

### 2. 性能优化层次
```
应用层：业务逻辑、算法、数据结构
│
框架层：Web框架、中间件、SDK
│
运行时层：GC、JIT、线程调度
│
系统层：内存管理、I/O、网络
│
硬件层：CPU、内存、磁盘、网络
```

### 2. 缓存友好代码
```cpp
// 坏：内存跳跃访问
for (int i = 0; i < N; i++)
    for (int j = 0; j < M; j++)
        sum += matrix[j][i];

// 好：顺序访问
for (int i = 0; i < N; i++)
    for (int j = 0; j < M; j++)
        sum += matrix[i][j];

// 预取
__builtin_prefetch(&matrix[i+1][0], 0, 3);
```

### 3. 伪共享
```cpp
// 伪共享：不同线程修改同一缓存行的不同变量
struct Foo {
    int x;  // Thread1 修改
    char pad[64];  // 填充到不同缓存行
    int y;  // Thread2 修改
};
```
- **解决方案**：缓存行填充（64字节对齐）
- **alignas(64)**：C++11对齐

### 4. 线程优化
```cpp
// CPU密集：线程数 = CPU核心数
```

## 三、内存性能优化

### 1. 内存分配优化
```cpp
// 对象池
class ObjectPool {
    std::vector<void*> pool;
    std::mutex mtx;
public:
    void* allocate(size_t size) {
        std::lock_guard<std::mutex> lock(mtx);
        if (!pool.empty()) {
            void* p = pool.back();
            pool.pop_back();
            return p;
        }
        return ::malloc(size);
    }
    void deallocate(void* p) {
        std::lock_guard<std::mutex> lock(mtx);
        pool.push_back(p);
    }
};
```

## 四、I/O性能优化

### 1. 同步I/O vs 异步I/O
```cpp
// 同步I/O：阻塞等待
int fd = open("file", O_RDONLY);
read(fd, buf, size);
close(fd);

// 异步I/O：立即返回
aio_context_t ctx;
io_setup(1, &ctx);
struct aiocb cb = {0};
cb.aio_fildes = fd;
cb.aio_buf = buf;
cb.aio_nbytes = size;
aio_read(&cb);
// 等待完成
aio_suspend(&ctx, 1, NULL);
```

### 2. 零拷贝技术
```cpp
// sendfile (文件->Socket)
#include <sys/sendfile.h>
sendfile(out_fd, in_fd, &offset, count);

// splice (管道/套接字)
splice(in_fd, NULL, out_fd, NULL, len, SPLICE_F_MOVE);

// DMA拷贝：减少CPU参与
// - 传统：磁盘→内存→CPU→内存→网卡
// - DMA：磁盘→内存→内存→网卡
```

### 3. mmap文件映射
```cpp
// 大文件高效读取
int fd = open("bigfile", O_RDONLY);
struct stat st;
fstat(fd, &st);
void* addr = mmap(NULL, st.st_size, PROT_READ, 
                  MAP_PRIVATE, fd, 0);
// 直接访问内存读取文件
munmap(addr, st.st_size);
```

### 4. I/O多路复用
```cpp
// select/poll/epoll对比
// select: fd_setsize限制(1024), 每次全量拷贝
// poll: 无限制，但仍是全量拷贝
// epoll: 红黑树+就绪链表，高效事件通知

// epoll LT vs ET模式
// LT (Level Trigger): 持续通知
// ET (Edge Trigger): 只通知一次

// epoll服务器模板
int epfd = epoll_create1(0);
struct epoll_event ev = {EPOLLIN, {}};
epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);

while (true) {
    int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
    for (int i = 0; i < n; ++i) {
        // 处理事件
    }
}
```

```cpp
// Nagle算法：合并小包
// 禁用：适用于低延迟场景
setsockopt(sock, IPPROTO_TCP, TCP_NODELAY, 1);

// 连接队列
// SYN队列 + accept队列
// backlog参数调优

// 保活
setsockopt(sock, SOL_SOCKET, SO_KEEPALIVE, 1);
setsockopt(sock, IPPROTO_TCP, TCP_KEEPIDLE, 60);
setsockopt(sock, IPPROTO_TCP, TCP_KEEPINTVL, 10);
setsockopt(sock, IPPROTO_TCP, TCP_KEEPCNT, 3);

// 缓冲区大小

```

### 2. 连接池
```cpp
class ConnectionPool {
    std::queue<Connection*> pool;
    std::mutex mtx;
    std::condition_variable cv;
    size_t maxSize;
    std::function<Connection*()> factory;
    
public:
    std::shared_ptr<Connection> acquire() {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [this]{ return !pool.empty(); });
        auto conn = pool.front();
        pool.pop();
        return {conn, [this](Connection* c){ 
            std::lock_guard<std::mutex> lock(mtx);
            pool.push(c); 
            cv.notify_one();
        }};
    }
};
```

## 七、缓存优化

### 1. 多级缓存
```
┌─────────────────┐
│   CDN缓存        │ 毫秒~秒级
├─────────────────┤
│   浏览器缓存      │ 本地
├─────────────────┤
│   反向代理缓存    │ Redis/Memcache
├─────────────────┤
│   本地缓存        │ 本进程
└─────────────────┘
```

### 2. 缓存策略
```go
// Cache-Aside（旁路缓存）
// 读：cache -> miss -> db -> update cache
// 写：db -> delete cache

// Read-Through
// 读：cache自动从db加载

// Write-Through
// 写：cache和db同步更新

// Write-Behind
// 写：先更新cache，异步写db
```

### 3. 缓存问题
```go
// 缓存穿透
if cache.Get(key) == nil {
    if db.Exists(key) {
        cache.Set(key, db.Get(key))
    } else {
        cache.Set(key, nil, shortTTL) // 空值缓存
    }
}

// 缓存击穿
// 互斥锁
mu.Lock()
defer mu.Unlock()
// 双检锁
if cache.Get(key) == nil {
    val := db.Get(key)
    cache.Set(key, val, longTTL)
}

// 缓存雪崩
// 随机TTL
ttl := baseTTL + random(0, baseTTL)
```

## 八、算法优化

### 1. 复杂度分析
```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ) < O(n!)

空间换时间
├── 预处理
├── 记忆化
└── 空间缓存
```

### 2. 高效算法
```cpp
// 跳表：O(log n)查找，替代平衡树
// 布隆过滤器：O(1)存在判断，有假阳性
// LRU：O(1)获取/设置
// 桶排序：O(n)特定场景
// 计数排序：O(n+k)
```

### 3. SIMD优化

```cpp
#include <immintrin.h>

__m256d a = _mm256_load_pd(data1);
```
