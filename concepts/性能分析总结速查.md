# 性能分析总结速查

## 核心工具速查

| 工具 | 用途 | 常用命令 |
|------|------|---------|
| **perf** | Linux性能分析标准工具 | `perf record -g ./program`<br>`perf report`<br>`perf stat ./program`<br>`perf top` |
| **火焰图** | 可视化调用栈热点 | `perf record -F 99 -g ./program`<br>`perf script \| stackcollapse-perf.pl \| flamegraph.pl > flame.svg` |
| **Valgrind** | 内存/性能分析 | `valgrind --leak-check=full ./program`<br>`valgrind --tool=callgrind ./program` |
| **gprof** | GNU性能分析器 | `g++ -pg -O2 -o program program.cpp`<br>`gprof program gmon.out` |

## 关键性能指标（KPI）

| 指标 | 含义 | 正常范围 | 优化目标 |
|------|------|---------|---------|
| **QPS** | 每秒查询数 | - | 提高吞吐量 |
| **延迟** | 响应时间（P50/P95/P99） | - | 降低延迟 |
| **IPC** | 每周期指令数 | >1.0 | 提高流水线效率 |
| **cache-misses** | 缓存未命中率 | <10% | 优化数据布局、顺序访问 |
| **branch-misses** | 分支预测失败率 | <5% | 减少分支、使用查找表 |
| **cycles** | CPU周期数 | - | 减少指令数、提高IPC |
| **instructions** | 指令总数 | - | 优化算法、减少冗余计算 |

## 性能分析流程

```
1. 建立基准测试 → 记录QPS、延迟、CPU、内存等指标
2. 识别瓶颈 → perf record/report定位热点函数
3. 定位问题 → 分析算法复杂度、内存访问模式、缓存命中率
4. 优化实施 → 应用优化技巧，验证效果
5. 回归测试 → 对比优化前后性能
```

## perf核心命令速查

### perf 常用命令对照与场景速查

| 命令                 | 常用参数          | 作用             | 场景           |
|----------------------|------------------|------------------|----------------|
| perf record          | -g, -F, -e, -p   | 采样数据/调用栈    | 离线分析、定位瓶颈 |
| perf report          | -g, -i           | 查看采样报告      | 热点函数分析     |
| perf stat            | -e, -p           | 输出核心指标      | 性能基准/瓶颈分析 |
| perf top             | -p, -H           | 实时热点监控      | 线上排查       |
| perf script          | -i               | 转文本调用栈      | 火焰图生成     |
| perf annotate        | -i, --stdio      | 汇编级热点分析    | 指令/流水线优化 |
| perf list            | 无               | 列出支持事件      | 事件查询       |
| perf diff            | 无               | 比较两次报告      | 优化前后对比   |

### 1. 热点函数定位

```bash
perf record -g ./program    # 采集性能数据（带调用栈）
perf report                  # 查看热点函数报告
perf top                     # 实时监控CPU热点
```

### 2. 整体性能评估
```bash
perf stat ./program          # 统计cycles、instructions、IPC等
perf stat -e cache-misses ./program     # 缓存瓶颈分析
perf stat -e branch-misses ./program    # 分支瓶颈分析
```

### 3. 火焰图生成
```bash
perf record -F 99 -g ./program
perf script | stackcollapse-perf.pl | flamegraph.pl > flame.svg
```

## 内存分析工具速查

| 工具 | 用途 | 命令 |
|------|------|------|
| **AddressSanitizer** | 内存越界/非法访问检测 | `g++ -fsanitize=address -g -O1 program.cpp` |
| **LeakSanitizer** | 内存泄漏检测 | `g++ -fsanitize=leak -g program.cpp` |
| **Massif** | 堆内存使用分析 | `valgrind --tool=massif ./program`<br>`ms_print massif.out.*` |
| **系统工具** | 进程内存监控 | `top -p <pid>`<br>`pmap -x <pid>`<br>`cat /proc/<pid>/status` |
