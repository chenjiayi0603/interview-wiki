# 智能指针优化

## 四、智能指针优化

### 4.1 智能指针选择策略

| 智能指针 | 所有权 | 性能开销 | 适用场景 |
|---------|--------|---------|---------|
| `std::unique_ptr` | 独占 | 零开销（编译期） | 单一所有者、资源管理 |
| `std::shared_ptr` | 共享 | 引用计数原子操作 | 多所有者、共享资源 |
| `std::weak_ptr` | 无所有权 | 轻量级 | 打破循环引用、观察者模式 |

### 4.2 `shared_ptr` 性能优化

**问题**：`shared_ptr` 的引用计数是原子操作，有性能开销

**优化技巧**：

**1. 使用 `make_shared`**：
```cpp
// 推荐：一次分配，控制块和对象在一起
auto ptr = std::make_shared<MyClass>(args);

// 不推荐：两次分配
auto ptr = std::shared_ptr<MyClass>(new MyClass(args));
```

**2. 避免不必要的 `shared_ptr` 拷贝**：
```cpp
// 推荐：传递引用
void process(const std::shared_ptr<MyClass>& ptr);

// 避免：值传递（增加引用计数）
void process(std::shared_ptr<MyClass> ptr);
```

**3. 使用 `weak_ptr` 打破循环引用**：
```cpp
struct Node {
    std::shared_ptr<Node> next;
    std::weak_ptr<Node> prev;  // 使用 weak_ptr 避免循环引用
};
```

### 4.3 自定义删除器优化

```cpp
// 使用自定义删除器避免额外分配
// Deleter（删除器）是智能指针 unique_ptr/shared_ptr 的模板参数。
// 它会在如下情形被调用：
// 1. 智能指针销毁时（例如作用域结束，或显示调用 reset、赋予新值等）
// 2. 其析构函数 unique_ptr::~unique_ptr() / shared_ptr::~shared_ptr() 内部会调用删除器完成资源释放。
// 
// 为什么调用？
// 保证资源自动释放，实现安全管理（如执行自定义清理），防止资源泄漏。
//
// 怎样调用？
// 无需用户手动调用，由智能指针实现自动调用。例如 unique_ptr 的 dtor（析构）伪代码：
//   ~unique_ptr() { if(ptr) Deleter()(ptr); }
//
// 源码分析（以 unique_ptr 为例）：
//   ~unique_ptr() noexcept { if (pointer) get_deleter()(pointer); }
// pointer 为数据指针，get_deleter() 获取 Deleter 实例。
struct Deleter {
    void operator()(MyClass* p) {
        p->cleanup();  // 自定义清理
        delete p;
    }
};

std::unique_ptr<MyClass, Deleter> ptr(new MyClass);
```
