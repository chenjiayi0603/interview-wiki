# 树状数组

树状数组（Fenwick Tree / Binary Indexed Tree）是一种支持单点修改和前缀和查询的数据结构，复杂度 O(log n)。

## 核心操作

- `lowbit(x) = x & (-x)`：取出 x 二进制表示中最低位的 1。
- `push(x, v)`：从 x 开始，不断加上 lowbit(x)，将 v 累加到 nodes[x] 中（向上更新）。
- `find(x)`：从 x 开始，不断减去 lowbit(x)，累加 nodes[x] 的值（向下求和）。

## 应用场景

- 计算右侧小于当前元素的个数（LeetCode 315）
- 逆序对计数
- 区间和查询与单点更新

## 示例：计算右侧小于当前元素的个数

给定整数数组 nums，返回新数组 counts，其中 counts[i] 是 nums[i] 右侧小于 nums[i] 的元素数量。

**力扣**：[count-of-smaller-numbers-after-self](https://leetcode-cn.com/problems/count-of-smaller-numbers-after-self/)

```cpp
class Solution {
public:
    int lowbit(int x){return x & (-x);}
    int find(int x,vector<int> &nodes){
        int res = 0;
        while(x){
            res += nodes[x];
            x -= lowbit(x);
        }
        return res;
    }
    void push(int x, int v,vector<int> &nodes){
        while(x < nodes.size()){
            nodes[x] += v;
            x += lowbit(x);
        }
    }
    vector<int> countSmaller(vector<int>& nums) {
        if (nums.size() == 0)return {};
        vector<int> res;
        vector<int> nodes = vector<int>(20002);
        for(int i=nums.size()-1;i>=0;i--){
           res.push_back(find(nums[i] + 10001-1,nodes));
           push(nums[i] + 10001, 1,nodes);
        }
        reverse(res.begin(),res.end());
        return res;
    }
};
```
