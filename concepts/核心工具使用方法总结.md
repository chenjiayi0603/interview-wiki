## 2.1 strace - 系统调用跟踪

**核心用途**：分析程序与操作系统内核的交互，定位 I/O、文件、网络瓶颈。

**常用命令**：
```bash
# 统计系统调用分布（快速定位瓶颈）
strace -c ./program

# 跟踪文件操作，显示耗时
strace -e trace=file -T ./program

# 跟踪网络操作
strace -e trace=network -T ./program

# 跟踪已运行进程
strace -p <pid> -c -T

# 跟踪子进程和线程
strace -f ./program
```

**关键指标解读**：
- `% time`：各系统调用占总时间的比例
- `seconds`：系统调用总耗时
- `usecs/call`：每次调用平均耗时
- `calls`：调用次数

## 2.2 perf - Linux 性能分析标准工具

**核心功能**：热点函数定位、硬件事件统计、火焰图生成。

#### （1）perf record - 采集性能数据
```bash
# 基础用法（带调用栈）
perf record -g ./program

# 指定采样频率
perf record -F 99 -g ./program

# 采样指定进程
perf record -p <pid> -g -- sleep 30

# 采样特定硬件事件
perf record -e cache-misses -g ./program
```

#### （2）perf report - 查看热点报告
```bash
# 交互式查看
perf report

# 文本方式输出
perf report --stdio
```

#### （3）perf stat - 统计性能指标
```bash
# 统计整体性能指标
perf stat ./program

# 统计特定事件
perf stat -e cache-references,cache-misses ./program
perf stat -e branches,branch-misses ./program

# 定时输出
perf stat -I 1000 ./program
```

#### （4）perf top - 实时监控
```bash
# 全局热点
perf top

# 指定进程
perf top -p <pid>

# 按线程显示
perf top -p <pid> -H
```

#### （5）火焰图生成
```bash
# 1. 采集数据
perf record -F 99 -g ./program

# 2. 转换为文本
perf script > out.perf

# 3. 折叠样本
./stackcollapse-perf.pl out.perf > out.folded

# 4. 生成火焰图
./flamegraph.pl out.folded > flame.svg
```

## 2.3 关键性能指标详解

| 指标 | 含义 | 正常范围 | 优化建议 |
|------|------|---------|---------|
| **IPC（每周期指令数）** | CPU 流水线效率 | >1.0 为佳 | 减少分支、优化内存访问 |
| **cache-misses** | 缓存未命中率 | <10% 为佳 | 调整数据布局、顺序访存 |
| **branch-misses** | 分支预测失败率 | <5% 为佳 | 减少 if-else、用查找表 |
| **cycles** | CPU 周期数 | 越少越好 | 减少无用指令、优化算法 |
| **instructions** | 执行指令总数 | 越少越好 | 高效数据结构、算法优化 |

## 2.4 VTune - 综合性能分析

**主要分析模式**：

| 分析类型 | 命令 | 用途 |
|---------|------|------|
| **热点分析** | `vtune -collect hotspots` | 定位 CPU 消耗最多的函数 |
| **内存带宽分析** | `vtune -collect memory-access` | 分析内存访问瓶颈（需物理机） |
| **线程/锁竞争分析** | `vtune -collect threading` | 分析多线程同步问题 |

**典型命令**：
```bash
# 热点分析
vtune -collect hotspots -result-dir ./vtune_result -- ./program

# 查看报告
vtune -report summary -result-dir ./vtune_result

# 线程分析
vtune -collect threading -result-dir ./vtune_thread -- ./program
```

## 2.5 其他工具

#### gprof - 函数级性能分析
```bash
# 编译时加 -pg
g++ -pg -O2 -o program program.cpp

# 运行程序生成 gmon.out
./program

# 查看报告
gprof program gmon.out > report.txt
```

#### valgrind - 内存和缓存分析
```bash
# 内存泄漏检测
valgrind --leak-check=full ./program

# 函数级性能分析
valgrind --tool=callgrind ./program

# 缓存命中分析
valgrind --tool=cachegrind ./program
```

#### AddressSanitizer - 内存错误检测
```bash
# 编译时启用
g++ -fsanitize=address -g -O1 program.cpp -o program

# 运行时自动检测并报告内存错误
./program
```

#### C++11 chrono - 代码段时间测量
```cpp
auto start = std::chrono::high_resolution_clock::now();
// ... 执行代码 ...
auto end = std::chrono::high_resolution_clock::now();
auto duration = std::chrono::duration_cast<std::chrono::microseconds>(end - start);
std::cout << "耗时: " << duration.count() << " 微秒" << std::endl;
```
