# 桶计数快速排序

## 摆动排序 II

给你一个整数数组 nums，将它重新排列成 nums[0] < nums[1] > nums[2] < nums[3]... 的顺序。

你可以假设所有输入数组都可以得到满足题目要求的结果。

**力扣**：[摆动排序 II](https://leetcode-cn.com/problems/wiggle-sort-ii)

### 示例

示例 1：
输入：nums = [1,5,1,1,6,4]
输出：[1,6,1,5,1,4]
解释：[1,4,1,5,1,6] 同样是符合题目要求的结果，可以被判题程序接受。

示例 2：
输入：nums = [1,3,2,2,3,1]
输出：[2,3,1,3,1,2]

### 提示

- 1 <= nums.length <= 5 * 10^4
- 0 <= nums[i] <= 5000
- 题目数据保证，对于给定的输入 nums ，总能产生满足题目要求的结果

进阶：你能用 O(n) 时间复杂度和 / 或原地 O(1) 额外空间来实现吗？

### 解法一：桶计数

桶计数。大数放奇数位置，小数放偶数位（取数从后往前，放数从前往后）。复杂度 N + max(nums[i])。

```cpp
class Solution {
public:
    void wiggleSort(vector<int>& nums) {
        int ma(0);
        for (int i: nums)
        {
            ma = max(i,ma);
        }
        vector<int> tmp(ma+1);
        for (int i: nums)
        {
            tmp[i]++;//计数
        }
        int r = tmp.size() -1;
        for(int i = 1;i < nums.size();i += 2)//put big
        {
            while(tmp[r] == 0 && r > 0)r--;
            nums[i] = r,tmp[r]--;
        }
        for(int i = 0;i < nums.size();i += 2)//put small
        {
            while(tmp[r] == 0 && r > 0)r--;
            nums[i] = r,tmp[r]--;
        }
    }
};
```

### 解法二：排序 + 双指针

复杂度 N * logN。

```cpp
class Solution {
public:
    void wiggleSort(vector<int>& nums) 
    {
        vector<int> tmp = nums;
        sort(tmp.begin(),tmp.end());
        int mid = (tmp.size() + 1)/2 -1;
        int n = tmp.size() -1;
        for(int i = 0;i < nums.size();++i)
        {
            if (i % 2 == 0)nums[i] = tmp[mid--];//put small
            else nums[i] = tmp[n--];//put big
        }
    }
};
```
