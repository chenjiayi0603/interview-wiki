# 火焰图使用

## 4.1 什么是火焰图（Flame Graph）？

**定义**：一种性能分析可视化工具，用堆叠柱状条展示函数调用关系和各自消耗的 CPU 时间/采样次数。

**特点**：
- **横轴宽度** = 时间或采样比例（宽->更耗时）
- **纵轴高度** = 调用深度
- **颜色**：无语义，仅便于区分
- 支持多语言：C/C++、Java、Go 等

**用途**：
- 快速定位最大耗时/热点函数及其路径（宽条为"瓶颈"）
- 直观展现调用链/上下文，一目了然
- 复杂/多线程程序也适用

## 4.2 火焰图生成流程

**基本原理**：
- 利用 perf、gperf 等采样工具定时采集调用栈
- `stackcollapse-perf.pl` 脚本折叠并聚合
- `flamegraph.pl` 生成交互式 SVG，可浏览分析

**完整流程**：

1. **安装Flamegraph工具**
   ```bash
   git clone https://github.com/brendangregg/Flamegraph
   cd Flamegraph
   ```

2. **采集调用栈采样**
   ```bash
   # 全系统99Hz采样，30秒
   perf record -F 99 -a -g -- sleep 30
   perf script > out.perf
   ```
   参数说明：`-F` 频率，`-a` 全系统，`-g` 采样调用栈

3. **折叠原始样本**
   ```bash
   ./stackcollapse-perf.pl ../out.perf > out.folded
   ```

4. **生成 SVG 火焰图**
   ```bash
   ./flamegraph.pl out.folded > flame.svg
   ```
   用浏览器查看和分析 SVG 即可。

5. **采集指定进程（pid = <pid>）**
   ```bash
   perf record -F 99 -p <pid> -g -- sleep 30
   perf script > perf.stacks
   ./stackcollapse-perf.pl perf.stacks > perf.folded
   ./flamegraph.pl perf.folded > perf.svg
   ```

## 4.3 火焰图的阅读方法

**阅读要点**：
- **X轴宽度**：函数或路径的耗时比例（宽即热点）
- **Y轴高度**：调用链层数（向上为上层被调用者）
- **颜色**：无语义，仅便于区分
- **热点定位**：关注最宽的"火苗"，自底向上可快速发现瓶颈调用链

**分析技巧**：
- 点击火焰图可以放大查看细节
- 鼠标悬停显示函数名和采样次数
- 搜索功能可以快速定位特定函数

## 4.4 常用命令速查

```bash
# 分析当前程序火焰图
perf record -F 99 -g ./program
perf script | stackcollapse-perf.pl | flamegraph.pl > flame.svg
```

**注意**：Go/C++ 也可用 pprof 生成火焰图（详见 pprof 文档）
