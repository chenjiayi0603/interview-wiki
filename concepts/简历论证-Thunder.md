## P2：Thunder 简历知识点论证

**简历原文**：**Thunder** 分布式异步集群框架（C++20，自研 RPC + Raft 共识，QPS 200万+，动态插件热加载，已开源）

### 数据支撑

| 指标 | 值 |
|------|----|
| 空请求 QPS | 200 万 |
| P99 延迟 | 0.8ms |
| 协程切换开销 | 50ns（比线程快 200 倍）|
| 50 万并发内存 | 10GB |
| 核心代码量 | 1.5 万行 |

### 优化历程

1. **V0.1 基准**：10万 QPS
2. **V0.3 内存池**：50万 QPS（对象池复用，零分配）
3. **V0.4 锁消除**：120万 QPS（Per-CPU 队列 + 无锁队列）
4. **V0.5 Batch**：200万 QPS（批量处理减少 RTT）

### 核心技术点

**Stackless 协程**：50万并发只需 1GB 内存 vs Stackful 需要 32GB
**Raft 随机化选举**：解决选举死循环，3节点 50ms 选主
**动态插件热加载**：dlopen + dlsym + OnUnload/dlclose
