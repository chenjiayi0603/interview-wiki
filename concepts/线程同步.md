# 线程同步

See also: [[C++多线程与并发]], [[C++语言特性]]

## 一、同步原语对比

| 同步原语 | 特点 | 适用场景 |
|----------|------|----------|
| `std::mutex` | 重量级锁，会让出 CPU | 一般互斥 |
| `std::atomic` | 无锁，不会让出 CPU | 计数器、标志位 |
| `std::condition_variable` | 条件变量 | 生产者-消费者 |
| `std::shared_mutex` | 读写锁（C++17） | 读多写少 |
| `std::spinlock` | 自旋锁，忙等待 | 短时间等待 |

## 二、核心知识点

### 1. mutex vs atomic

```cpp
#include <mutex>
#include <atomic>

// mutex：会让出 CPU，适合临界区较长的场景
std::mutex mtx;
int counter = 0;

void increment_mutex() {
    std::lock_guard<std::mutex> lock(mtx);
    counter++;  // 临界区可能包含多步操作
}

// atomic：无锁，适合简单操作
std::atomic<int> atomic_counter{0};

void increment_atomic() {
    atomic_counter++;  // 单条原子指令
}
```

**关键区别**：
- `mutex` 会让出 CPU（上下文切换），适合临界区较长
- `atomic` 不会让出 CPU（忙等待或硬件指令），适合极短操作

### 2. 伪共享（False Sharing）

```cpp
// 问题：两个原子变量在同一缓存行
struct Bad {
    std::atomic<int> a;  // Thread 1 频繁修改
    std::atomic<int> b;  // Thread 2 频繁修改
    // a 和 b 可能在同一个 64 字节缓存行
};

// 解决：缓存行填充
struct Good {
    alignas(64) std::atomic<int> a;
    alignas(64) std::atomic<int> b;
    // 确保 a 和 b 在不同缓存行
};
```

### 4. 条件变量

```cpp
#include <condition_variable>

std::mutex mtx;
std::condition_variable cv;
std::queue<int> queue;
bool done = false;

// 生产者
void producer() {
    for (int i = 0; i < 100; ++i) {
        std::lock_guard<std::mutex> lock(mtx);
        queue.push(i);
        cv.notify_one();
    }
    {
        std::lock_guard<std::mutex> lock(mtx);
        done = true;
    }
    cv.notify_all();
}

// 消费者
void consumer() {
    while (true) {
        std::unique_lock<std::mutex> lock(mtx);
        cv.wait(lock, [] { return !queue.empty() || done; });
        if (!queue.empty()) {
            int val = queue.front();
            queue.pop();
            lock.unlock();
            // 处理 val
        } else if (done) {
            break;
        }
    }
}
```

### 5. 读写锁

```cpp
#include <shared_mutex>

std::shared_mutex rw_mtx;
std::map<int, std::string> data;

// 读操作：共享锁
std::string read(int key) {
    std::shared_lock<std::shared_mutex> lock(rw_mtx);
    return data[key];
}

// 写操作：独占锁
void write(int key, const std::string& value) {
    std::unique_lock<std::shared_mutex> lock(rw_mtx);
    data[key] = value;
}
```
