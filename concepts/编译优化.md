# 编译优化

## 5.1 编译器优化选项

**GCC/Clang 优化选项**：

```bash
# 最高优化级别
-O3 -march=native -mtune=native

# 链接时优化（LTO）
-flto -fuse-linker-plugin

# 特定优化
-ffast-math          # 快速数学运算（可能损失精度）
-funroll-loops       # 循环展开
-finline-functions   # 内联函数
-fomit-frame-pointer # 省略帧指针（节省寄存器）

# 完整优化命令示例
g++ -O3 -march=native -mtune=native -flto \
    -ffast-math -funroll-loops \
    -fomit-frame-pointer \
    -DNDEBUG \
    -o program program.cpp
```

**关键优化说明**：
- **-O3**：最高优化级别，包括向量化
- **-march=native**：针对当前 CPU 架构优化
- **-flto**：链接时优化，跨文件优化
- **-ffast-math**：快速数学（交易系统慎用，可能影响精度）

## 5.2 内联函数优化

```cpp
// 强制内联关键函数
inline __attribute__((always_inline)) 
int fast_add(int a, int b) {
    return a + b;
}

// 或者使用 C++ 方式
inline int fast_add(int a, int b) __attribute__((always_inline));

// 编译器提示：likely/unlikely
if (__builtin_expect(condition, 1)) {
    // 大多数情况下为真
}
```

## 5.3 基于性能分析的优化（PGO, Profile-Guided Optimization，性能分析引导优化）

**原理**：根据实际运行数据优化代码。

```bash
# 1. 编译时添加 -fprofile-generate
g++ -O3 -fprofile-generate -o program program.cpp

# 2. 运行程序生成 profile 数据
./program < typical_input

# 3. 使用 profile 数据重新编译
g++ -O3 -fprofile-use -o program_optimized program.cpp
```

## 5.4 静态链接

**优势**：避免动态链接开销，提高启动速度。

```bash
# 静态链接
g++ -static -o program program.cpp

# 或者只静态链接特定库
g++ -Wl,-Bstatic -lmylib -Wl,-Bdynamic -lpthread -o program program.cpp
```
