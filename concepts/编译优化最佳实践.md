# 编译优化最佳实践

## 7.1 编译器优化选项

**GCC/Clang 优化选项**：

```bash
# 最高优化级别
-O3 -march=native -mtune=native

# 链接时优化（LTO）
-flto -fuse-linker-plugin

# 特定优化
-ffast-math          # 快速数学运算（可能损失精度）
-funroll-loops       # 循环展开
-finline-functions   # 内联函数
-fomit-frame-pointer # 省略帧指针（节省寄存器）

# 完整优化命令示例
g++ -O3 -march=native -mtune=native -flto \
    -ffast-math -funroll-loops \
    -fomit-frame-pointer \
    -DNDEBUG \
    -o program program.cpp
```

## 7.2 内联函数与分支预测优化

```cpp
// 强制内联关键函数
inline __attribute__((always_inline)) 
int fast_add(int a, int b) {
    return a + b;
}

// 分支预测提示
#define likely(x)   __builtin_expect(!!(x), 1)
#define unlikely(x) __builtin_expect(!!(x), 0)

// C++20 标准方式
int modern_process(int value, bool is_valid) {
    if (is_valid) [[likely]] {
        return value * 2 + 1;
    } else [[unlikely]] {
        return -1;
    }
}
```

## 7.3 Profile-Guided Optimization (PGO)

**原理**：根据实际运行数据优化代码，编译器根据真实执行路径优化分支预测、函数内联和代码布局。

```bash
# 1. 编译时添加 -fprofile-generate
g++ -O3 -fprofile-generate -o program program.cpp

# 2. 运行程序生成 profile 数据
./program < typical_input

# 3. 使用 profile 数据重新编译
g++ -O3 -fprofile-use -o program_optimized program.cpp
```

## 7.4 静态链接优化

**优势**：避免动态链接开销，提高启动速度，消除运行时库依赖。

```bash
# 完全静态链接
g++ -static -o program program.cpp

# 部分静态链接
g++ -static-libstdc++ -static-libgcc -o program program.cpp

# 对比动态链接
g++ -o program_dynamic program.cpp  # 默认动态链接
```

```c
// gcc/tree-ssa-loop-unroll.c - 循环展开优化
static bool try_unroll_loop_completely(struct loop *loop) {
    unsigned HOST_WIDE_INT niter;
    bool exit_at_end;
    
    // 计算循环迭代次数
    if (!number_of_iterations_exit(loop, loop->latch, &niter, &exit_at_end, false))
        return false;
    
    // 检查是否适合完全展开
    if (niter > (unsigned HOST_WIDE_INT)param_max_completely_peeled_insns)
        return false;
    
    // 执行循环展开
    return unroll_loop_constant_iterations(loop, niter, exit_at_end);
}
```

```cpp
// llvm/lib/Transforms/Scalar/LoopUnrollPass.cpp - LLVM循环展开
PreservedAnalyses LoopUnrollPass::run(Loop &L, LoopAnalysisManager &AM) {
    // 获取循环分析信息
    auto &FAM = AM.getResult<FunctionAnalysisManagerLoopProxy>(L).getManager();
    ScalarEvolution &SE = FAM.getResult<ScalarEvolutionAnalysis>(*L.getHeader()->getParent());
    
    // 计算展开因子
    TargetTransformInfo &TTI = FAM.getResult<TargetIRAnalysis>(*L.getHeader()->getParent());
    unsigned TripCount = SE.getSmallConstantTripCount(&L);
    
    // 自动决定展开因子
    unsigned UnrollFactor = computeUnrollCount(&L, TripCount, TTI, SE);
    
    if (UnrollFactor > 1) {
        // 执行循环展开
        UnrollLoop(&L, UnrollFactor, TripCount, false, &LI, &SE, &DT, &AC, &TTI, &ORE);
        return PreservedAnalyses::none();
    }
    
    return PreservedAnalyses::all();
}
```

**技术说明**：LLVM的循环展开优化使用目标架构信息（TTI）和标量演化分析（SE）智能决定展开因子，考虑CPU流水线、缓存大小等因素，生成最优代码。
