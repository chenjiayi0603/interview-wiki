# 编译器优化

> 编译器优化是 C++ 性能优化的重要考点，涵盖编译选项优化、编译器优化技术（内联、循环优化、死代码消除、常量折叠和传播）以及链接时优化（LTO）。

## 编译选项优化

### 优化级别

```bash
# -O0: 无优化（调试用）
g++ -O0 -g program.cpp

# -O1: 基本优化
g++ -O1 program.cpp

# -O2: 推荐优化级别（平衡性能和编译时间）
g++ -O2 program.cpp

# -O3: 激进优化（可能增加代码大小）
g++ -O3 program.cpp

# -Os: 优化代码大小
g++ -Os program.cpp

# -Ofast: 最快优化（可能违反标准）
g++ -Ofast program.cpp
```

**优化级别对比**：

| 级别 | 优化内容 | 适用场景 |
|------|---------|---------|
| -O0 | 无优化 | 调试阶段 |
| -O1 | 基本优化（删除未使用代码、简化表达式） | 开发阶段 |
| -O2 | 完整优化（内联、循环优化、指令调度） | **生产环境推荐** |
| -O3 | 激进优化（向量化、函数内联、循环展开） | 性能关键路径 |
| -Os | 代码大小优化 | 嵌入式系统 |

### 常用优化选项

```bash
# 内联函数优化
g++ -O2 -finline-functions program.cpp

# 循环优化
g++ -O2 -funroll-loops program.cpp        # 循环展开
g++ -O2 -floop-optimize program.cpp      # 循环优化

# 链接时优化（LTO）
g++ -O2 -flto program.cpp

# 架构特定优化
g++ -O2 -march=native program.cpp        # 针对当前CPU优化
g++ -O2 -mtune=haswell program.cpp       # 针对特定架构调优

# 向量化优化
g++ -O3 -mavx2 -mfma program.cpp         # 启用AVX2和FMA指令

# 分支预测优化
g++ -O2 -fprofile-use program.cpp       # 使用性能分析数据优化
```

## 编译器优化技术

### 内联优化

```cpp
// 显式内联
inline int add(int a, int b) {
    return a + b;
}

// 强制内联（可能增加代码大小）
__attribute__((always_inline))
int fast_add(int a, int b) {
    return a + b;
}

// 禁止内联
__attribute__((noinline))
void debug_function() {
    // 调试函数，不希望被内联
}

// 模板函数自动内联
template<typename T>
T max(T a, T b) {
    return a > b ? a : b;  // 编译器会自动内联
}
```

### 循环优化

```cpp
// 1. 循环展开（Loop Unrolling）
// 编译器自动展开小循环
for (int i = 0; i < 4; ++i) {
    arr[i] = i;
}
// 可能被优化为：
arr[0] = 0;
arr[1] = 1;
arr[2] = 2;
arr[3] = 3;

// 2. 循环不变式外提（Loop Invariant Code Motion）
int sum = 0;
int constant = expensive_function();  // 不变式
for (int i = 0; i < n; ++i) {
    sum += arr[i] * constant;  // constant 会被外提
}

// 3. 循环融合（Loop Fusion）
// 原始代码
for (int i = 0; i < n; ++i) {
    a[i] = b[i] + 1;
}
for (int i = 0; i < n; ++i) {
    c[i] = a[i] * 2;
}
// 优化后
for (int i = 0; i < n; ++i) {
    a[i] = b[i] + 1;
    c[i] = a[i] * 2;  // 合并循环，提高缓存局部性
}

// 4. 循环交换（Loop Interchange）
// 提高缓存局部性
int arr[1000][1000];
// ❌ 不好的访问模式
for (int i = 0; i < 1000; ++i) {
    for (int j = 0; j < 1000; ++j) {
        arr[j][i] = i + j;  // 列优先访问
    }
}
// ✅ 好的访问模式
for (int i = 0; i < 1000; ++i) {
    for (int j = 0; j < 1000; ++j) {
        arr[i][j] = i + j;  // 行优先访问
    }
}
```

### 死代码消除

```cpp
// 编译器会自动删除死代码
int unused_variable = 100;  // 未使用，会被删除

void function() {
    if (false) {  // 条件永远为假
        // 这段代码会被删除
    }
    
    int x = 10;
    if (x > 20) {  // 编译时可知为假
        // 也会被删除
    }
}
```

### 常量折叠和传播

```cpp
// 编译时计算常量表达式
const int a = 10;
const int b = 20;
int c = a + b;  // 编译时计算为 30

// 常量传播
int x = 5;
int y = x * 2;  // 编译器知道 y = 10
```

## 链接时优化（LTO）

```bash
# 编译时生成中间表示
g++ -O2 -flto -c file1.cpp -o file1.o
g++ -O2 -flto -c file2.cpp -o file2.o

# 链接时优化
g++ -O2 -flto file1.o file2.o -o program

# 或者一步完成
g++ -O2 -flto file1.cpp file2.cpp -o program
```

**LTO优势**：
- 跨文件内联
- 跨文件死代码消除
- 更好的全局优化

**LTO缺点**：
- 编译时间增加
- 内存占用增加
- 调试困难
