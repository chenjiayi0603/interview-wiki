# 网络编程

## 一、TCP/UDP协议

### 1. TCP特性
- **面向连接**：三次握手建立，四次挥手断开
- **可靠传输**：确认应答、超时重传、流量控制
- **顺序保证**：序号和确认号
- **拥塞控制**：慢启动、拥塞避免、快速恢复
- **全双工**：双向通信

### 2. 三次握手与四次挥手
```
三次握手：
Client ─── SYN=1, seq=x ────> Server
Client <── SYN=1, ACK=1, seq=y, ack=x+1 ── Server
Client ─── ACK=1, seq=x+1, ack=y+1 ───> Server

四次挥手：
Client ─── FIN=1, seq=u ────> Server
Client <── ACK=1, ack=u+1 ──── Server  (服务端可能还有数据)
Client <── FIN=1, seq=w ──── Server
Client ─── ACK=1, ack=w+1 ───> Server
```

### 3. TCP状态转换
```
LISTEN → SYN_SENT → ESTABLISHED → FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT → CLOSED
                                         ↓
                                    CLOSING
SYN_RCVD → ESTABLISHED → CLOSE_WAIT → LAST_ACK → CLOSED
```

### 4. UDP特性
- **无连接**：不需要握手
- **不可靠**：无确认、无重传
- **高效**：头部仅8字节
- **无流量控制**
- **无拥塞控制**

### 5. TCP vs UDP
| 特性 | TCP | UDP |
|------|-----|-----|
| 连接性 | 面向连接 | 无连接 |
| 可靠性 | 可靠 | 不可靠 |
| 效率 | 较低 | 高 |
| 头部 | 20-60字节 | 8字节 |
| 应用 | HTTP/SSH/MySQL | DNS/VoIP/游戏 |

## 二、TCP深入原理

### 1. 滑动窗口
```
发送方：
┌────────┬────────┬────────┐
│ 已发送 │ 可发送  │ 不可发送│
│ 已确认 │        │        │
└────────┴────────┴────────┘

接收方：
┌────────┬────────┬────────┐
│ 已接收 │ 等待    │ 无法接收│
│ 已确认 │ 窗口    │        │
└────────┴────────┴────────┘
```

### 2. 流量控制
- 接收方通过rwnd通知发送方窗口大小
- Zero Window：窗口为0时停止发送
- Window Probe：探测窗口是否恢复

### 3. 拥塞控制
```cpp
// cwnd：拥塞窗口
// ssthresh：阈值

// 慢启动：cwnd指数增长，直到ssthresh
cwnd *= 2

// 拥塞避免：cwnd线性增长
cwnd += 1

// 快速重传：收到3个重复ACK
cwnd = cwnd / 2, ssthresh = cwnd
进入快速恢复

// 超时
ssthresh = cwnd / 2, cwnd = 1 MSS
重新慢启动
```

### 4. Nagle算法
- 合并小包，减少网络小包数量
- 适用于ssh等低延迟场景
- 可以通过TCP_NODELAY禁用

## 三、Socket编程

### 1. TCP Server
```cpp
#include <sys/socket.h>
#include <netinet/in.h>
#include <arpa/inet.h>

int create_tcp_server(int port) {
    int sockfd = socket(AF_INET, SOCK_STREAM, 0);
    
    int opt = 1;
    setsockopt(sockfd, SOL_SOCKET, SO_REUSEADDR, &opt, sizeof(opt));
    
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(port);
    
    bind(sockfd, (struct sockaddr*)&addr, sizeof(addr));
    listen(sockfd, SOMAXCONN);
    
    return sockfd;
}

void handle_client(int clientfd) {
    char buf[1024];
    while (true) {
        ssize_t n = read(clientfd, buf, sizeof(buf));
        if (n <= 0) break;
        write(clientfd, buf, n);
    }
    close(clientfd);
}

int main() {
    int serverfd = create_tcp_server(8080);
    while (true) {
        struct sockaddr_in client;
        socklen_t len = sizeof(client);
        int clientfd = accept(serverfd, (struct sockaddr*)&client, &len);
        handle_client(clientfd);
    }
}
```

### 2. TCP Client

### 3. UDP Server
```cpp
int create_udp_server(int port) {
    int sockfd = socket(AF_INET, SOCK_DGRAM, 0);
    
    struct sockaddr_in addr;
    memset(&addr, 0, sizeof(addr));
    addr.sin_family = AF_INET;
    addr.sin_addr.s_addr = INADDR_ANY;
    addr.sin_port = htons(port);
    
    bind(sockfd, (struct sockaddr*)&addr, sizeof(addr));
    return sockfd;
}

void handle_udp() {
    char buf[1024];
    struct sockaddr_in client;
    socklen_t len = sizeof(client);
    
    ssize_t n = recvfrom(sockfd, buf, sizeof(buf), 0,
                         (struct sockaddr*)&client, &len);
    sendto(sockfd, buf, n, 0, (struct sockaddr*)&client, len);
}
```

### 2. epoll
```cpp
#include <sys/epoll.h>

// 创建
int epfd = epoll_create1(0);

// 添加事件
struct epoll_event ev;
ev.events = EPOLLIN | EPOLLET;
ev.data.fd = serverfd;
epoll_ctl(epfd, EPOLL_CTL_ADD, serverfd, &ev);

// 等待
struct epoll_event events[1024];
while (true) {
    int n = epoll_wait(epfd, events, 1024, -1);
    for (int i = 0; i < n; ++i) {
        int fd = events[i].data.fd;
        if (events[i].events & EPOLLIN) {
            // 读事件
        }
        if (events[i].events & EPOLLOUT) {
            // 写事件
        }
    }
}
```

### 3. epoll LT vs ET
```cpp
// LT（Level Trigger，水平触发）
// 只要条件满足，一直通知
// 适合读取：没读完会继续通知

// ET（Edge Trigger，边沿触发）
// 状态变化才通知一次
// 必须循环读取到EAGAIN
// 性能更高，但代码复杂

// ET模式读取示例
while (true) {
    ssize_t n = read(fd, buf, sizeof(buf));
    if (n > 0) {
        // 处理数据
    } else if (n == 0) {
        // 对端关闭
        break;
    } else {
        if (errno == EAGAIN) {
            // 读完，等待下次事件
            break;
        }
        // 错误处理
    }
}
```

## 五、高性能网络编程

### 1. Reactor模型
```cpp
class Reactor {
    int epfd_;
    std::unordered_map<int, Channel*> channels_;
    
public:
    void addFd(int fd, Channel* ch) {
        struct epoll_event ev;
        ev.events = ch->events();
        ev.data.ptr = ch;
        epoll_ctl(epfd_, EPOLL_CTL_ADD, fd, &ev);
        channels_[fd] = ch;
    }
    
    void loop() {
        while (true) {
            int n = epoll_wait(epfd_, events, MAX_EVENTS, -1);
            for (int i = 0; i < n; ++i) {
                Channel* ch = (Channel*)events[i].data.ptr;
                ch->handle(events[i].events);
            }
        }
    }
};
```

### 2. 线程池
```cpp
class ThreadPool {
    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex mtx_;
    std::condition_variable cv_;
    bool stop_ = false;
    
public:
    ThreadPool(size_t n) {
        for (size_t i = 0; i < n; ++i) {
            workers_.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    {
                        std::unique_lock<std::mutex> lock(mtx_);
                        cv_.wait(lock, [this] { return stop_ || !tasks_.empty(); });
                        if (stop_ && tasks_.empty()) return;
                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    task();
                }
            });
        }
    }
    
    template<typename F>
    void enqueue(F&& f) {
        {
            std::lock_guard<std::mutex> lock(mtx_);
            tasks_.emplace(std::forward<F>(f));
        }
        cv_.notify_one();
    }
    
    ~ThreadPool() {
        stop_ = true;
        cv_.notify_all();
        for (auto& t : workers_) t.join();
    }
};
```

#include <evwebsocket.h>

void read_cb(struct ev_loop* loop, struct ev_io* watcher, int revents) {
    char buffer[1024];
    int n = recv(watcher->fd, buffer, sizeof(buffer), 0);
    if (n <= 0) {

## 九、面试高频问题

### Q1: TCP三次握手为什么需要三次？
**参考答案**：
- 确认双方发送和接收能力
- 第一次：服务端确认客户端发送正常
- 第二次：客户端确认服务端发送和接收正常
- 第三次：服务端确认客户端接收正常
- 如果只有两次，服务端无法确认客户端是否收到自己的 SYN+ACK

### Q2: TCP四次挥手为什么需要四次？
**参考答案**：
- 主动关闭方发送FIN，表示不再发送数据
- 被动关闭方收到后返回ACK，可能还有数据要发送
- 被动关闭方发送FIN，表示不再发送数据
- 主动关闭方返回ACK，等待2MSL后关闭
- 确保被动方收到最后的ACK

### Q3: TIME_WAIT状态为什么需要2MSL？
**参考答案**：
- MSL（Maximum Segment Lifetime）：报文最大生存时间
- 确保最后一个ACK到达对方
- 让本连接的所有报文在网络中消失
- 防止旧连接的报文干扰新连接

### Q4: TCP如何保证可靠性？
**参考答案**：
- 校验和：检测数据错误
- 序号：检测重复和乱序
- 确认应答：确认收到数据
- 超时重传：丢失数据重发
- 流量控制：滑动窗口
- 拥塞控制：避免网络过载

### Q5: 什么是半连接队列？
**参考答案**：
- 服务器收到SYN后进入SYN_RCVD状态
- 此时连接在半连接队列
- 队列满时丢弃SYN
-防御SYN Flood：
  - SYN Cookie
  - 减少SYN+ACK重试次数
  - 防火墙

### Q6: epoll比select/poll好在哪？
**参考答案**：
- select/poll每次调用需要传递所有fd，内核遍历
- epoll用红黑树管理fd，增删改高效
- epoll只返回就绪的fd，不用遍历
- epoll支持LT和ET模式
- epoll支持边缘触发，性能更高
