# 跳表

> 跳表 (Skip List) 是一种在 O(log n) 时间内完成增加、删除、搜索操作的数据结构。相比于树堆与红黑树，其功能与性能相当，并且跳表的代码长度相较下更短，其设计思想与链表相似。

See also: [[Go_LeetCode技巧]], [[C++链表]], [[C++手写代码模板]]

## 概述

跳表中有很多层，每一层是一个短的链表。在第一层的作用下，增加、删除和搜索操作的时间复杂度不超过 O(n)。跳表的每一个操作的平均时间复杂度是 O(log(n))，空间复杂度是 O(n)。

了解更多: https://en.wikipedia.org/wiki/Skip_list

## 接口设计

在 LeetCode 题目 [设计跳表](https://leetcode.cn/problems/design-skiplist/) 中，需要实现以下函数：

- `bool search(int target)` : 返回 target 是否存在于跳表中。
- `void add(int num)`: 插入一个元素到跳表。
- `bool erase(int num)`: 在跳表中删除一个值，如果 num 不存在，直接返回 false. 如果存在多个 num ，删除其中任意一个即可。

注意，跳表中可能存在多个相同的值，代码需要处理这种情况。

## C++ 实现

```cpp
class Skiplist {
public:
    static const int level = 8; // 层数，经验值 8,2的8次方是512量级
    // 定义跳表节点
    struct Node {
        int v; // 节点值
        vector<Node*> next = move(vector<Node*>(level)); //next[i] 表示当前节点第 i 层的 next
        Node(int _v) : v(_v) {}
    };
    Node head = Node(-1); // 定义头节点 head
    //找到每一层 i 小于目标值 target 的最大节点 pre[i]
    vector<Node*> find(int num) {
        vector<Node*> pre(level);
        auto p = &head; // 从头节点开始遍历每一层
        for (int i = level - 1; i >= 0; i -- ) {// 从上层往下层找(位置pre) 
            while (p->next[i] && p->next[i]->v < num) p = p->next[i]; 
            pre[i] = p; // 找到了第 i 层小于 target 的最大节点就是 p
        }
        return move(pre);
    }
    // 从跳表中查找 target
    bool search(int num) {
        auto pre = move(find(num)); 
        auto p = pre[0]->next[0]; 
        return p && p->v == num;//pre[0]->next[0] 的值不是 target 说明没有这个元素
    }
    // 向跳表中插入元素 num
    void add(int num) {
        auto pre = move(find(num)); 
        auto p = new Node(num); // 新节点
        for (int i = 0; i < level; i ++ ) { // 遍历每一层，从下往上插入新节点
            p->next[i] = pre[i]->next[i]; // 插入到pre后面
            pre[i]->next[i] = p;
            if (rand() % 2) break; // 每一层有 50% 的概率不插入新节点
        }
    }
    // 从跳表中删除 num
    bool erase(int num) {
        auto pre = move(find(num)); 
        auto p = pre[0]->next[0];
        if (!p || p->v != num) return false;// 先判断 num 是否存在，不存在直接返回 false
        // pre[i]->next[i] == p 说明第 i 层存在 p;从底往上移除链表节点
        for (int i = 0; i < level && pre[i]->next[i] == p; i ++ ) {
            pre[i]->next[i] = p->next[i]; // 单链表删除
        }
        delete p;
        return true;
    }
};
```
