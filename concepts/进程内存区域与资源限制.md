# 进程内存区域与资源限制

> 归纳：小对象分配器、BSS/栈/堆、RLIMIT_DATA 等核心概念与配置

---

## 1. 小对象分配器：栈 vs 堆

### 1.1 核心结论

**小对象分配器 ≠ 栈上分配**。「小对象」指**对象尺寸小**（如 ≤128 字节），不是指分配位置。

常见小对象分配器（SGI STL、jemalloc、tcmalloc、池化分配器等）都是**堆上的内存池**：从堆一次申请大块，再切分成小对象，供高频分配/释放复用。

### 1.2 分配位置速览

| 类型 | 分配位置 | 说明 |
|------|----------|------|
| SGI STL 二级分配器 | 堆 | malloc 批量申请 chunk，16 个 bin/free list |
| SmallObjectPoolAllocator | 堆 | 每次从堆申请 chunk，再切 block |
| jemalloc / tcmalloc 小对象路径 | 堆 | 线程本地 arena/cache，底层仍从堆取内存 |
| ObjectPoolFreelist（成员 storage） | 取决于实例 | 局部变量→栈；全局/static→BSS；new 出来→堆 |

**栈上分配**：局部变量、`alloca()`——不用小对象分配器。

### 1.3 会栈溢出吗？

标准小对象分配器从堆取内存，**一般不会导致栈溢出**。栈溢出多因：递归过深、超大局部数组、`alloca()` 等。

---

## 2. 成员变量 storage 的位置

以 `ObjectPoolFreelist` 的 `alignas(T) unsigned char storage[N * sizeof(T)]` 为例：

| ObjectPoolFreelist 实例所在位置 | storage 所在位置 |
|--------------------------------|------------------|
| 局部变量 `ObjectPoolFreelist<Foo,64> pool;` | **栈** |
| 全局/静态 `static ObjectPoolFreelist<Foo,64> pool;` | **静态区（BSS）** |
| 动态分配 `new ObjectPoolFreelist<Foo,64>()` | **堆** |
| 作为另一类成员 | 跟随 outer 对象 |

storage 是普通成员，对象在哪它就哪，**不一定是静态区**。

## 3. BSS 与栈的典型大小

### 3.1 BSS 段（静态区）

| 特性 | 说明 |
|------|------|
| 大小决定因素 | 未初始化/零初始化的全局/静态变量，编译链接时固定 |
| 有无固定上限 | 无独立硬上限，受进程地址空间和 RLIMIT_DATA 限制 |
| 典型范围 | 几 KB～数 MB |
| 磁盘占用 | 几乎不占可执行文件体积（OS 加载时清零分配） |

### 3.2 栈

| 平台 | 主线程 | 子线程 |
|------|--------|--------|
| Linux | 默认约 **8MB**（`ulimit -s`） | 默认约 **8MB**，可 `pthread_attr_setstacksize` |
| macOS | 主线程约 8MB | 默认约 **512KB** |
| Windows | 默认 **1MB** | 默认 1MB |

```bash
ulimit -s          # 查看栈大小（KB）
ulimit -s 16384    # 设为 16MB
```

---

## 4. BSS 最大能有多大

### 4.1 架构限制

| 架构 | 用户空间 | BSS 理论上限 |
|------|----------|--------------|
| 32 位 Linux | 约 3GB | Data+BSS+堆 共享，总和约 3GB 以内 |
| 64 位 Linux | 约 128TB | 理论上可很大，受 RLIMIT_DATA、物理内存等限制 |

### 4.2 与堆共享 RLIMIT_DATA

BSS 与 brk 堆**共享同一上限**：`RLIMIT_DATA`（数据段限制）。

```
低地址
├── Data 段
├── BSS 段        ← RLIMIT_DATA 限制
├── 堆 (brk)      ← 此三者之和
└── ...
```

- **brk 堆**：通过 `brk/sbrk` 扩展，受 RLIMIT_DATA
- **mmap 分配**（malloc 大块）：独立 mmap 区域，受 RLIMIT_AS 等，**不受** RLIMIT_DATA

## 5. RLIMIT_DATA（数据段限制）

### 5.1 定义

| 项目 | 内容 |
|------|------|
| 英文名 | RLIMIT_DATA |
| 中文名 | **数据段限制** / 数据段大小限制 |
| 限制对象 | Data + BSS + brk 堆（三者总和） |
| 单位 | 字节 |

### 5.2 查看与配置

**Shell：**
```bash
ulimit -d              # 查看（KB）
ulimit -d 1048576      # 设为 1GB
ulimit -d unlimited    # 设为无限制
```

**C/C++：**
```cpp
#include <sys/resource.h>

struct rlimit lim;
getrlimit(RLIMIT_DATA, &lim);   // 查询
lim.rlim_cur = 2ULL * 1024 * 1024 * 1024;  // 2GB
setrlimit(RLIMIT_DATA, &lim);   // 设置
```

**配置文件 `/etc/security/limits.conf`：**
```
user1  soft  data  4194304    # 4GB
*      hard  data  unlimited
```

### 5.3 权限规则

| 操作 | 权限 |
|------|------|
| 降低 rlim_cur | 普通用户可 |
| 提高 rlim_cur | 不能超过 rlim_max |
| 提高 rlim_max | 通常需 root 或 CAP_SYS_RESOURCE |

---

## 6. 速查表

| 区域 | 典型大小 | 主要限制 | 可配置 |
|------|----------|----------|--------|
| BSS | 程序决定，几 KB～数 MB | RLIMIT_DATA | 编译期固定，运行期不变 |
| 栈 | Linux 8MB，Windows 1MB | RLIMIT_STACK | `ulimit -s`、pthread_attr |
| Data+BSS+brk 堆 | 共享上限 | RLIMIT_DATA | `ulimit -d`、setrlimit |
| mmap 区域 | 动态 | RLIMIT_AS 等 | setrlimit |

---

## 7. 面试要点

1. **小对象分配器**：针对小尺寸对象的堆上内存池，非栈分配。
2. **ObjectPool 的 storage**：成员变量，位置取决于实例（栈/堆/BSS）。
3. **BSS 与堆**：共享 RLIMIT_DATA，BSS 大则堆空间少。
4. **RLIMIT_DATA**：数据段限制，限制 Data+BSS+brk 堆总和。
5. **栈溢出**：递归、大局部数组、alloca，与小对象分配器无直接关系。
