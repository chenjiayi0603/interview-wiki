# 进程同步

See also: [[线程同步]], [[C++多线程与并发]]

## 一、概述

进程同步涉及多个独立进程之间的协调与通信。与线程同步不同，进程拥有独立的地址空间，需要借助操作系统提供的 IPC（进程间通信）机制。

## 二、核心知识点

### 1. 共享内存

```cpp
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>

// 创建共享内存
int fd = shm_open("/my_shm", O_CREAT | O_RDWR, 0666);
ftruncate(fd, sizeof(SharedData));

// 映射到进程地址空间
SharedData* data = (SharedData*)mmap(
    NULL, sizeof(SharedData),
    PROT_READ | PROT_WRITE,
    MAP_SHARED,
    fd, 0
);

// 使用共享内存
data->counter++;

// 清理
munmap(data, sizeof(SharedData));
close(fd);
shm_unlink("/my_shm");
```

### 2. 信号量

```cpp
#include <semaphore.h>

// 创建命名信号量
sem_t* sem = sem_open("/my_sem", O_CREAT, 0666, 1);

// 等待（P 操作）
sem_wait(sem);
// 临界区
// ...
// 释放（V 操作）
sem_post(sem);

// 关闭
sem_close(sem);
sem_unlink("/my_sem");
```

### 3. 文件锁

```cpp
#include <sys/file.h>

int fd = open("/tmp/lockfile", O_CREAT | O_RDWR, 0666);

// 排他锁
flock(fd, LOCK_EX);
// 临界区
flock(fd, LOCK_UN);

// 或使用 fcntl
struct flock fl;
fl.l_type = F_WRLCK;
fl.l_whence = SEEK_SET;
fl.l_start = 0;
fl.l_len = 0;
fcntl(fd, F_SETLKW, &fl);
```

### 4. 进程间通信方式对比

| 方式 | 特点 | 适用场景 |
|------|------|----------|
| 管道 (pipe) | 单向，父子进程 | 简单数据流 |
| 命名管道 (FIFO) | 无亲缘关系进程 | 持久化通信 |
| 共享内存 | 最快，需同步 | 大数据量 |
| 信号量 | 计数器，同步 | 资源控制 |
| 消息队列 | 结构化消息 | 异步通信 |
| Socket | 跨网络 | 分布式系统 |

## 三、进程同步 vs 线程同步

| 特性 | 进程同步 | 线程同步 |
|------|----------|----------|
| 地址空间 | 独立 | 共享 |
| 通信开销 | 大（内核介入） | 小（用户态） |
| 同步机制 | 信号量、文件锁、共享内存+互斥 | mutex、atomic、条件变量 |
| 安全性 | 更隔离 | 需小心数据竞争 |

## 四、面试重点

1. **进程间通信方式**：管道、共享内存、信号量、socket
2. **共享内存同步**：必须配合同步原语使用
3. **进程同步 vs 线程同步**：跨进程的开销更大
