**每连接开销明细**:
```

写缓冲区（AI 响应）：16KB
```

## 三、核心框架/核心技术

### WebSocket Hub + Client Actor 模型

```
Client A → WebSocket Conn → Hub.Register → Actor Goroutine（循环读）
                                      ↓
Client B → WebSocket Conn → Hub.Register → Actor Goroutine（循环读）
                                      ↓
                                    Hub.Broadcast → 所有 Client
```

- 每连接独立 Actor Goroutine，避免多连接共享锁
- Hub 层统一管理注册/注销/广播
- 读写分离: 读 Goroutine + 写 Buffer（channel 投递）

### AI 流式响应

```
客户端 → WebSocket 发送问题 → 服务端 → DeepSeek API（stream=true）
                                          ↓
                                    逐 chunk 回传
                                          ↓
                                    每收到一个 token 立即推 WebSocket
首字延迟: 2s → 0.5s（打字机效果）
```

### 四 Agent 提示词系统

```
面试官 Agent:  出题 + 追问（基于岗位 JD + 简历）
评分 Agent:    实时评分（发音 + 内容 + 逻辑）
反馈 Agent:    生成改进建议
引导 Agent:    控制对话流程（开始/结束/难度调整）
```

## 四、瓶颈

| 问题 | 现象 | 优化 | 效果 |
|------|------|------|------|
| **AI 首字延迟** | 等待完整响应 2s | 流式 stream=true 逐 chunk 转发 | **0.5s** |
| **TTS 合成慢** | 首次合成 2s | 启动预加载模型 | **1s** |
| **STT 延迟** | 录音结束才识别 800ms | 流式上传，边录边识别 | **500ms** |
| **内存占用高** | 频繁 GC 5GB | 对象池复用 buffer/连接 | **3GB** |
| **并发瓶颈** | 5,000 连接 Goroutine 调度开销大 | 调优 GOMAXPROCS + 复用 Goroutine | **10,000** |
