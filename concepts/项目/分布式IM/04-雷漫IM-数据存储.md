## 三、Redis 缓存结构设计

### 3.1 登录与 Token 缓存

#### Token (String)
```
Key:   1:1:im:token:userid:${userid}:deviceid:${deviceid}
Value: token 字符串
```

#### 用户登录状态 (Hash) ⭐
```
Key:   1:2:im:status:userid:${userid}
Fields: (所有字段带 ${deviceid} 后缀)
  - logintime:${deviceid}      登录时间（秒）
  - clienttype:${deviceid}     客户端类型
  - status:${deviceid}         在线状态 0/1/2
  - loginseq:${deviceid}       防重登序列号
  - ssidfreshtime:${deviceid}  心跳刷新时间
  - sessionid:${deviceid}      链路唯一标识
  - sessionkey:${deviceid}     对称加密密钥（32字节）
  - accnodeidentify:${deviceid} 网关定位
```

### 3.2 好友关系缓存

#### 好友缓存信息 (Hash)
```
Key: 1:2:im:friend:userid:${userid}
Fields: friendid → 好友信息 JSON
```

#### 好友在线状态 (Hash)
```
Key: 1:2:im:friendonline:userid:${userid}
Fields: friendid → is_online
```

### 3.3 群组缓存

#### 群信息 (String/JSON)
```
Key: 1:2:im:group:groupid:${groupid}
Value: 群信息 JSON
```

#### 群成员列表 (Set)
```
Key: 1:2:im:groupmember:groupid:${groupid}
Members: userid 列表
```

### 3.4 消息缓存

#### 最近消息列表 (List)
```
Key: 1:2:im:msg:recent:userid:${userid}
Value: 最近 N 条消息的 msgId 列表
```

#### 消息内容 (String/JSON)
```
Key: 1:2:im:msg:content:msgid:${msgid}
Value: 消息内容 JSON
```

### 3.5 分布式缓存架构（Codis）

```
codis-proxy:  172.19.1.38:19000, 172.19.1.193:19000
codis-fe:     172.19.1.38:8090（控制台）
codis-dashboard: 172.19.1.38:18080

Group1: 172.19.1.38:6379, 172.19.1.193:6380
Group2: 172.19.1.193:6379, 172.19.1.38:6380
Sentinels: 172.19.1.38:26379, 172.19.1.193:26379, 172.19.1.163:26379
```

### 3.6 缓存 Key 命名规范

```
格式：{分段1}:{分段2}:{模块}:{表/功能}:{key字段}:{key值}

分段1：项目标识（1=IM）
分段2：数据类型（1=String 2=Hash 3=Set 4=List）
模块：模块名（im）
表/功能：表名或功能名（status, token, friend）
key字段：主键列名（userid, groupid）
key值：主键值
```

**设计原则**：
- 先更新数据库，再失效缓存
- 支持多设备：所有设备相关字段带 `${deviceid}` 后缀
- 会话路由：`accnodeidentify` 定位用户连接的网关节点，消息路由的关键
