# IM消息协议定义

> 本文档整理自雷漫分布式IM系统的消息协议定义，涵盖协议包头结构、命令字分段、核心消息类型、消息类型定义及命令字映射。

## 3.1 协议框架

**协议包头结构**:
```
字段名    描述        长度字节    备注
len      包总长度     4          固定包头+可变包体
cmd      消息类型     4
seq      序列号id     4          请求方填写，返回确认需带回SEQ
version  协议版本号   1          协议版本号：当前固定为1
reserve  保留字段     1          保留
status   状态         2          请求默认200，返回具体定义
协议包体
```

**命令字分段**:
- `1001~2000`: 用户相关命令字
- `2001~3000`: 用户关系命令字
- `3001~4000`: 群管理命令字
- `4001~5000`: 聊天相关命令字
- `5001~6000`: IM管理相关命令字
- `6001~7000`: 社交相关命令字
- `7001~8000`: 官方或第三方消息推送
- `8001~9000`: IM与业务后台通信协议
- `1~1000`: IM服务端系统协议

## 3.2 核心消息类型

### 3.2.1 长连接认证请求 (cmd=1001)

- **方向**: APP->TS
- **用途**: 长连接认证和建立
- **字段**: 参见加密协议文档

### 3.2.2 发送消息 (cmd=4001)

- **方向**: APP->TS
- **字段**:
  - `fromId`: 发送ID
  - `dstId`: 接收ID
  - `dstType`: 目的类型（1:用户 2:群 3:系统）
  - `msgId`: 消息id
  - `sendTime`: 客户端发送时间
  - `msgType`: 消息类型
  - `msg`: 消息体内容
  - `nodeId`: 会话id
  - `msgseq`: 消息流水，必须递增且连续
  - `keyVersion`: 端到端密钥版本号

**ACK响应 (cmd=4002)**:
- `code`: 返回码
- `msgId`: 消息id（服务器生成）
- `serverTime`: 服务器时间戳(单位: 微秒)
- `msgseq`: 服务端返回的消息序列号
- `keyUpdated`: 是否需要更新密钥（0不用更新，1需要更新）

### 3.2.3 接收消息 (cmd=4003)

- **方向**: TS->APP
- **字段**: 同发送消息结构

### 3.2.4 发送消息状态 (cmd=4005)

- **方向**: APP->TS
- **字段**:
  - `fromId`: 发送ID
  - `dstId`: 接收ID
  - `msgState`: 状态（0:默认 1:xxx 2:送达 3:已读 4:撤回 5:删除自己 6:清空会话 7:上报语音已播状态）
  - `opmsgid`: 消息id数组（撤回/删除可以填多个）
  - `sendTime`: 客户端发出状态消息的时间

**说明**: 已读回执消息本质上是一条新的消息，存储进消息表（msg_c2c）中，与普通消息同级。

### 3.2.5 群消息 (cmd=4501/4503)

- **发送群消息 (cmd=4501)**: APP->TS
- **接收群消息 (cmd=4503)**: TS->APP
- **特殊字段**:
  - `notifyUserId`: @群成员列表
  - `notifyMsgId`: 针对群某单条消息回复

### 3.2.6 心跳 (cmd=1101)

- **方向**: APP->TS
- **间隔**: 推荐3.5分钟固定心跳
