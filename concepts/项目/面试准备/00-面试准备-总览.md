# 面试准备总览

> 面试策略、项目性能数据、简历论证、基础考点、故障排查、算法模板。

---

## 一、文件地图

| 文件 | 内容 | 优先级 |
|------|------|--------|
| **01-面试准备-项目性能数据.md** | 各项目性能数据详解（QPS/延迟/成本/可用性）+ 追问预案 | ⭐ 面试前必看 |
| **02-面试准备-简历知识点论证.md** | 简历每条描述的数据来源、理论依据、业界对标、追问预案 | 被追问时查阅 |
| **03-面试准备-基础考点.md** | C++/Go/Redis/MySQL 高频考点 | ⭐ 技术面必看 |
| **04-面试准备-故障排查.md** | 生产故障分类、五层防线、远程调用/内存/网络问题排查 | 项目面深挖 |
| **05-面试准备-算法模板.md** | A* / KMP / Viterbi / TF-IDF / Trie / 编辑距离 | 手写题参考 |
| **06-面试准备-面试策略.md** | 项目讲法、必背数据表、回答模板、节奏控制 | ⭐ 面试前过一遍 |

## 二、考前冲刺路径

| 时间 | 做什么 |
|------|--------|
| **面试前 1 天** | 06（策略+数据表）→ 01（性能数据追问预案）→ 03（基础考点速览） |
| **面试前 1 小时** | 06 的必背数据表再过一遍，每个项目的故事框架默念一次 |
| **被追问项目细节** | 翻 02（简历论证）找对应章节 |
| **被问故障场景** | 翻 04（故障排查）的四层防线框架 |
| **手写题** | 翻 05（算法模板）找对应模板 |
