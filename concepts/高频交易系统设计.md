# 高频交易系统设计

## 系统架构

### 架构设计原则
1. 低延迟：微秒级延迟要求
2. 高吞吐：支持高并发订单处理
3. 高可用：系统容错和快速恢复
4. 可扩展：支持多交易所接入

### 核心模块
- **订单管理模块**：订单路由、匹配、执行
- **行情处理模块**：行情订阅、解析、分发
- **交易所连接管理模块**：连接池管理、协议适配（REST/WebSocket/私有）、重连与故障恢复
- **网络层（Kernel Bypass）**：Onload/DPDK/VMA、零拷贝传输

## 延迟优化

### 下单链路优化
- 使用无锁队列（SPSCQueue）
- 预分配内存（ObjectPool）
- 批量发送（BatchSender）
- 零拷贝传输（共享内存或sendfile）

### 行情链路优化
- 使用epoll边缘触发
- 批量接收
- 消息解析优化（SIMD加速、二进制协议）
- 内存池管理

### 微秒级延迟优化方法
1. **用户态网络协议栈/内核旁路**：DPDK、Onload绕过内核协议栈，直接收发报文到用户程序
2. **锁内存（mlockall）**：阻止内存被换出
3. **CPU绑核与隔离**：关键线程绑定独立核，隔离中断和其他负载
4. **内存和对象预分配**：启动时分配所有数据结构，运行时避免动态分配
5. **实时调度（SCHED_FIFO/SCHED_RR）**：调高线程优先级，使用实时调度类
6. **禁用CPU省电/频率调节**：设置为performance mode
7. **紧凑数据结构/零拷贝**：mmap、共享内存、sendfile
8. **Cache及NUMA优化**：访问本地内存，避免跨NUMA节点访问；关键数据结构按64字节对齐，防止伪共享
9. **精细化延迟测量**：对p99/p999延迟持续监控
10. **分支优化与批处理**：减少分支预测失败，使用likely/unlikely宏

### 延迟优化实践举例
- 使用DPDK直通网卡，内核旁路，收发帧延迟子微秒
- 所有订单、行情对象由预先分配的对象池管理，不触发malloc/free
- 尽量避免C++虚函数、std::function等动态多态带来的间接寻址
- 关键路径线程用SCHED_FIFO调度，绑定物理核，所在核关闭超线程和中断

### C++实现示例
```cpp
#include <sched.h>
#include <numa.h>
#include <sys/mman.h>
#include <pthread.h>

#define likely(x)   __builtin_expect(!!(x), 1)
#define unlikely(x) __builtin_expect(!!(x), 0)

class MicrosecondLatencyOptimizer {
public:
    // 1. 禁用系统调用开销（DPDK/Onload初始化）
    void disableSystemCalls() { /* 用户态网络协议栈初始化 */ }

    // 2. 内存预分配
    template<typename T>
    std::vector<T> preallocateMemory(size_t n) {
        std::vector<T> pool;
        pool.reserve(n);
        for(size_t i = 0; i < n; ++i) pool.emplace_back();
        return pool;
    }

    // 3. CPU绑定和隔离
    void isolateCPU(int cpu_id) {
        cpu_set_t cpuset;
        CPU_ZERO(&cpuset);
        CPU_SET(cpu_id, &cpuset);
        pthread_setaffinity_np(pthread_self(), sizeof(cpuset), &cpuset);
    }

    // 4. 禁用CPU频率调节
    void disableCPUFreqScaling(int cpu_id) {
        char cmd[128];
        snprintf(cmd, sizeof(cmd),
                 "echo performance | sudo tee /sys/devices/system/cpu/cpu%d/cpufreq/scaling_governor", cpu_id);
        std::cout << "请以root运行: " << cmd << std::endl;
    }

    // 5. 使用实时调度
    void setRealtimeScheduling() {
        struct sched_param param;
        param.sched_priority = 99;
        if (sched_setscheduler(0, SCHED_FIFO, &param) != 0) {
            std::cerr << "Failed to set real-time scheduling: " << strerror(errno) << std::endl;
        }
    }

    // 6. 内存锁定
    void lockMemory() {
        if (mlockall(MCL_CURRENT | MCL_FUTURE) != 0) {
            std::cerr << "mlockall failed: " << strerror(errno) << std::endl;
        }
    }

    // 7. 避免分支预测失败
    template<typename Func>
    void optimizeBranchPrediction(bool condition, Func fastPath) {
        if (likely(condition)) { fastPath(); }
    }
};
```
